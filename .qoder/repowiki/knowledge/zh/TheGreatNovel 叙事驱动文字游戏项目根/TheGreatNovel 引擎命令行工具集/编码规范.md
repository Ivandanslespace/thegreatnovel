- 每个脚本都是独立 CLI 工具，使用 `#!/usr/bin/env python3` shebang 和 `if __name__ == "__main__": sys.exit(main())` 模式暴露命令行入口。
- 通过 `sys.path.insert(0, str(Path(__file__).resolve().parent.parent))` 将项目根目录加入导入路径，从而直接 `from engine_runtime.* import ...` 访问引擎核心。
- 所有外部依赖（如 PyYAML）采用 try/except ImportError 懒加载并在缺失时输出友好提示后退出，保证脚本在无依赖环境下给出明确错误信息。
- CLI 参数统一使用 `argparse.ArgumentParser` 定义，子命令通过位置参数（如 `phase` 的 resolve/record）或显式子命令组织，错误处理统一打印到 stderr 并返回非零退出码。
- 存档校验结果通过 `Finding(severity, category, message)` 对象收集，严重度固定为 CRITICAL/ERROR/WARNING/INFO 四级，按类别分组输出。
- 对玩家输入的文本进行严格白名单校验，通过 `FORBIDDEN_TERMS` 列表检测 LLM 输出是否泄露系统细节（如「预览合法」「未结算」「Python」「SQLite」等关键词）。
