- 所有数值计算以纯函数形式放在 calculators.py，不接受也不修改全局状态，仅通过 dataclass 入参出参。
- GameState 与结算中间态使用 dataclass 定义，跨子模块传递时保持字段稳定并通过 FORMULA_VERSION 控制兼容性。
- SQLite 操作必须包裹在事务中，事件账本是唯一可信源，任何状态变更先写事件再投影快照。
- LLM 输入只允许 action_id/type/target/risk_preference/requirements 等最小结构，time_minutes/stamina_cost/seed/resolution 等派生字段禁止由 LLM 提交。
- 对外暴露的 API 集中在 __init__.py 的 __all__ 中，内部模块通过相对导入复用，避免直接调用 execute_action 等内部方法。
