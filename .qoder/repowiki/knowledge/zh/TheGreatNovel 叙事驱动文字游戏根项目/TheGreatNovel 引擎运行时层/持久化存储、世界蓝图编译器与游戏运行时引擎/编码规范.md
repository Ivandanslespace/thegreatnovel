- 所有状态变更都通过 `standard_event` 构造事件记录，再由 `state.apply_and_append` 统一写入，避免直接操作底层数据结构。
- 对外 API 遵循 preview-execute 双阶段模式：先调用 `preview_*` 返回 `{legal, errors, resolution, action_ledger}`，再通过对应的 `execute_*` 提交，失败时抛出 ValueError。
- SQLite 写入统一通过 `connect()` 上下文管理器获取连接并设置 `PRAGMA foreign_keys = ON`，批量写入使用 `BEGIN IMMEDIATE` 显式事务。
- 世界注册表查找统一使用 `_registry_lookup(registry, identifier)` 支持 Mapping 和 List 两种形态，优先按 id/name 匹配。
- 所有 JSON 序列化使用 `json.dumps(..., ensure_ascii=False)` 保证中文内容可读性，反序列化对应 `json.loads`。
- 常量与配置集中定义在模块级（如 SCHEMA、PROFILE_CONTENT、COMPILER_VERSION），函数内部只做浅拷贝 `deepcopy` 防止污染共享结构。
