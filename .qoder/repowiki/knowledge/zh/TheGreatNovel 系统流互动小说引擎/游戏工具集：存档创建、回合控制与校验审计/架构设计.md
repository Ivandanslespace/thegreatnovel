本模块是一组独立的 Python CLI 脚本，每个文件对应一个单一职责的工具入口，通过 `argparse` 暴露命令行参数，统一以 `sys.exit(main())` 作为可执行入口。

- 存档生命周期工具：`create_save.py` 基于模板和 YAML/交互式输入生成完整存档目录，调用 `engine_runtime.world_compiler.compile_world_bundle` 编译世界包并写入 SQLite 事件源；`validate_save.py` 实现六类校验（连续性、规则、知识、战力、关系、叙事），并通过 `assert_startable` 作为启动门禁。
- 回合控制工具：`game_turn.py` 提供基础的两阶段接口（resolve/record），`turn_controller.py` 在其之上增加智能选项识别（正则匹配 A/B/C 或自由文本）和 turn_token 机制，是 LLM 调用的统一入口。
- 行动执行工具：`run_action.py` 支持 dry-run 预览与实际执行，失败时自动回滚文件系统快照并追加拒绝审计记录；`record_turn.py` 专门用于补录已结算回合的小说正文。
- 数据验证工具：`replay_campaign.py` 从 SQLite 事件源重放投影，`verify_projection.py` 验证事件重放结果与最新快照一致，`audit_report.py` 将 `decision_audit.jsonl` 渲染为可读报告。

依赖方向单向指向 `engine_runtime.*`（GameEngine、state、events、persistence、presentation 等），tools 内部脚本之间仅通过 `validate_save.assert_startable` 和 `run_validation` 间接耦合，无循环依赖。所有脚本通过 `sys.path.insert(0, str(PROJECT_DIR))` 将项目根加入导入路径以访问 engine_runtime。
