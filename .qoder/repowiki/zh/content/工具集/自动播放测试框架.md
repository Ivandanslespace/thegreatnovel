## 核心工具详解

### autoplay_suite.py - 自动播放套件管理器
这是主要的自动播放执行工具，提供了完整的测试套件管理功能。它负责协调各种测试场景的执行，管理测试数据，并生成详细的测试结果报告。

主要功能：
- 批量执行自动播放测试用例
- 管理测试环境和配置
- 集成多种测试模式（单元测试、集成测试、端到端测试）
- 生成测试报告和统计数据

### autoplay_test.py - 专用测试工具
这是一个专门用于测试自动播放功能的工具，提供了更细粒度的测试控制能力。适合需要精确控制测试流程的高级用户。

主要特性：
- 单个测试用例的精确执行
- 调试模式和详细日志输出
- 自定义测试参数配置
- 实时测试状态监控

### autoplay_TEST_README.md - 测试文档
详细的测试工具使用文档，包含所有工具的完整说明、配置选项和使用示例。

## 使用指南

### 基本使用方法
```bash
# 运行完整的自动播放测试套件
python tools/autoplay_suite.py

# 运行特定的测试用例
python tools/autoplay_test.py --test-case specific_test

# 查看测试帮助信息
python tools/autoplay_test.py --help
```

### 配置选项
大多数工具支持以下通用配置选项：
- `--config`: 指定配置文件路径
- `--verbose`: 启用详细日志输出
- `--output`: 指定输出目录
- `--parallel`: 启用并行测试执行

### 最佳实践
1. 在开发环境中先运行单元测试
2. 使用集成测试验证系统整体功能
3. 定期运行完整的测试套件确保稳定性
4. 根据测试结果优化代码性能

## 故障排除

### 常见问题
1. **权限错误**: 确保具有执行 Python 脚本的权限
2. **依赖缺失**: 检查项目依赖是否完整安装
3. **配置文件错误**: 验证配置文件格式和路径正确性
4. **内存不足**: 对于大型测试套件，考虑增加系统内存或减少并行度

### 调试技巧
- 使用 `--verbose` 参数获取详细的错误信息
- 检查临时文件和日志输出
- 逐步缩小问题范围，从单个测试开始排查
