## 概述

存档创建工具是一个用于从模板生成新的游戏存档的实用程序。该工具支持多种存档文件格式，包括YAML配置和Markdown文档，能够创建完整的角色扮演游戏存档，包含玩家信息、物品清单、派系关系、NPC数据等。

该工具经过重大重构，现在提供了更简洁的接口和更强大的功能，支持自定义模板、数据验证和批量操作。最新版本增加了对多个战役配置的支持，包括"灰烬列车"和"锈铁方舟"等预设场景。

## 命令行参数

### 基本参数
```
--template <路径>     指定模板文件路径
--output <路径>      指定输出目录
--name <名称>        设置存档名称
--version <版本>     设置存档版本
--author <作者>      设置作者信息
--description <描述> 设置存档描述
--overwrite          允许覆盖现有文件
--verbose            启用详细输出
--validate           执行数据验证
```

### 高级参数
```
--config <配置文件>  指定配置文件路径
--batch              批量模式
--dry-run            仅模拟运行
--format <格式>      指定输出格式
--compress           压缩输出文件
--encrypt            加密敏感数据
```

### 参数组合示例
```bash
# 基本用法
python create_save.py --template templates/save_template --output ./saves

# 带命名参数的用法
python create_save.py --template templates/save_template --output ./saves --name "灰烬列车" --author "玩家1"

# 批量模式
python create_save.py --template templates/save_template --output ./saves --batch --config batch_config.yaml
```

## 使用方法

### 基本存档创建
```bash
# 从默认模板创建新存档
python create_save.py --template templates/save_template --output ./my_save

# 指定特定模板
python create_save.py --template /path/to/custom_template --output ./custom_save

# 创建带元数据的存档
python create_save.py --template templates/save_template \
    --output ./save_with_meta \
    --name "冒险开始" \
    --author "游戏设计师" \
    --description "一个全新的冒险故事"
```

### 批量创建存档
```bash
# 使用配置文件进行批量创建
python create_save.py --template templates/save_template \
    --output ./bulk_saves \
    --batch \
    --config bulk_config.yaml

# 批量创建并验证
python create_save.py --template templates/save_template \
    --output ./validated_saves \
    --batch \
    --config bulk_config.yaml \
    --validate
```

### 调试和测试
```bash
# 模拟运行（不实际创建文件）
python create_save.py --template templates/save_template \
    --output ./test_output \
    --dry-run \
    --verbose

# 仅执行验证
python create_save.py --template templates/save_template \
    --output ./validation_test \
    --validate \
    --verbose
```

## 模板系统

### 模板结构
存档模板采用分层结构，包含多个YAML配置文件和Markdown文档：

```
save_template/
├── base.yaml          # 基础配置
├── meta.yaml          # 元数据
├── player.yaml        # 玩家数据
├── inventory.yaml     # 物品清单
├── factions.yaml      # 派系关系
├── npcs.yaml          # NPC数据
├── relationships.yaml # 关系网络
├── event_queue.yaml   # 事件队列
├── conversation_log.md # 对话记录
├── decision_audit.md  # 决策审计
├── event_log.md       # 事件日志
├── novel_draft.md     # 小说草稿
└── story.md           # 故事框架
```

### 模板变量
模板支持以下变量替换：
- `{{name}}` - 存档名称
- `{{author}}` - 作者信息
- `{{date}}` - 创建日期
- `{{version}}` - 版本号
- `{{description}}` - 描述信息

### 自定义模板
创建自定义模板的步骤：
1. 复制现有模板结构
2. 修改需要的字段
3. 添加自定义验证规则
4. 测试模板完整性

### 基础配置
```yaml
# 基础配置示例

output_path: "./saves"
default_name: "未命名存档"
default_version: "1.0.0"
default_author: "未知作者"
```

### 高级配置
```yaml
# 高级配置示例
validation:
  enabled: true
  strict_mode: false
  skip_missing_fields: true

processing:
  parallel: true
  max_workers: 4
  timeout: 300

output:
  format: "yaml"
  compress: false
  encrypt: false
  backup_existing: true
```

### 批量配置
```yaml

  input_file: "input_data.csv"
  template_mapping:
    name: "character_name"
    author: "creator_name"
    description: "story_description"
  
  processing_rules:
    validate_each: true
    skip_on_error: false
    continue_on_failure: true
```

## 存档格式规范

### YAML格式规范
所有YAML文件遵循严格的格式规范：
- 使用UTF-8编码
- 缩进使用2个空格
- 字符串使用双引号
- 数字不使用引号
- 布尔值使用小写true/false

### Markdown格式规范
文档文件遵循Markdown标准：
- 使用ATX风格标题
- 列表使用有序和无序混合
- 代码块使用语法高亮
- 链接使用相对路径

### 元数据要求
每个存档必须包含以下元数据：
- 唯一标识符
- 创建时间戳
- 版本信息
- 作者信息
- 兼容性信息
