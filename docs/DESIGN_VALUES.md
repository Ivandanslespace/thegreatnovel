# TheGreatNovel 设计宪法

这份文档只回答：我们要让玩家体验什么。它稳定、短小、不可妥协；当前实现边界、
验收合同和路线只见 [`DEV_SPEC.md`](DEV_SPEC.md)。例子用于澄清原则，不是固定模板。

普通 coding、bugfix 或局部 review 只需读取本页定义、核心原则和相关章节；架构级、
产品级、跨 Feature、authority、Knowledge、WorldGen、Replay 或长期路线变更才需要
完整读取本文。减少上下文不等于跳过设计价值。

# NON-NEGOTIABLE CORE EXPERIENCE

正式 TGN 世界的唯一核心循环：

```text
CONTROL DEFICIT
→ RULE LEGIBILITY
→ ASYMMETRIC LEVERAGE
→ COMPOUNDING CONTROL
→ RELATIONSHIP REVERSAL
→ TIER ASCENT
→ LARGER WORLD
```

准确中文是：

```text
控制缺口
→ 看懂规则
→ 使用主角非对称杠杆
→ 将已有成果继续转化为更强控制力
→ 关系反转（并重新处理与危险、匮乏、规则和他人的关系）
→ 完成当前真实阶层跃迁
→ 进入更大的世界，在保留既有成果时重新面对相对失控
```

这是产品体验不变量。Feature、World Blueprint、Prompt、Agent、Preflight、Autoplay
和 Narrator 都不得与它冲突。短 slice 不必完成整个长循环，但每个正式世界必须能说明
自己如何沿这条循环发展。它描述体验，不是固定的 gameplay interface。

## 1. 规则产生经历，经历产生小说

世界先运行，小说后书写：玩家的行动、未行动、时间、资源、关系、风险和承诺共同产生
可追溯后果，叙事只表达已经成立的事实。删掉文字后，结构化世界仍应大致成立；删除
叙事不能删除因果。

```text
World / State
    ↓
+ consequence
    ↓
Narrative
```

LLM 可以提出可能性、解释和描写，但不能为了戏剧性临时补资源、改规则、让敌人变弱、
复活机会或覆盖历史。世界规则对所有人基本一致，主角的差异来自可验证的长期杠杆，
不是每次局部事件的剧情保护。

### 1.1 可理解、可归因、可重放

玩家不必预先知道所有答案，但应该能够通过观察、调查、关系、经验和承担成本逐步理解
失败原因。未知是可管理的风险，不是作者随时按下的惩罚按钮。一个重要后果至少应能
回答：发生了什么、为什么发生、玩家当时能知道什么、下次怎样改变策略。

规则的“公平”不是让每个角色得到相同结果，而是让结果遵循事先存在的条件。随机性可以
创造体验差异，但不能掩盖规则错误；关键事实应能从状态、事件和历史重放，而不是从
散文猜回去。

### 1.2 时间给世界行动权

时间不是 UI 上的扣数值。玩家花掉时间时，世界也获得行动权：人物会改变计划，资源会
被获取，关系会恶化或巩固，风险会累积，机会会开启或关闭。已经解决的低层劳动可以
自动化、委托或背景化，以便玩家把时间投入新的机会、责任、维护和更高层冲突；这不是
让时间失去意义，而是让稀缺对象随着控制力改变。

## 2. 写死体验，不写死接口

不可妥协的是：

- 玩家真实感到控制缺口，并能逐步看懂规则；
- 规则稳定、可解释、可验证，风险不是任意惩罚；
- 主角拥有普通人难以复制的因果杠杆；
- 已挣得成果可以保存、积累并提高后续转化能力；
- 成长扩大策略空间，而不是只增加数字；
- 世界和重要人物会在玩家不在场时继续有后果；
- 世界内部会反馈主角的地位、责任和关系变化；
- 当前 cohort 中的关系反转和阶层跃迁真实发生；
- 进入更大世界时保留已挣得成果，并面对新的相对压力。

这些体验可以由不同世界的不同机制实现。宇宙规则不得固定要求每个世界都有怪物、
战斗、掉落、等级、经验、货币、商店、合成、基地、载具、装备、建筑、学院、排行榜、
其他玩家、三选一、固定 loot→currency→upgrade、固定地点拓扑、昼夜或经济结构。
具体世界可以拥有 feature-local 常量；禁止的是把某一世界的接口升级为 Genesis 默认。

因此每个正式体验都必须同时可理解、可积累、可超越：玩家能学会世界如何回应，能把
已经挣得的成果带到下一次转化，并能在真实新压力下超越原先的相对位置。

## 3. 主角非对称杠杆

每个正式世界必须给主角一种与关键因果链绑定、普通人难以复制的杠杆。它至少改变一项：

- 输入到结果的转化；
- 合法行动或可达策略；
- 风险—收益关系或机会质量；
- 成长速度、组合能力或规则影响范围。

主角不自动成功。正确理解和行动才会把杠杆转化为更高、更持久、能够继续复利的结果。
移除杠杆后，最优策略、长期成长轨迹或资源/机会成本必须发生可验证变化。

不得把万能感知、无条件幸运、固定攻击倍率、临时救场、凭空奖励或 Narrator 改结果
当作默认杠杆。幸运可以改变高价值机会的分布，但不能替代判断；能力可以来自角色、
工具、关系、组织或环境，但必须在当前世界中有真实因果和边界。

杠杆的强度应体现在可重复的转化差异：同一机会对普通人和主角的可见性、可执行性、
风险承受力或后续组合不同。它不能只在一段旁白中显得神奇，也不能在失败后被悄悄
改写。主角可以失败、受伤、欠债、失去相对排名；但正确决策仍应让优势有机会继续
复利。

### 3.1 杠杆的检验

设计主角能力时，至少说明它改变了哪条因果链、主角需要付出什么、普通人为什么难以
复制、失败怎样发生、玩家怎样学会更好地使用它。好的杠杆可以改变输入、行动资格、
机会筛选、风险承担、组合顺序或影响范围；它不必是超能力，也不必由主角身体单独拥有。

以下都不是充分证明：一段“主角很特殊”的旁白；统一的隐藏信息扫描；无条件的好运；
只提高攻击、掉落或经验的倍率；危急时刻的临时救场；Narrator 说结果已经发生。若
移除能力后玩家仍采用同一最优计划，能力只是装饰或数值奖励。

## 4. 可积累与复利

积累不只是数值保存。能力、知识、资产、工具、关系、声誉、身份、组织、生产能力或
规则影响力等已挣得成果，应提高后续行动效率、机会质量、风险承受力、影响范围或策略
组合。它们是可能载体，不是固定系统清单。

```text
earned result
→ improves later conversion capacity
→ opens a previously unavailable or impractical strategy
```

如果成长只能回答“数字变大了吗”，不能回答“以前不可能的计划现在是否成立”，它就
没有表达核心爽感。解决低层问题后，系统应释放玩家时间，让稀缺性转移到更高层的机会、
责任、关系、维护和战略冲突，而不是强迫玩家永久重复同一种劳动。

可积累成果也不等于不能失去一切：伤势、盗窃、破产、政治变化和明确的永久牺牲都可以
发生。关键是损失必须有世界内来源、玩家可追溯的因果和可重放的历史；系统不能把“曾经
挣得的东西”无因抹掉，也不能为了新一幕偷偷把主角重置成陌生人。

### 4.1 积累的载体

可积累的成果可以是能力、知识、资产、工具、关系、声誉、身份、组织、生产能力、空间
或规则影响力。它们不必全部同时存在，也不应被强行归入一个等级字段。重要的是成果
改变后续转化：更少时间完成同一工作、能承担新的风险、能接触新的机会、能联合更多
资源、能影响更多人，或能把一个过去不实际的计划变成可行计划。

长期资产也可以带来维护、责任、注意力、能源、工资、政治和关系成本。成本的作用是
保持决策空间，而不是惩罚成长；它应让玩家权衡“把控制力投入哪里”，而不是把所有
积累都变成被动收益。

## 5. 关系反转与阶层跃迁

成长必须在世界内部得到证明，而不是由旁白宣布。抽象关系变化包括：

- 从被威胁者变成利用或管理威胁的人；
- 从依赖供给者变成生产或分配者；
- 从被评价者变成能够制定条件的人；
- 从规则服从者变成能够利用、解释或影响规则的人。

`Absolute Power` 是已经挣得的长期策略容量；`Effective Capacity` 是当前受资源、
位置、伤势、维护或政治条件限制的可用能力；`Relative Standing` 是主角相对于真实、
稳定 cohort 的当前位置。Relative Standing 可以回撤；Absolute Power 不得被系统无因
清零或追溯改写。永久损失可以发生，但必须来自明确的世界因果，且保留可验证历史。

阶层跃迁不是偷偷削弱主角后重新刷数字。新的压力来自更大的世界、更强的竞争者、新
责任和更复杂的约束；旧成果成为新层级的起点，而非被抹掉的假成长。

## 6. 有意义的选择、稀缺与机会成本

“有意义的选择必须产生真实机会成本”，而不是“每次选择必须永久放弃一切”。时间、
地点、风险、供给、知识、身份、关系、生产能力和机会窗口都可以形成约束。多数选择
允许阶段性成本和不同顺序；玩家以后可以完成延后的目标。永久关闭只能来自明确、可追溯
的世界原因。

稀缺是可访问供给、获取速度、时间、地点、风险、知识、身份和生产能力相对于并发需求
形成的约束；它不等于单用途、唯一、只能获得一次、来源必然永久关闭，或每次使用都
删除另一条路线。

局部人物、地点和机会可以不可逆消失，但长期成长总体应扩大可行策略和控制范围，不得
让每次选择持续压缩整个世界。选择应改变其他选择的成本、时机或风险，才能让“我决定
这么做”拥有重量。

有效机会成本可以是错过窗口、暴露身份、消耗维护能力、改变关系、承担债务或延迟另一
个目标；不要求每次都永久二选一。一个健康的成长循环允许玩家暂时不能同时拥有全部
成果，但通过继续行动仍可能获得更多选择。永久互斥是世界原因的结果，不是系统为了
制造戏剧而默认的经济模型。

### 6.1 选择的尺度

选择可以在不同时间尺度成立：一次危险判断、几回合的资源安排、数天的承诺、长期的
组织和身份。它们不必造成相同强度的损失，但都应改变至少一个后续条件。短期顺序差异
可以与长期可逆性并存；真正的永久后果应让玩家能追溯“哪一个行动关闭了哪一条路”，
而不是在结算时随机删除内容。

稀缺的价值来自代价和约束，不来自稀有度颜色。重复获得的资源仍可稀缺：获取速度、
地点、窗口、风险、资格或生产能力可能限制即时使用。可重复并不等于无限供应，可逆也
不等于无成本。

## 7. 世界继续运行，信息有边界

时间不是背景；玩家花掉的时间也给世界行动权。重要人物和已经物化、拥有真实规则的
过程可以在玩家视线外继续推进，玩家应偶尔发现“这件事发生时我根本不在场”。尚未
物化的远方内容不能被假称为已经完整模拟；它只有在合法触发、验证并成为世界事实后
才能产生后果。

World Truth 不等于 Actor Knowledge，也不等于 Player Observation。秘密、误解、调查、
欺骗和信息优势必须尊重角色能合理知道的事实。玩家不是世界中心，但应能成为重要变量；
NPC 有自己的目标、资源、关系、恐惧和计划，不是等待玩家触发的背景板。

远方内容可以有宏观锚点和约束而暂未细化；当它被合法触发时，必须先成为经过验证的
候选内容，再成为新的世界事实。这样既避免为开局预写整个宇宙，也避免把“尚未生成”
说成“离屏一直完整模拟”。物化不能迎合玩家当下的答案，不能追溯修改父世界的既有事实。

世界真实性不要求每个路人都独立模拟。重要人物应保留持久身份、目标和选择；背景人口
可以聚合，只要聚合层仍产生可解释的供给、竞争、关系或事件结果。离屏推进必须遵循
已经成立的规则，不能因为玩家暂时看不见就改用剧情方便的答案。

信息本身也是资源：一条事实应当能够改变优先级、风险判断、关系信任、交易条件或路线
选择。不同世界可以给予精确数值、模糊风险或近乎无 HUD 的信息体验，但都应让玩家知道
自己知道什么、为何知道、还不知道什么。

## 8. 结构多样性，拒绝换皮

不同 World Prompt 必须能够产生不同的：

- 玩家主要决策问题；
- 主角杠杆；
- 核心因果结构；
- 风险与机会模型；
- 成长和控制力路径；
- 社会或世界反馈。

只替换名称、标签、资源名、数值或 prose 不算独特。固定的基地—搜寻—战斗—撤离—升级
循环也不能伪装成通用答案。若当前运行语义不支持某个核心机制，诚实的结果是阻断或
明确降级，不能由 Blueprint prose、Acknowledgement 或 LLM 临场发明行动和后果来掩盖。

抽象必须被真实需求挣出来：先做一个具体 slice，再做结构不同的第二个 slice，观察
重复的因果结构，最后提取最小公共规律。不要为了未来可能存在的世界预建万能框架。

世界可以在局部采用简单方案；简单不应被写成永远唯一的宇宙规则。一个 feature 的
名称、参数和界面属于它自己的因果合同；只有多个真实、结构不同的世界证明相同因果
边界后，才有理由把它提升为共享语言。即使名称完全配置化，若玩家的主要决定、风险
循环和成长路径永远相同，仍然是换皮。

## 9. 关系、承诺与玩家自由

关系是双方状态和博弈，不是好感度条或伴侣奖励。信任、利益、依赖、债务、恐惧、秘密、
承诺和背叛成本都可能重要；NPC 保留自主意愿。成人亲密内容必须有明确成年事实，不能
由文本推断；行动可执行不等于自愿、同意、爱或道德正确。Narrator 不能创造、洗白或
抹除关系事实。

玩家可以提出任何合理行动，但自由度不等于无限制：世界必须按统一规则判断可能性、
时间、资源、风险、冲突和后果。自由输入不能把 prose 直接变成成功结果。

承诺也是行动的后果：帮助某人、加入组织、签订交易、公开站队、承担任务或接受身份，
都可以占用时间、消耗资源、改变关系、产生 deadline、创造责任或关闭路线。没有约束力
的承诺只是对白；违约也必须有真实后果。关系不能退化为“好感达到阈值就成功”，双方
都有目标、知识、压力、拒绝和退出能力。

涉及成人亲密内容时，成年事实必须明确且不可由 Narrator 或自由文本推断；行动可执行
不等于同意、爱、原谅或道德正确。任何关系反转都应由双方状态和世界事件证明，而不是
用浪漫措辞洗掉过去的压力、交易或伤害。

## 10. 节奏、好奇心与长期爽感

低潮、准备、观察、恢复和小投资让高潮有重量；平静不等于世界停止。好奇心应形成
“发现→新问题→局部答案→更大问题”，并连接生存、资源、人物、能力和成长，而非只
堆 lore。长期爽感在多个时间尺度上递进：当下判断、短期瓶颈、稳定优势、关系/组织
影响，再到阶层跃迁和更大世界。

Autoplay 是设计体检，不只是 crash 检查：它应暴露无限资源、固定最优策略、成长停滞、
NPC 停滞、策略坍缩、世界换皮和重复劳动。指标是观察工具，不是直接改写世界状态的
目标值。

长期观察应同时关注短期选择、中期资源瓶颈、关系/组织反馈和层级跃迁。好的长周期玩法
会改变“什么值得花时间”：旧问题变得廉价或自动化，新问题带来新的风险和责任。更换
世界后，Autoplay 不应只把同一循环换成另一组名词；不同主角杠杆也不应只造成数值高低
而没有决策差异。

## 11. 设计警报

以下方向与宪法冲突：伪选择；纯数值成长；万能感知；NPC 只在玩家出现时存在；LLM
上帝模式；无代价自由；世界自动等待；Prompt 修补 Engine 问题；玩家或 NPC 全知；
解决旧问题后仍强迫重复劳动；不同题材却同一最优策略；为了一个需求提前建立万能框架。

## 12. 最小检查

每个新 Feature 或世界问题都回答：

1. 玩家现在面对什么控制缺口？
2. 哪条规则可理解且会改变决定？
3. 主角杠杆改变了什么转化或策略？
4. 已得成果如何复利并扩大策略空间？
5. 选择产生什么真实机会成本，之后是否仍可有意义地扩展？
6. 世界、NPC、知识边界和叙事如何反馈？
7. 换一个结构不同的世界后，它仍是体验原则而非接口假设吗？

若不能回答，先缩小设计，不要用更多文本或更大的抽象掩盖缺口。

### 12.1 设计评审的证据语言

评审可以使用“控制缺口、规则清晰度、杠杆、复利、机会成本、关系反转、策略空间、
世界反馈”这些体验词，但不能用一段 prose 代替因果证据。一个声明越接近长期成长、
社会地位或世界扩张，就越需要玩家可观察的后果和一致的历史；没有证据时应缩小声明，
而不是把未来愿景写成当前能力。

### 12.2 复盘问题

实现或审查结束时，再问一次：玩家是否感到控制缺口被真实解决？规则是否让失败可学习？
主角杠杆是否带来普通人没有的转化？成果是否提高了后续能力而不是只改变数字？选择
是否产生了可解释的机会成本？世界和人物是否在玩家离开时仍有自己的因果？新的世界
结构是否真的改变了玩家要解决的问题？如果答案只存在于说明文字而不存在于经历中，
就应降低承诺或重做规则。

## 13. 宣言

我们不是在做一个会写小说的聊天机器人，而是在做一个会留下历史的世界。玩家拥有
有限时间、资源、信息和能力；世界不会为玩家暂停；理解规则、承担代价并善用非对称
杠杆，才会产生能够复利的控制感。LLM 描写已发生的复杂经历，不能替玩家制造胜利。

最终的玩家感受是：

> 我曾经失去控制，但我看懂了规则；我用自己的判断挣得了成果；现在的我能做以前
> 做不到的事，也能带着这些成果进入一个更大的世界。
