## 基础篇幅稳定，临界状态主动展开

- Sources: `book-01-bcc78727 · segment-0124 · 行 9627-10152`；`book-01-bcc78727 · segment-0177 · 行 25728-26349`；`book-01-bcc78727 · segment-0374 · 行 77420-77649`
- Observation: 379 个检测片段的字符中位数约 8,402；常规段多围绕一个片段，关键比赛、献祭和神战扩展到相邻片段。
- Mechanism: 篇幅增加集中在规则、关系、生死或底牌发生不可逆变化之处。
- Transferable principle: 普通段只承载一个主要目标和状态变化；只有不可逆变化才扩写。
- Controls: 目标数；反转数；不可逆状态；下一门槛。
- Risks: 索引字符数不是出版社章字数，不能机械套用。
- Confidence: medium-high

## 一个核心问题承载多次有效反转

- Sources: `book-01-bcc78727 · segment-0136 · 行 13209-13702`；`book-01-bcc78727 · segment-0368 · 行 76206-76351`；`segment-0369 · 行 76352-76444`；`book-01-bcc78727 · segment-0375 · 行 77650-77835`；`segment-0376 · 行 77836-77942`
- Observation: 高密度段围绕一个胜负/复活问题并行处理控制、资源、军队或神魂层级。
- Mechanism: 每次反转都改变胜率、资源或关系，因而密度高但仍有中心。
- Transferable principle: 同场并行线不超过三条，并共享同一资源、倒计时或核心问题。
- Controls: 每次反转前后记录状态差；无状态变化的技能段压缩。
- Risks: 只增加事件数量会稀释焦点。
- Confidence: high

## “高压—照护/复盘—新门槛”循环

- Sources: `book-01-bcc78727 · segment-0177 · 行 26138-26274`；`book-01-bcc78727 · segment-0215 · 行 38564-38851`；`book-01-bcc78727 · segment-0247 · 行 48030-48109`；`book-01-bcc78727 · segment-0307 · 行 62704-63077`
- Observation: 刺杀后诊断、杀戮后礼仪训练、献祭后照护、神考之间休整，均把上场后果转成下一场目标。
- Mechanism: 喘息不是无事件区，而是伤势、情绪和规则的转换器。
- Transferable principle: 连续两到三个高压片段后插入恢复或关系确认，并让它产生下一门槛。
- Controls: 高压段数；恢复长度 0.5-1 个基础单元；必须更新伤势/承诺/计划。
- Risks: 纯闲聊不更新状态，只会拖慢节奏。
- Confidence: high

## 压缩重复成长，展开状态重逢与代价选择

- Sources: `book-01-bcc78727 · segment-0060 · 行 3573-3634`；`book-01-bcc78727 · segment-0222 · 行 40810-41101`；`book-01-bcc78727 · segment-0309 · 行 63270-63477`
- Observation: 多年训练被快速跨过，重聚、献祭、复活和终局选择获得显著篇幅。
- Mechanism: 读者需要知道成长结果，但更需要亲眼看见关系如何适应新状态。
- Transferable principle: 训练只保留第一次、失败转折和最终验证；重复过程用结果矩阵压缩。
- Controls: 压缩跨度；跳跃后的差异清单；第一场冲突。
- Risks: 时间跳跃若不更新年龄和状态，会制造连续性漏洞。
- Confidence: high

## 钩子落在“状态已变、方案未完”

- Sources: `book-01-bcc78727 · segment-0277 · 行 55838-56255`；`book-01-bcc78727 · segment-0374 · 行 77420-77649`；`book-01-bcc78727 · segment-0376 · 行 77904-77942`
- Observation: 新考核、牺牲、死亡、身体复活但神魂未归、最后条件，都是已发生变化与未完成方案的组合。
- Mechanism: 读者既获得进展，又清楚知道下一步必须解决什么。
- Transferable principle: 章节结尾先改变一个状态，再留下一个具体未完成动作。
- Controls: 状态变化；剩余门槛；倒计时；谁承担下一步。
- Risks: 只停在敌人出现或普通胜负，缺少因果拉力。
- Confidence: high

## 张力是多峰楼梯，不是单线爬升

- Sources: `book-01-bcc78727 · segment-0208 · 行 36222-36555`；`segment-0212 · 行 37340-37617`；`book-01-bcc78727 · segment-0222 · 行 40810-41101`；`segment-0223 · 行 41102-41423`；`book-01-bcc78727 · segment-0374 · 行 77420-77649`；`segment-0375 · 行 77650-77835`；`segment-0376 · 行 77836-78061`
- Observation: 个人试炼、团队危机、杀戮、重聚/照护、海岛考核、战争和神战构成多次上升与短降；海神陨落是谷底后的再抬升。
- Mechanism: 短降让前一峰的代价可见，也为下一峰重新定价。
- Transferable principle: 大高潮前保留一次可感知失败；高潮后再安排道德/制度选择作为尾波。
- Controls: 相对张力可粗分 1-5；每次升档必须扩大损失范围或缩短选择窗口。
- Risks: 该曲线是比较工具，不是精确情绪测量。
- Confidence: medium-high

## 规模放大时保持同一情感锚点

- Sources: `book-01-bcc78727 · segment-0025 · 行 1437-1508`；`book-01-bcc78727 · segment-0229 · 行 42892-43127`；`book-01-bcc78727 · segment-0325 · 行 66874-67289`；`book-01-bcc78727 · segment-0379 · 行 78586-78644`
- Observation: 舞台从宿舍扩到团队、宗门、帝国、军队和神界，核心仍被翻译回保护谁、是否滥杀和能否共同生活。
- Mechanism: 熟悉的关系问题为不断增长的规模提供稳定尺度。
- Transferable principle: 每扩一层世界规模，都把新目标回译成一个已建立人物的具体风险。
- Controls: 每个宏观弧明确一个情感锚点和一个公共后果。
- Risks: 战争只剩地图和数字时，早期人物承诺会被抽空。
- Confidence: high

## 节奏控制面板

| 控制项 | 建议 |
|---|---|
| 基础单元 | 一个主要目标、一个状态变化；不可逆转折才扩写到相邻单元。 |
| 段内节拍 | 目标/规则 → 首次受挫 → 战术选择 → 第二次逆转 → 代价/新门槛。 |
| 并行线 | 同场最多三条，必须共享资源、倒计时或核心问题。 |
| 喘息 | 连续高压后用 0.5-1 个单元恢复、复盘或确认关系；必须产生下一目标。 |
| 时间压缩 | 压缩重复训练，展开重聚、生死、身份与代价选择。 |
| 信息释放 | 异常先出现，危机中兑现，战后只补当前所需机制。 |
| 悬崖 | 优先“状态已改变、方案未完成”。 |
| POV | 默认主角近距；只为信息差或外部代价短暂外扩。 |
| 终局尾波 | 动作高潮之后必须有战争、权力、武器或共同生活的选择。 |
