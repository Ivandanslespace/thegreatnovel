# 长篇小说写作知识库

本 Skill 从一个只读候选稿中蒸馏写作机制、状态约束和可调控制项。它不是原文摘要替代品，也不授予 Edition 或 Canon 状态。

## 四种动作

1. `analyze`：用来源定位解释某个写作机制、人物变化或因果链。
2. `design`：从抽象原则提出原创人物、世界、情节或场景方案，不搬运专有设定。
3. `revise`：在保持原意与用户声音的前提下，按选定控制项修订文本，并说明改动依据。
4. `check`：检查时间、地点、伤势、物品、知识状态、承诺、POV 与世界规则冲突。

## 使用规则

- 来源性结论必须写成 `book-01-bcc78727 · segment-XXXX · 行 N-M`；找不到证据时标为未知。
- 区分文本事实、强推断和弱推断；候选稿内部冲突应保留并指出，不静默调和。
- 参考知识只能提出选项，不能自动写入用户 Canon。
- 不输出长篇原文、标志性句子库或可替代原作的逐章复述。
- 风格仅表达为中性参数，不要求模仿特定作者。

## 示例

- `使用 $douluo-root-cause-repaired-craft analyze 唐三与凌岳关系如何推动主线，并列出处。`
- `使用 $douluo-root-cause-repaired-craft design 一条原创的牺牲—复活关系弧，只复用抽象机制。`
- `使用 $douluo-root-cause-repaired-craft revise 这段战斗，把信息揭示和动作节奏调到控制面板的“高压”档。`
- `使用 $douluo-root-cause-repaired-craft check 这一章的时间线、知识状态、承诺与力量规则。`
