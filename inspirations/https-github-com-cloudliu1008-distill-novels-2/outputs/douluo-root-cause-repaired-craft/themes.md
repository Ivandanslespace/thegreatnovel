# 主题问题

完整取证见 [characters-themes.md](books/book-01-bcc78727/evidence/characters-themes.md)。以下是文本中由不同角色行动形成的竞争性答案，不是对作者意图的断言。

## 人由出身、身体、灵魂，还是被选择的关系定义？

- Sources: `book-01-bcc78727 · segment-0203 · 行 34560-34640`；`book-01-bcc78727 · segment-0247 · 行 47892-47930`；`book-01-bcc78727 · segment-0318 · 行 65258-65372`
- Competing answers: 机构用物种、血统和天赋分类；伴侣与团队承认事实身份，却用持续站队确认“关系身份”；多次身体/灵魂分离说明身份也不能脱离记忆和选择。
- Plot test: 身份揭示触发捕获战，复活过程把抽象问题变成身体状态机。
- Motifs: 森林、魂骨、红光、戒指。
- Transferable principle: 让身份定义在一次高成本站队中被检验。
- Confidence: high

## 力量应服务于征服、自由，还是保护？

- Sources: `book-01-bcc78727 · segment-0100 · 行 6083-6138`；`book-01-bcc78727 · segment-0310 · 行 63540-63608`；`book-01-bcc78727 · segment-0379 · 行 78588-78630`
- Competing answers: 比比宸把力量组织成帝国；弗兰德和唐三把不受机构支配视为自由；唐三、唐昊和团队把力量用于保护，却也被保护责任推向独自承担。
- Plot test: 同一种高级力量既能建立统治，也能被主动限制、销毁或退出。
- Motifs: 王冠、教皇殿、战场、被回收的武器。
- Transferable principle: 终局不仅问角色是否获胜，也问他愿意放弃哪一种力量用途。
- Confidence: high

## 压力使人成长，还是让创伤重演？

- Sources: `book-01-bcc78727 · segment-0003 · 行 119-175`；`book-01-bcc78727 · segment-0279 · 行 56516-56618`；`book-01-bcc78727 · segment-0299 · 行 61142-61208`
- Competing answers: 锻造、阶梯和考核把压力变成技能；森林幻境又把同类刺激转成复仇和失控；导师的责任是同时设计压力与恢复边界。
- Plot test: 同一角色在训练与创伤触发中对压力作出不同反应。
- Motifs: 铁锤、阶梯、幻境森林、魔纹。
- Transferable principle: 压力场景必须同时追踪能力收益和心理/身体损耗。
- Confidence: high

## 牺牲证明爱，还是制造新的债务？

- Sources: `book-01-bcc78727 · segment-0246 · 行 47676-47732`；`book-01-bcc78727 · segment-0318 · 行 65220-65278`；`book-01-bcc78727 · segment-0375 · 行 77652-77670`；`book-01-bcc78727 · segment-0376 · 行 77868-77940`
- Competing answers: 献祭确认关系，却让幸存者背负复仇、照料和自我剥离；团队复活把代价扩展到共同体；战后限制武器试图终止牺牲循环。
- Plot test: 每次复活都保留身体、能力或责任后果。
- Motifs: 魂环、魂骨、心脏、信仰光、戒指。
- Transferable principle: 牺牲之后必须给牺牲者和幸存者重新选择旧承诺的机会。
- Confidence: high

## 仁慈与复仇如何在同一个人身上共存？

- Sources: `book-01-bcc78727 · segment-0171 · 行 24380-24466`；`book-01-bcc78727 · segment-0299 · 行 61172-61208`；`book-01-bcc78727 · segment-0379 · 行 78544-78630`
- Competing answers: 唐三用伤害控制和投降规则为暴力划边界，又会在创伤触发时释放杀意；比比宸把受害转成制度性报复；结尾保留敌人后代生命但不取消责任判断。
- Plot test: 仁慈必须改变攻击对象、俘虏处理或战后制度，而不是停留在性格标签。
- Motifs: 神光、怨念、毒、海水。
- Transferable principle: 同一角色的“不可杀清单”和“必须追责清单”都要可见，并允许冲突。
- Confidence: high

## 家庭是血缘继承，还是选择形成的照料网络？

- Sources: `book-01-bcc78727 · segment-0059 · 行 3495-3572`；`book-01-bcc78727 · segment-0261 · 行 51904-51932`；`book-01-bcc78727 · segment-0379 · 行 78526-78644`
- Competing answers: 血缘留下责任和愧疚，却不自动产生照料；伴侣、团队和父亲式导师通过长期行动取得家庭功能；知识和行动边界又被交给下一代。
- Plot test: 角色在危险、订婚、复活和退场中反复选择谁属于“我们”。
- Motifs: 铁匠铺、蓝银草叶、戒指、师徒称谓、婚礼。
- Transferable principle: 用持续照料和权利义务定义家庭，不只用称谓或血缘揭示。
- Confidence: high

## 复活之后，旧承诺仍然有效吗？

- Sources: `book-01-bcc78727 · segment-0247 · 行 47892-48042`；`book-01-bcc78727 · segment-0318 · 行 65258-65372`；`book-01-bcc78727 · segment-0376 · 行 77888-78056`；`book-01-bcc78727 · segment-0379 · 行 78614-78644`
- Competing answers: 身体恢复不等于灵魂、能力和身份恢复；亲密关系必须重新确认是否共同赴战；共同体参与复活又让第二次生命带上公共责任。
- Plot test: 复活门槛按身体、神魂、关系和社会角色逐层通过，战后退隐成为另一种履约。
- Motifs: 心脏、神魂、红蓝光、戒指、婚礼。
- Transferable principle: 把“复活后第一次拒绝/同意”写成真正的关系重启点。
- Confidence: high
