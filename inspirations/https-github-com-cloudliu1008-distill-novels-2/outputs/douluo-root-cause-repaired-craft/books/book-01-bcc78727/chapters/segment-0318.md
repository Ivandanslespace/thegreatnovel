# segment-0318｜完整复活与代价回收

- Source: `book-01-bcc78727 · segment-0318 · 行 65168-65399`
- 章节标题：第二百六十五章 复活吧，我的爱人
- 代表维度：人物、情节、主题、连续性、节奏

## 本段前状态

凌岳已有身体但灵魂不完整；唐三已经达到执行复活所需的高阶条件，并把原有魂环、魂骨与神力接口准备到位。此前的订婚确认了关系，但不能替代身体和灵魂门槛。

## 因果链

1. 唐三先确认自身状态、场地与凌岳身体位置，把仪式建立在可控条件上。
2. 他按顺序处理原属凌岳的魂环、魂骨和灵魂回归，不把多个资源变化写成一个模糊光效。
3. 归还过程对唐三造成剥离和身体损耗，使复活保留真实成本。
4. 海神之光完成灵魂与身体融合，关系从单向照料恢复为双方可回应状态。
5. 凌岳复活后，唐三立即把恢复承诺扩展到唐昊残肢和阿岚人形，私人奇迹生成新的家庭义务。

## 本段后状态

- 凌岳进入“灵魂与身体完整融合”的状态，恢复行动与关系选择能力。
- 唐三承担资源剥离和身体损伤，不能视为无损施术。
- 复活机制完成一次长线回收，同时开启父母修复的后续任务。
- 订婚仍有效，但婚礼与长期共同生活尚未在本段执行。

## 可复用观察

- **高潮清晰度**：把复杂仪式拆成条件、顺序、反馈与代价，让情绪不取代规则。
- **关系回收**：复活的关键不是外观恢复，而是对方重新获得回应与选择能力。
- **代价延续**：施救者的损伤把前弧的牺牲重量带入后续，而非结算后归零。
- **义务扩散**：一次成功会让其他关系提出合理期待，防止“奇迹只服务主角恋爱”。

## 未决与风险

- 复活依赖凌岳特有的献祭、环骨、仙草与神力历史链，不是通用规则。
- 唐三伤势的恢复时间与残留影响需在后文继续登记。
- “完整融合”指当前身体—灵魂状态，不自动回答神位、寿命和战后生活问题。
