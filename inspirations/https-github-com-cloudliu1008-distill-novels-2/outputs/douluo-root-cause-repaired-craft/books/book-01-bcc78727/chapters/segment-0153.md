# segment-0153｜分离后的关系修复与沟通协议

- Source: `book-01-bcc78727 · segment-0153 · 行 18385-18690`
- 章节标题：第六十九章 凌岳：发誓不要离开我
- 代表维度：人物、对话、主题、节奏、连续性

## 本段前状态

唐三离开约半年，凌岳没有获得充分的去向与回归信息。两人长期相伴形成的安全感被突然分离打断；唐三同时带回新的知识、盟友关系和仙草资源。

## 因果链

1. 重逢先通过拥抱、呼吸和身体距离释放累积情绪，而不是立即解释全部经历。
2. 凌岳明确指出伤害来源不是“允许离开”，而是只能从他人的沉默中猜测唐三是否安全。
3. 唐三承诺提前说明任务、回来后补足信息；凌岳也撤回以死亡担保关系的方式，改为报告自己的选择。
4. 双方确认亲密接触的许可，再回到公开场合和团队任务。
5. 同段后部由唐三分配带回的仙草，私人归来转成全队资源升级。

## 本段后状态

- 关系从模糊的“不离开”升级为可执行协议：可因任务分开，但必须告知、回报并保留对方选择权。
- 公开与私下亲密边界得到重新确认。
- 唐三的个人收获进入团队资源分配，重聚同时推动集体成长。

## 可复用观察

- **冲突修复**：把抽象抱怨改写成可观察行为和下一次可执行要求。
- **同意机制**：请求、点头、动作和场合转换共同建立许可，不用旁白替角色决定。
- **关系—情节接口**：沟通协议可在后续任务、牺牲和救援中接受实际检验。
- **节奏**：先展开不可替代的重逢，再压缩团队近况和资源说明。

## 未决与风险

- 凌岳听到独孤博时出现明显不安，本段没有充分解释来源。
- 一次承诺不能自动解决双方“独自承担代价”的长期倾向。
- 标题中的绝对化誓言已被正文中的双向协议细化，续写应服从正文状态而非只服从标题。
