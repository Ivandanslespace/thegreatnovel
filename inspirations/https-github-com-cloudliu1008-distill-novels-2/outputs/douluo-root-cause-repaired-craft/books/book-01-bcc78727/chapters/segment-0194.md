# segment-0194｜竞技线转入政治冲突

- Source: `book-01-bcc78727 · segment-0194 · 行 31296-31539`
- 章节标题：第一百一十八章 总决赛，武魂城
- 代表维度：世界、情节、叙事、节奏、连续性

## 本段前状态

预选阶段已经结束，参赛者仍可把总决赛理解为更高等级的学院竞技。帝国、武魂殿和学院之间的政治张力存在，但尚未直接改写比赛路程。

## 因果链

1. 总决赛地点被改到武魂殿主城，主办权与空间控制权集中到同一势力。
2. 帝国派出代表、护送军队和多支学院，竞技移动同时成为外交与军事行动。
3. 行军路径在有利于伏击的地形中受阻，普通盗匪外观迅速被有组织协同和大量高阶魂师推翻。
4. 学院队伍擅长小规模比赛，却被群体围攻和战场配合打乱；导师因此把目标从表现转为节省资源、击溃袭击者。

## 本段后状态

- 总决赛不再是封闭赛场事件，而是权力中心主动布置的风险空间。
- 参赛者第一次面对接近战争的数量、阵型和护送责任。
- 敌方组织身份仍未在本段完全揭开，但资源规模已经排除“普通盗匪”的解释。

## 可复用观察

- **尺度升级**：先改变空间所有权，再改变敌人数量和协同方式，升级才具有因果基础。
- **类型转场**：用角色原有技能在新规模下失效，完成竞技故事向政治冲突的转换。
- **信息差**：读者与导师从异常配置推断幕后势力，悬念来自证据累积而非无提示突袭。
- **连续性**：护送人数、队伍数量、地形和魂力消耗都应进入后续战斗账本。

## 未决与风险

- 袭击者的具体命令链和最终目标在本段仍属推断。
- 比赛规则不能直接套用到伏击；伤害边界、撤退条件和保护对象已变化。
- 大规模战斗若继续只列技能而不追踪阵型和资源，会失去空间方向感。
