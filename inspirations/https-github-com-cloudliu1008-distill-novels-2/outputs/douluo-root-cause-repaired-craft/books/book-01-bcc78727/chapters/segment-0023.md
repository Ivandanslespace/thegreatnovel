# segment-0023｜学院微型权力结构与初次关系试探

- Source: `book-01-bcc78727 · segment-0023 · 行 1305-1372`
- 章节标题：第六章 我叫凌岳，山岳的岳（一）
- 代表维度：世界、人物、情节、对话、连续性

## 本段前状态

唐三刚以能力取得七舍名义上的首位，却把入学目标理解为学习，不愿主动争夺领导身份。工读生群体已经受欺压，但责任结构尚未被他接受。

## 因果链

1. 王圣用伤痕说明“老大”不是荣誉，而是替弱者出头的义务。
2. 宿舍规则把力量排名转成资源保护和集体责任，迫使唐三重新理解胜负后果。
3. 凌岳进入同一规则空间，双方以比试确认资格。
4. 唐三预设了可控、低伤害的取胜脚本；凌岳用身体结构和借力反制，使他的判断第一次失效。

## 本段后状态

- 唐三知道学院底层存在一套由暴力和保护责任共同维持的微型秩序。
- 凌岳不再只是新室友，而是能打破主角既有预测的可信对手。
- 双方地位与关系仍在形成，本段只完成“重新估价”，没有完成最终结盟。

## 可复用观察

- **权力具象化**：用伤痕、床位、保护义务说明地位，而不是旁白宣布谁有威望。
- **初遇设计**：让新角色破坏主角最擅长的预测，可迅速建立独立能动性。
- **战斗信息**：动作的价值在于改变判断和关系，不在于招式数量。
- **对话功能**：王圣的说明直接改变唐三对职位的理解，因此设定信息也是场景事件。

## 未决与风险

- 凌岳的完整能力、动机和身份尚未揭示。
- 不能把后续伴侣关系倒灌成本段事实；此时可靠结论仅是竞争与关注形成。
- 宿舍规则是地方性制度，不能自动推广为整个学院或世界的正式法律。
