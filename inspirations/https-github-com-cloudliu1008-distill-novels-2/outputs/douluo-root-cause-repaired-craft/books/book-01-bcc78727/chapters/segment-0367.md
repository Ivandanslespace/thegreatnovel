# segment-0367｜战争线与神级力量线汇聚

- Source: `book-01-bcc78727 · segment-0367 · 行 75848-76205`
- 章节标题：第三百二十二章 嘉陵关，双神降临
- 代表维度：世界、情节、叙事、战斗、节奏

## 本段前状态

嘉陵关经过一个月修复，武魂帝国依靠守城与供奉维持局势，并等待天使神传承者。唐三一方也已取得海神力量，军队战争即将被神级个体改写。

## 因果链

1. 天使神以公开可见的光与神装抵达，先改变守军信心和权力中心，再进入战斗。
2. 双方神级身份由军队共同见证，个人力量立即拥有战略与政治后果。
3. 唐三与千仞霄首次正面对撞，神器、神装、太阳和海洋信仰分别成为力量接口。
4. 一次全力攻击未能按预期破坏对方装备，唐三修正对敌方防御机制的判断。
5. 双方都需要回力并重新连接环境资源，战斗因此仍有窗口、成本和信息更新，而非无限输出。

## 本段后状态

- 嘉陵关战局从军队攻防转成神级决斗，但军心、城防和环境仍是后果承受者。
- 唐三确认对方神装可集中防御，原先的破坏预期被下调。
- 千仞霄暴露太阳依赖，唐三则建立海洋信仰/神力汇聚，下一轮对抗获得明确资源方向。

## 可复用观察

- **尺度可读性**：先写力量如何改变群众判断，再写个体对撞，宏大场景就有社会锚点。
- **神战规则化**：神器完整度、环境供能、回力窗口和错误预期继续约束最高级战力。
- **内心说明**：只解释读者理解下一选择所需的资源与判断，不提前公布全套计划。
- **状态推进**：一次碰撞至少改变装备判断、剩余能量、空间位置和双方情绪中的一项。

## 未决与风险

- 本段没有结算整个嘉陵关战争，只完成双神公开与第一轮测量。
- 视觉规模不能替代军队伤亡、城防与补给状态的后续追踪。
- 神力环境依赖若在后续突然消失，需要明确解释场域变化。
