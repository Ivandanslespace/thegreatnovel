# segment-0230｜森林死战中的协作、成本与失控变量

- Source: `book-01-bcc78727 · segment-0230 · 行 43128-43399`
- 章节标题：第一百六十章 森林死战
- 代表维度：人物、情节、战斗、节奏、连续性

## 本段前状态

唐三带着凌岳逃离武魂殿追兵。两人等级低于多名追击魂圣，速度也不足以直接脱离；目标不是击败全部敌人，而是消除最能持续追踪的敏攻力量。

## 因果链

1. 唐三先用精神探测、森林地形与蓝银草评估追击扇面，把“逃跑”拆成可解决的速度问题。
2. 他利用寄生控制、隐藏武器、毒与短窗口逐个削减敏攻者，同时承受魂力抽空、内伤和暴露底牌的成本。
3. 凌岳用突进、锁定、短时防护和位置交换补足唐三的控制间隙，二人把早期组合默契转成明确分工。
4. 四名敏攻者被解决后，意外出现的人面魔蛛迫使他们再次消耗并拖慢速度。
5. 追兵主力完成包围，局部战术成功反而抵达更坏的战略状态。

## 本段后状态

- 敌方高速追击能力大幅下降，但唐三已重伤、资源消耗严重，凌岳也进入高风险承伤位置。
- 蓝狮组合证明可越级解题，却无法控制所有环境变量。
- 两人被重新包围，故事被推入下一阶段的牺牲链；本段本身尚未完成献祭。

## 可复用观察

- **战斗可读性**：每一招都有明确目的、窗口和新状态，技能名服从因果。
- **关系转战术**：保护不是谁永远挡在前面，而是按控制、突进、锁定和恢复窗口轮换任务。
- **局部胜利/全局失败**：解决主要约束后引入有前置生态依据的失控变量，可避免胜利线性累积。
- **成本账本**：魂力、伤势、暗器库存、底牌公开和位置必须同步更新。

## 未决与风险

- 献祭发生在后续链条，不能把它误标为本段已完成事件。
- “以命搏命”在文本中仍以计算最小代价为前提，不等于无计划冲锋。
- 意外魂兽若无此前生态和能力铺垫，会显得纯粹作者干预；续写应补足可追溯线索。
