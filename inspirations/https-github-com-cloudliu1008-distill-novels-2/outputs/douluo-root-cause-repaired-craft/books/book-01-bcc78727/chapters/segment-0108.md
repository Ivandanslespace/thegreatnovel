# segment-0108｜蓝狮组合成立与双人协作入口

- Source: `book-01-bcc78727 · segment-0108 · 行 6517-6564`
- 章节标题：第二十四章 蓝狮组合的成立（一）
- 代表维度：世界、人物、情节、对话、节奏

## 本段前状态

唐三与凌岳已通过史莱克筛选，但两人的协作尚未在斗魂场的正式积分制度中注册。团队需要实战经验，也需要理解不同赛制的风险。

## 因果链

1. 场馆规模、观众、贵宾与势力展示功能，把战斗放进商业和政治制度。
2. 博弈、生死斗和赌斗被区分，先建立伤害边界与收益差异。
3. 凌岳发现同一魂师可参加不同类型，主动提出增加二对二场次以加速经验和积分积累。
4. 唐三接受方案，二人取得队友许可并前往报名。

## 本段后状态

- “蓝狮组合”从私人默契转为被制度识别的二人战术单位。
- 凌岳承担机会识别与提案，唐三承担评估与确认，初步形成互补决策模式。
- 本段只完成组队与规则入口；实际协作成效要到后续斗魂验证。

## 可复用观察

- **制度先行**：先让读者理解赛制，后续胜负才有具体意义。
- **关系转战术**：亲近不是自动配合；必须有共同目标、角色分工和外部计分机制。
- **说明型对白**：规则解释后立刻产生报名选择，避免成为无后果百科段落。
- **节奏功能**：这是短 setup 场景，以清晰决策为收束，不需要提前展开完整战斗。

## 未决与风险

- 组合的控制、突进、保护和撤退分工尚未在本段明确。
- 赛制允许多场不等于身体成本为零，后续需要登记消耗与恢复。
- 不应从组合名反推固定招式或永久阵位。
