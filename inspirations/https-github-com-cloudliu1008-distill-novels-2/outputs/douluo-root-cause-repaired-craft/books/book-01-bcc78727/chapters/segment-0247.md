# segment-0247｜不完整复活与照料状态机

- Source: `book-01-bcc78727 · segment-0247 · 行 47892-48109`
- 章节标题：第一百八十章 复活，凌岳，二分之一
- 代表维度：人物、情节、主题、连续性、对话

## 本段前状态

凌岳在献祭后失去正常的人类身体—灵魂统一状态。仙草提供了恢复身体的可能，唐三期待的是完整归来，但复活条件尚未被验证。

## 因果链

1. 凌岳恢复人形和生命体征，最初外观足以制造“已经复活”的希望。
2. 空洞反应和无法回应使唐三识别出身体恢复不等于灵魂归位。
3. 唐三把后续条件拆成魂环、魂骨、九环魂力与可能的药物接口，不再把复活当作单次奇迹。
4. 他公开介绍凌岳为爱人，并在宗门建制和资源谈判中保留其社会位置。
5. 日常照料转成可观察状态：体温、睡眠、重心、魂力回流、衣物、触碰许可和回应方式。

## 本段后状态

- 凌岳进入“身体存在、灵魂不完整”的明确中间状态。
- 唐三获得可执行的复活条件表，但结果和部分资源需求仍不确定。
- 关系身份被公开维持，身体照料建立了边界；唐门建制与私人复活目标并行推进。

## 可复用观察

- **复活分层**：先让外观制造希望，再用反应和知识状态揭示缺失层级。
- **照料叙事**：通过可记录的身体指标和许可表现爱，避免只重复悲伤宣言。
- **公共身份**：失能或失语不应自动抹除角色在关系与机构中的位置。
- **情节联动**：私人资源消耗会改变宗门谈判，复活线因此不是脱离主线的情感插曲。

## 未决与风险

- 完整灵魂回归的确切机制和成功率尚未闭合。
- “身体本能回应”不能被等同于完整知情同意，亲密互动必须保持更高边界。
- 本段的复活例外依赖特定历史链，不能推广为普通治疗规则。
