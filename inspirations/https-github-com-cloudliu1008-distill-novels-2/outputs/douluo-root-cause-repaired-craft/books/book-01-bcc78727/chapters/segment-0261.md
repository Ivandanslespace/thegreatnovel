# segment-0261｜订婚、家庭许可与公开承诺

- Source: `book-01-bcc78727 · segment-0261 · 行 51828-52051`

- 代表维度：人物、主题、对话、连续性、意象

## 本段前状态

凌岳只有阶段性身体恢复，唐三准备前往海神岛寻找更高层复活条件。两人的关系已经公开，但尚未得到父母共同见证，也没有明确婚姻状态。

## 因果链

1. 唐三带凌岳回到冰火两仪眼，与唐昊和阿岚重建家庭场景。
2. 他完整报告献祭、半复活、唐门和后续计划，把私人关系置于家庭知情之下。
3. 唐三请求先订婚、待凌岳完整恢复后再举行婚礼，主动区分当前承诺与未来仪式。
4. 凌岳的灵魂获得短暂表达窗口，双方共同向父母确认选择。
5. 阿岚以金丝戒指形成物件化见证，家庭称谓和公开许可同步改变关系状态。

## 本段后状态

- 唐三与凌岳进入“已订婚、婚礼待完整复活”的关系状态。
- 唐昊与阿岚明确接纳凌岳为家庭成员。
- 金色戒指成为承诺与心灵联系的连续性物件，后续持有和状态需要追踪。
- 海神岛任务获得更清楚的私人动机，但不是只服务恋爱线。

## 可复用观察

- **承诺分级**：订婚、完整复活和婚礼分成不同门槛，避免一次场景结清全部关系问题。
- **家庭许可**：通过报告、请求、共同动作、称谓和物件完成，而不是旁白宣布认可。
- **意象功能**：戒指既是情感符号，也是后续可见、可追踪的状态载体。
- **主题推进**：家庭由血缘见证与被选择关系共同构成。
