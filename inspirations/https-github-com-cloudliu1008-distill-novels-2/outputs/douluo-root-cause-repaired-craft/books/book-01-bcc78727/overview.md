## 核心因果骨架

1. **规则先定义门槛**：学院、斗魂场、大赛、杀戮之都、神考与战争分别规定资格、禁令、资源和失败代价。
2. **关系决定角色愿意支付什么**：父子、伴侣、团队与导师关系把抽象门槛变成不可回避的选择。
3. **选择改变身体与制度状态**：魂环、魂骨、伤势、身份公开、宗门职位和战争承诺都留下后续约束。
4. **旧状态成为下一弧障碍**：一次胜利不会清空代价；秘密、损伤、承诺与制度后果继续推动下一弧。
