# 写作控制面板

这些控制项用于 `design`、`revise` 和 `check`。数值是创作档位，不是对正文的硬性统计复刻。

## 场景总控

| 控制项 | 低压 | 中压 | 高压/高潮 | 检查问题 |
|---|---|---|---|---|
| 目标可见度 | 暗示需求 | 明确短期任务 | 一句话说明不可失去之物 | 角色现在到底要什么？ |
| 规则密度 | 1 条背景规则 | 2-3 条行动约束 | 只保留决定生死的规则 | 规则是否改变选择？ |
| 信息差 | 读者≈角色 | 隐藏一项底牌 | 隐藏答案，但显示异常后果 | 谁知道什么？ |
| 叙事距离 | 概述/观察 | 近距判断 | 身体、距离、时间窗口 | 不可逆选择是否被展开？ |
| 对话长度 | 短交流 | 一轮解释加回应 | 短命令、拒绝、承诺 | 长话轮后是否有人行动？ |
| 动作粒度 | 结果概述 | 目的—阻力 | 目的—阻力—成本—新状态 | 每个动作改变了什么？ |
| 关系压力 | 习惯性配合 | 边界协商 | 许可、牺牲或背叛 | 对方是否拥有拒绝权？ |
| 连续性负担 | 轻量物件 | 能力/知识更新 | 伤势、承诺、身份、资源全登记 | 下一章继承了哪些状态？ |

## 场景入口

- 默认顺序：**地点锚点 → 一个感官变化 → 角色身体动作 → 当前判断/目标**。
- 中途转场至少重置地点、时间或任务中的一项。
- 避免连续使用“目光、眼中、身体、突然、顿时”承载不同情绪；重复词必须带来不同后果。
- 来源模型：`book-01-bcc78727 · segment-0001 · 行 3-25`；`segment-0340 · 行 70353-70399`。

## 对话场景

1. 为每个长话轮指定唯一功能：解释、请求、拒绝、谈判或真相揭示。
2. 长话轮后必须出现追问、反对、沉默、许可改变或身体行动之一。
3. 地位变化用可验证动作收尾：改称谓、允许留下、收回威压、交付物件或离场。
4. 沉默只有在改变下一步行动时才保留。
5. 核心需求可延迟 1-3 回合，但显形点要伴随真实代价。

来源模型：`book-01-bcc78727 · segment-0153 · 行 18535-18575`；`segment-0240 · 行 46066-46110`；`segment-0379 · 行 78598-78644`。

## 战斗场景

- 开战前登记：目标、敌我已知信息、地形、禁止项、一次性资源、撤退条件。
- 每次出招只写一个主要目的；命中与否都必须改变距离、控制、资源、伤势、信息或关系中的至少一项。
- 强敌解题优先使用规则窄缝、地形、控制窗口和协作，不用无来源的临时加力。
- 连续三次动作后安排一次状态小结，但只说明下一选择需要的信息。
- 高阶能力同步登记魂力/神力、精神负担、环境依赖、冷却与身体损伤。

来源模型：`book-01-bcc78727 · segment-0138 · 行 13975-14238`；`segment-0230 · 行 43128-43399`；`segment-0367 · 行 75848-76205`。

## 关系与牺牲

- 先写双方协议：什么可以代替对方决定，什么必须获得许可。
- 牺牲后分开更新牺牲者与幸存者的身体、知识、责任和选择权。
- 复活至少检查五个闸门：身体、灵魂/记忆、能力、社会身份、关系重新同意。
- “保护”必须产生具体分工；不要只用宣言证明关系。

来源模型：`book-01-bcc78727 · segment-0153 · 行 18553-18575`；`segment-0247 · 行 47892-48042`；`segment-0318 · 行 65168-65399`。

## 节奏档位

### 训练/旅行压缩档

- 说明时间跨度。
- 只保留三类差异：能力、关系、机构身份。
- 跳跃后的第一场戏必须展示旧状态与新状态的对照。

### 危机展开档

- 缩短句内目标数量。
- 用距离、剩余资源和倒计时维持方向感。
- 每 2-4 个动作兑现一次局部结果。

### 情感回收档

- 降低设定密度。
- 展开一次许可、拒绝或承诺。
- 用一个物件或身体动作承接主题，不重复总结情绪。

来源模型：`book-01-bcc78727 · segment-0222 · 行 40810-41101`；`segment-0261 · 行 51904-51932`；`segment-0374 · 行 77420-77649`。

## 连续性闸门

交稿前逐项确认：

- [ ] 时间锚点与所有主要人物年龄同步；`AGE_TIMELINE_CONFLICT` 未被静默修复。
- [ ] 等级提升有魂环、神赐或其他明确例外来源。
- [ ] 双武魂、身份秘密和神考条件按角色分别更新知识状态。
- [ ] 魂环、魂骨、神器、暗器和遗物的持有人与损坏状态明确。
- [ ] 伤势有治疗来源、恢复时长和残留后果。
- [ ] 环境倍率与地点移动有证据。
- [ ] 承诺、禁令、停战和销毁武器等义务仍可追踪。
- [ ] 越级吸收、献祭、复活、神位继承和双神融合没有被普通化。
- [ ] “阿银/阿岚”名称差异在获得用户决定前保持显式警告。

完整规则见 [continuity.md](continuity.md)。

## 原创性闸门

- 只迁移抽象机制和参数，不迁移专名、独特设定组合、标志性台词或场景顺序。
- 不按原作角色做一一换皮映射。
- 新方案至少改变世界资源、人物关系、失败代价和终局选择中的三项。
- 输出分析时给来源定位；输出原创方案时明确它是新创作，不伪装成源文本事实。

## 最小修订流程

1. 写出本场景开始前的五项状态：身体、资源、知识、关系、制度。
2. 选一个主要目标和一个真正阻力。
3. 选择本场景唯一不可逆变化。
4. 按对应档位修订叙事距离、对话和动作粒度。
5. 写出结束后的五项状态差异。
6. 运行连续性与原创性闸门，只修复实际冲突。
