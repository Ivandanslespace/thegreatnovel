# 跨维度综合

本文件把世界、人物、情节、叙事、文风、对话、节奏、主题与连续性结论组合成新的因果模型。它们是蒸馏后的综合推导，不是正文原句。当前只有一个来源，因此不做跨书共性声明。

## 1. 制度门槛把升级转成选择

- Sources: `book-01-bcc78727 · segment-0075 · 行 4541-4602`；`segment-0108 · 行 6517-6564`；`segment-0208 · 行 36222-36555`；`segment-0277 · 行 55838-56255`
- Chain: 世界先规定资格、禁令、时限和奖励 → 人物解释规则并决定是否进入 → 情节以通过、利用或拒绝规则推进 → 新身份和资源写入连续性账本。
- Writing use: 设计新试炼时，先写“谁有资格、失败失去什么、哪条规则可被聪明利用”，最后才设计招式。
- Risk: 如果每个制度只换名称而不改变角色愿意支付的代价，长篇会退化成同构副本。
- Confidence: high

## 2. 关系协议直接生成战术结构

- Sources: `book-01-bcc78727 · segment-0108 · 行 6517-6564`；`segment-0153 · 行 18535-18575`；`segment-0230 · 行 43150-43294`；`segment-0366 · 行 75648-75784`
- Chain: 关系先明确沟通、保护和拒绝边界 → 战斗中转化为谁负责控制、突进、承伤和撤离 → 成功或失误反过来检验关系是否允许对方拥有选择权。
- Writing use: 在亲密关系场景里建立一条可执行协议，并在后续危机中让协议变成战术分工，而不是只靠告白证明感情。
- Risk: “替对方牺牲”如果永远绕过对方许可，会让互相保护退化为竞争性自毁。
- Confidence: high

## 3. 牺牲—复活是身体、关系与社会身份的多阶段状态机

- Sources: `book-01-bcc78727 · segment-0230 · 行 43128-43399`；`segment-0247 · 行 47892-48042`；`segment-0261 · 行 51904-51932`；`segment-0318 · 行 65168-65399`
- Chain: 生存危机迫使牺牲 → 身体与灵魂分离产生复活条件 → 照料和公开承认维持关系身份 → 完整复活仍要求归还资源并承担身体成本 → 主题从“爱能否战胜死亡”转成“第二次生命如何重新同意旧承诺”。
- Writing use: 将复活拆成身体、记忆、能力、法律/机构身份、关系许可五个闸门；每过一关都保留可见代价。
- Risk: 一次性无损复活会抹去前弧的牺牲重量。
- Confidence: high

## 4. 信息差用“异常—危机用途—局部解释”阶梯回收

- Sources: `book-01-bcc78727 · segment-0023 · 行 1305-1372`；`segment-0203 · 行 34560-34640`；`segment-0247 · 行 47892-48042`；`segment-0378 · 行 78310-78364`
- Chain: 先让角色或能力表现出无法解释的异常 → 在危机中让异常改变选择 → 高潮后只解释支持当前弧的规则 → 留下更高层、可验证的新问题。
- Writing use: 每次揭示只回答一个核心问题，并登记“谁知道、谁仍不知道、下一次验证点”。
- Risk: 高潮后集中说明所有机制，会把情绪尾声变成设定讲义。
- Confidence: high

## 5. 战力规模增长，但可读性锚点保持不变

- Sources: `book-01-bcc78727 · segment-0138 · 行 13975-14238`；`segment-0230 · 行 43128-43399`；`segment-0367 · 行 75848-76205`
- Chain: 敌我规模从小队扩大到军队和神级力量 → 叙事仍用距离、资源、控制窗口、伤势与下一选择解释战局 → 读者追踪的是状态改变，而不是技能名数量。
- Writing use: 无论力量级别多高，每个动作都写成“目的 → 阻力 → 成本 → 新状态”，下一动作必须由新状态触发。
- Risk: 视觉效果不断放大却不改变胜率、资源或关系，会造成虚假高潮。
- Confidence: high

## 6. 长篇终点由“放弃何种力量用途”定义

- Sources: `book-01-bcc78727 · segment-0001 · 行 39-45`；`segment-0310 · 行 63540-63608`；`segment-0379 · 行 78588-78708`
- Chain: 开篇以技术重建定义力量价值 → 中段以保护关系网络推动升级 → 战争迫使力量进入制度性杀伤 → 结尾通过停战、解散军队、限制武器和退出政治重定力量边界 → 场景回到起点空间，完成主题回环。
- Writing use: 终局除了回答“谁赢”，还要回答主角保留什么、销毁什么、交还什么、以后拒绝做什么。
- Risk: 只有口头宣布退出，没有执行场景或后续监督，会留下 `direction-paid / execution-open` 状态。
- Confidence: high

## 7. 文风、叙事与节奏的协同规律

- Sources: `book-01-bcc78727 · segment-0001 · 行 3-25`；`segment-0306 · 行 62528-62610`；`segment-0374 · 行 77420-77649`；`segment-0379 · 行 78598-78644`
- Chain: 地点和感官快速建立空间 → 近距判断解释下一选择 → 动作改变状态 → 对话或短反应确认关系后果 → 重复训练被概述，生死与承诺被展开。
- Writing use: 展开不可逆选择，压缩重复训练；说明必须由质疑、拒绝、许可或行动收尾。
- Risk: 规范化文本的标点和引号损伤会夸大长句与长话轮倾向，不能机械仿写。
- Confidence: high for structure; medium for exact sentence/dialogue statistics

## 可迁移的总模型

```text
规则门槛
  → 角色欲望与关系义务发生冲突
  → 角色作出有代价的选择
  → 身体 / 资源 / 知识 / 关系 / 制度状态改变
  → 新状态成为下一弧的障碍或资格
  → 终局决定哪些力量用途被保留、限制或放弃
```

迁移到原创内容时，只复用这条抽象因果链；不要复用源人物专名、专有力量名、标志性场面或句式。
