# 中性文风参数

## 系统卡片与行动段落交替

- Sources: `book-01-82fe54fd · segment-0002 · 行 274-350`；`book-01-82fe54fd · segment-0065 · 行 12498-12511`
- Observation: 文本频繁使用短系统卡片呈现属性、耗时、材料和结果，再用角色的判断把卡片转成行动；确定性扫描记录 922 行以 `【` 开头的系统/物品信息。
- Mechanism: 卡片给读者硬状态，行动段给状态以情境和代价；两者交替保持“爽点可核对”。
- Transferable principle: 把规则信息拆成可扫描模块，但每个模块后面都安排一次选择、试验或反应，避免设定独白。
- Controls: 卡片密度（低/中/高）、单卡字段数、卡片后行动延迟、解释长度。
- Risks: 卡片过密会像 UI 日志；若角色不解释字段之间的关系，数字不能形成戏剧。
- Confidence: high

## 短段落、动作链和感官冲击

- Sources: `book-01-82fe54fd · segment-0004 · 行 1112-1124`；`book-01-82fe54fd · segment-0032 · 行 6706-6718`；`book-01-82fe54fd · segment-0100 · 行 17572-17596`
- Observation: 高压场景把发现拆成多行短句和连续动作；视觉（浓雾、血色、影子）与听觉（撞击、爆炸、枪响）交替，先让读者感到异常，再补充分类和属性。
- Mechanism: 段落断裂模拟注意力被威胁切割；感官顺序把未知变成可追踪的空间。
- Transferable principle: 恐惧场景先给感官异常，再给对象命名；动作链中的每一步至少改变距离、声音、伤势或可见性。
- Controls: 平均段落长度、感官通道数、命名延迟、动作间隔、留白比例。
- Risks: 过度碎片化会让动作难以定位；感官词只堆颜色和声音会变成模板化惊吓。
- Confidence: high

## 口语化内心与算账式解释

- Sources: `book-01-82fe54fd · segment-0002 · 行 294-326`；`book-01-82fe54fd · segment-0035 · 行 7204-7244`
- Observation: 苏牧常用“先排除—比较—决定”的内心过程，把百分比、材料、距离和时间写成可复核的粗算；同时用短促吐槽打断高密度计算。
- Mechanism: 计算让外挂选择具有主人公人格，口语反应又防止章节变成攻略文档。
- Transferable principle: 让解释遵循角色当下的决策需要，只展示改变选择的数字；在算账之间保留一处情绪或身体反应。
- Controls: 推理显性度、计算精度、吐槽频率、情绪泄漏、错误允许度。
- Risks: 解释过于完整会消灭发现；所有粗算都正确会让人物像作者代言人。
- Confidence: high

## 反应式幽默与危险并置

- Sources: `book-01-82fe54fd · segment-0016 · 行 3390-3657`；`book-01-82fe54fd · segment-0037 · 行 7658-7813`；`book-01-82fe54fd · segment-0055 · 行 10780-10955`
- Observation: 文本在恶心、恐惧或高风险动作后插入一句反应式吐槽；幽默不取消危险，反而强调角色仍在用熟悉的语言维持控制感。
- Mechanism: 情绪松弛给读者换气，同时把苏牧的自信、贪财和恶作剧感固定成可识别声音。
- Transferable principle: 幽默应来自角色对刚刚发生的具体风险的反应，而不是脱离场景的段子；笑点后要保留资源或关系后果。
- Controls: 危险/幽默间距、角色语气强度、吐槽是否改变决定、换气频率。
- Risks: 在受害者创伤场景使用同样语气会造成伦理失真；幽默若总能解决尴尬，人物就没有脆弱面。
- Confidence: medium-high

## 轻量文本统计与适用范围

- Transferable principle: 把统计当作偏差报警器：发现章节过于平直或过于密集后，再回到场景功能检查。
- Controls: 章节字数目标、系统卡片密度、问句/感叹句密度、省略号密度、对白占比。
- Risks: 机械追数字会制造人工节奏；本测试快照包含编辑残留，指标只作趋势参考。
- Confidence: medium
