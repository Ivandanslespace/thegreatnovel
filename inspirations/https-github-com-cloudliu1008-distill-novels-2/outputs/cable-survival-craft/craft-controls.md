# 写作控制面板

## 设计控制

| 控制项 | 低档 | 高档 | 代价/检查 |
|---|---|---|---|
| 信息透明度 | 只给异常和方向 | 直接给属性和坐标 | 越透明越要增加规则交互，而非减少选择 |
| 行动预算 | 每日多次 | 每日一次或更少 | 预算越紧，情报越重要，撤离必须可验证 |
| 安全屋强度 | 只能暂避 | 可生产、可防守 | 强度越高，夜间威胁或维护成本越高 |
| 能力接口 | 独立加成 | 能力与职业/装备互相放大 | 乘法优势必须保留弹药、耐力或护甲边界 |
| 交易信任 | 一手交钱一手交货 | 允许产能和人情赊账 | 每笔信用记录偿还、违约或重新定价 |
| 夜间规则 | 只增加敌人 | 改变感知和知识传播 | 触发条件要有证据，不能完全靠作者解释 |
| 反作用力 | 奖励无后果 | 奖励改变生态和组织 | 大规模收益后至少留下一个可追踪残留 |

## 场景生成清单

1. 角色在本场景开始时知道什么、缺什么、不能做什么？
2. 本场景的行动预算是时间、弹药、负重、体力、信用还是隐蔽？
3. 场景先出现哪一个感官异常，何时给出命名和属性？
4. 每个关键动作是否改变距离、资源、伤势、信息、权限或关系？
5. 奖励是如何进入下一轮选择的？谁因此看见主角的能力？
6. 场景结束时，哪个问题已支付，哪个问题仍开放？

## 修订控制

- 若战斗像技能清单：为每三次动作补一个位置/资源/伤势状态变化。
- 若系统解释过长：删除不改变选择的字段，把解释移到角色做选择时。
- 若合作跳跃：补一笔可验证的共同风险、分配争执或关系债务。
- 若主角过强：不要只降低数值，优先引入护甲匹配、弹药、耐力、噪声、时间或知识污染。
- 若节奏平直：把下一次升级前的准备、试验和社会暴露拆成三个递进回合。
- 若主题说教：让人物在一个有收益的越界机会中做选择，并保留失败或余波。

## 连续性检查清单

- [ ] 当前时间、昼夜、落点和撤离状态清楚。
- [ ] 经验、等级、突破符、属性、职业栏和天赋状态可回溯。
- [ ] 弹药、食物、水、材料、耐久、制作倒计时已经记账。
- [ ] 角色知道的内容与读者/旁观者知道的内容分开。
- [ ] 新规则写出触发条件、边界、成本和已知反例。
- [ ] 交易、承诺、伤势和关系债务有前态与后态。
- [ ] 不把本知识库的专名、怪物、道具或桥段直接搬进用户 Canon。

## 原创性护栏

使用本面板时只迁移“有限行动预算”“规则能力的边界测试”“交易化信任”“规模化收益的反作用力”等抽象机制。不要复用原作专名、人物、世界设定、怪物外形、道具组合、独特场景顺序或标志性措辞。
