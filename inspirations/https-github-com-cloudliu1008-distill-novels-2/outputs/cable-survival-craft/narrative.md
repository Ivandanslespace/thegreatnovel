# 叙事信息控制

## 近距离第三人称跟随苏牧

- Sources: `book-01-82fe54fd · segment-0001 · 行 26-66`；`book-01-82fe54fd · segment-0065 · 行 12392-12511`
- Observation: 叙事通常贴着苏牧的感官、面板和即时判断展开；读者知道的规则多半不超过他刚刚观察或推导出的范围。
- Mechanism: 主角的分析成为读者的导航仪，未知被切成一连串可验证的问题。
- Transferable principle: 在规则型求生文中，让焦点人物的知识边界与读者同步增长；只提前给出会制造悬念的外部信号，不提前解释答案。
- Controls: 叙事距离、内心显性度、面板可见度、预知量、未知持续时间。
- Risks: 如果主角每次都马上解释，悬念会变成说明；如果完全不解释，战斗会失去可复盘性。
- Confidence: high

## 选择性切换到旁观者制造信息差

- Sources: `book-01-82fe54fd · segment-0010 · 行 2148-2327`；`book-01-82fe54fd · segment-0095 · 行 16802-17063`；`book-01-82fe54fd · segment-0099 · 行 17526-17571；book-01-82fe54fd · segment-0100 · 行 17572-17664`
- Observation: 文本偶尔切到林雨薇、军用基地外的队伍或旁观者，让读者先看到主角不知道的受伤、窥探或舔食者威胁，再回到苏牧的局部视角。
- Mechanism: 视角切换不是为了补全世界，而是为了把“读者知道、主角不知道”的危险压入下一次回合。
- Transferable principle: 只在旁观视角能改变读者对下一次行动的期待时切换；切回主视角时保留至少一条未共享信息。
- Controls: 切换频率、提前量、旁观者可靠性、回切延迟、信息能否转为行动。
- Risks: 频繁切换会稀释主角代入；旁观者知道所有答案会破坏探索。
- Confidence: high

## 卡片、频道和日记是三种信息媒介

- Sources: `book-01-82fe54fd · segment-0001 · 行 254-265；book-01-82fe54fd · segment-0002 · 行 266-362`；`book-01-82fe54fd · segment-0044 · 行 8866-9031`；`book-01-82fe54fd · segment-0051 · 行 10082-10237`
- Observation: 系统卡片给出当前硬状态，频道给出带偏差的群体信息，日记给出延迟且可能不完整的历史信息；三者的可信度和时间位置不同。
- Mechanism: 同一世界通过不同媒介呈现，读者需要同时判断“内容是什么”和“谁为什么现在说它”。
- Transferable principle: 为不同信息源分配不同可靠性、时效和触发成本；让媒介本身成为叙事选择。
- Controls: 可靠性、时效、公开范围、记录者动机、可交叉验证程度。
- Risks: 如果所有媒介都同样准确，会失去信息差；如果所有消息都不可靠，读者无法建立规则账本。
- Confidence: high

## 揭示策略：先给异常，再给命名，再给属性

- Sources: `book-01-82fe54fd · segment-0012 · 行 2512-2540`；`book-01-82fe54fd · segment-0058 · 行 11312-11324`；`book-01-82fe54fd · segment-0100 · 行 17572-17614`
- Observation: 夜袭先以声音和撞击出现；诡异威胁先以“敲门”与间接观察规则出现；舔食者先以残影屠杀队伍出现，随后才给出外形和属性。
- Mechanism: 感官异常制造问题，名称提供分类，属性提供策略边界；信息分层保持恐惧和可计算性同时存在。
- Transferable principle: 复杂威胁分三次揭示：它是什么感觉、它属于什么类别、它的可操作边界在哪里。
- Controls: 三层揭示间隔、异常强度、属性透明度、反制窗口。
- Risks: 命名太早会让怪物变成图鉴条目；只给感觉不给边界会让解决像随机。
- Confidence: high

## 章末钩子把能力边界而非答案留给下一章

- Sources: `book-01-82fe54fd · segment-0097 · 行 17104-17237`；`book-01-82fe54fd · segment-0099 · 行 17422-17571`；`book-01-82fe54fd · segment-0100 · 行 17670-17716`
- Observation: 救援后留下“尸体消失/外面有东西”的疑问，旁观者看见舔食者后再切回苏牧；苏牧能看清轨迹，却发现输出不足，故事停在“旧能力部分有效”的位置。
- Mechanism: 下一章的问题已经被限定，但答案没有被预先兑现；钩子来自策略缺口而非单纯喊出更强敌人。
- Transferable principle: 章末应明确下一回合要解决的能力边界，并让当前资源足以提出方案、又不足以直接解决。
- Controls: 未解问题数量、资源缺口、信息提前量、即时危险距离。
- Risks: 钩子太多会造成债务堆积；缺口若与主线无关，只是噪音。
- Confidence: high
