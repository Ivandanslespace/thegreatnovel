# 跨维度综合

## 1. 情报优势只有在行动预算中才会变成能力优势

- Sources: `book-01-82fe54fd · segment-0002 · 行 312-380`；`book-01-82fe54fd · segment-0060 · 行 11656-11818`
- Observation: 每日情报本身不杀怪；它只有在苏牧清点弹药、选择落点、安排树高和撤离窗口后才改变结果。
- New synthesis: “信息外挂”的真正产物不是知道更多，而是减少无效行动，让有限的每日机会集中到高回报且可撤离的位置。
- Transferable principle: 设计信息能力时，先定义它节省哪一种预算：时间、生命、负重、行动次数或关系成本。

## 2. 安全屋、交易网和生产力构成三层保护

- Sources: `book-01-82fe54fd · segment-0001 · 行 68-78`；`book-01-82fe54fd · segment-0049 · 行 9744-9900`；`book-01-82fe54fd · segment-0054 · 行 10602-10776`
- Observation: 纜車提供物理安全，频道/交易提供资源和情报，三级量产提供稳定产能；三者同时升级才形成结构性优势。
- New synthesis: 求生故事的强者不是“单人战力最高”，而是把安全边界、社会交换和生产能力连接成闭环的人。
- Transferable principle: 为主角设计至少一个物理护城河、一个信息/关系护城河和一个产能护城河；让它们相互依赖、不能各自无限扩张。

## 3. 规则能力的戏剧性来自边界测试

- Sources: `book-01-82fe54fd · segment-0017 · 行 3658-3877`；`book-01-82fe54fd · segment-0037 · 行 7658-7813`；`book-01-82fe54fd · segment-0100 · 行 17670-17716`
- Observation: 弱点锁定、好运和动态视觉持续有效，但捕兽夹会接近失控、转盘引发他人怀疑、M500 对高护甲输出不足。
- New synthesis: 规则型能力不能靠“是否有效”制造悬念，而应靠“在哪个接口上有效、在哪个接口上失效”制造策略题。
- Transferable principle: 每次强能力升级后，安排一次边界样本；让失败不否认能力，而是指出下一项资源或协作需求。

## 4. 合作关系是风险共享协议的逐次升级

- Sources: `book-01-82fe54fd · segment-0028 · 行 5958-6229`；`book-01-82fe54fd · segment-0047 · 行 9412-9586`；`book-01-82fe54fd · segment-0095 · 行 16802-16820`
- Observation: 苏牧与林雨薇先以威慑和分成建立最低合作，后来在战斗中互相采用指令，再通过药物和坐标形成关系债务。
- New synthesis: 关系弧和战力弧互相提供验证：谁能把自己的风险交给谁，决定谁能进入下一场战斗的关键位置。
- Transferable principle: 关系升级必须新增一种共享权限或共同失败；只增加好感不增加行动权限，关系不会真正改变剧情。

## 5. 规模化收益必须留下反作用力

- Sources: `book-01-82fe54fd · segment-0082 · 行 14920-15075`；`book-01-82fe54fd · segment-0098 · 行 17238-17421`；`book-01-82fe54fd · segment-0100 · 行 17572-17716`
- Observation: 爆炸带来经验和军火，但也带来外来队伍、尸体消失、受害者余波和五级舔食者；收益没有被世界无条件吞下。
- New synthesis: 当主角从“搜集者”进入“能改变区域生态的玩家”时，情节发动机应从资源发现转向后果管理。
- Transferable principle: 任何能批量制造资源的能力都应同时提高可见性、敌人密度或道德责任中的至少一项。

## 6. 可迁移组合（新综合，不归因于原作）

- **移动安全屋 + 一次性行动预算 + 信息污染**：让主角必须决定是否接收会改变风险的情报。
- **规则型能力 + 复杂职业操作 + 资源硬上限**：能力保证“看懂/命中”，但弹药、耐力和护甲仍限制解决方式。
- **交易型伙伴 + 共同战斗位置 + 不对称债务**：关系用权限和失败共担推进，而非直接宣告亲密。
- **规模化生产 + 生态反应 + 旁观者视角**：主角的成功越明显，世界越快生成新的捕食者和组织竞争。

这些组合只保留抽象机制；设计新作品时应替换专名、设定、场景、怪物和具体事件。
