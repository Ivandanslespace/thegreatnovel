# 节奏与张力控制

## 章节规模：短回合承载一个可见状态变化

- Sources: `book-01-82fe54fd · segment-0001 · 行 12-265`；`book-01-82fe54fd · segment-0100 · 行 17572-17716`
- Observation: 100 个片段的字符数范围约 1,067—4,056，中位数约 2,098；多数章节围绕一个落点、一次战斗、一次交易或一次系统升级完成闭环，同时在结尾留下下一问题。
- Mechanism: 章节短并不等于事件少；只要前后状态可对比，读者会把一个小循环当作进展。
- Transferable principle: 连载章节先定义本章状态变化，再决定场景数量；章末保留一个未解决但可计算的问题。
- Controls: 章节字符目标、状态变化数量、章末未解问题数、系统卡片比例。
- Risks: 每章都闭环会缺少长线；每章都只留悬念会让读者感觉没有获得。
- Confidence: medium-high

## 微观推进循环：情报—准备—落点—验证—回收

- Sources: `book-01-82fe54fd · segment-0002 · 行 348-380`；`book-01-82fe54fd · segment-0060 · 行 11656-11818`；`book-01-82fe54fd · segment-0077 · 行 14174-14303`
- Observation: 苏牧先取得坐标和怪物等级，再清点武器、弹药、撤离点和负重；落地后用地形和能力验证判断，最后把经验、材料和突破符归档为下一轮资源。
- Mechanism: 准备段让战斗结果可追踪，回收段让战利品转成后续选择；节奏因此是循环式而非单纯事件堆叠。
- Transferable principle: 每次探险至少包含一次出发前预算和一次返程后账本整理；两者之间的差异就是剧情收益。
- Controls: 准备篇幅、信息提前量、战斗时长、回收细度、下一次行动的提前埋点。
- Risks: 准备太长会压低速度；没有回收会让掉落失去意义。
- Confidence: high

## 自动化/刷怪段用数值递增替代重复动作

- Sources: `book-01-82fe54fd · segment-0014 · 行 3138-3151`；`book-01-82fe54fd · segment-0082 · 行 14920-15075`；`book-01-82fe54fd · segment-0090 · 行 16068-16223`
- Observation: 捕兽夹和箭匣把重复击杀压缩成经验、掉落和倒计时变化；真正的节奏点是设备耐久、诡晶数量、等级满格或新消息，而不是逐只描写。
- Mechanism: 机械重复成为资源背景，读者只在状态跨阈值时重新集中注意力。
- Transferable principle: 对重复劳动采用“节拍化摘要”，保留每个阈值和失效窗口；不要把效率爽感写成无差别蒙太奇。
- Controls: 摘要跨度、数值跳变幅度、阈值间隔、设备风险、背景信息插入率。
- Risks: 跳过太多会让升级像作弊；重复太细会让节奏停滞。
- Confidence: high

## 高压弧的张力曲线：危险先被看见，再被迫接近

- Sources: `book-01-82fe54fd · segment-0086 · 行 15598-15619`；`book-01-82fe54fd · segment-0088 · 行 15784-15939`；`book-01-82fe54fd · segment-0099 · 行 17526-17571；book-01-82fe54fd · segment-0100 · 行 17572-17716`
- Observation: 纜車先停，频道确认附近有人战斗；火光消失后只留下资源和未知；军火库外的旁观者先看到舔食者屠杀，再看到它转向苏牧。威胁距离逐层缩短。
- Mechanism: 视距、声音和旁观视角逐步收紧，让读者在答案出现前经历几次“还能否撤离”的判断。
- Transferable principle: 高压场景可以按 `远处信号 → 局部证据 → 旁观者确认 → 主角受袭` 排列，逐步减少退路。
- Controls: 威胁距离、预警层数、撤离窗口、旁观者信息量、主角可用资源。
- Risks: 预警太多会显得拖延；主角若总有充足撤离时间，压力不会真正收紧。
- Confidence: high

## 换气段通过交易和制作保持主线不断

- Sources: `book-01-82fe54fd · segment-0045 · 行 9032-9206`；`book-01-82fe54fd · segment-0079 · 行 14476-14627；book-01-82fe54fd · segment-0080 · 行 14628-14765`
- Observation: 战斗之间用频道交易、日记阅读、药酒制作和种植台整理换气，但每个换气动作都会引出新职业、新伤势或下一地点。
- Mechanism: 休息不是暂停，而是把上一场风险的余波转成生产或关系状态。
- Transferable principle: 换气场景至少承接一笔旧账并打开一条新线，避免“休息=信息清零”。
- Controls: 换气长度、旧账回收率、新线数量、制作/交易动作的可视化程度。
- Risks: 换气只剩百科解释会削弱人物；新线过多会堆积叙事债务。
- Confidence: high
