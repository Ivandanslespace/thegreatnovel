# 主题问题与竞争性答案

## 活下去是否等于保住人的边界

- Sources: `book-01-82fe54fd · segment-0034 · 行 7180-7203`；`book-01-82fe54fd · segment-0073 · 行 13590-13833`；`book-01-82fe54fd · segment-0097 · 行 17104-17237`
- Observation: 苏牧在可杀林雨薇的分配场景选择按贡献处理；但世界很快出现截杀、掠夺和性暴力，救援也不能保证被救者继续活下去。
- Mechanism: 人性主题不靠宣言，而靠资源极端化时人物是否仍承认他人的主体性。
- Transferable principle: 把“底线”放进真正有收益的越界机会里，再让遵守底线产生时间、资源或关系成本。
- Controls: 越界收益、底线可见度、介入成本、结果可控度。
- Risks: 让受害者的死亡只证明主角善良，会挪用受害者；需要保留其自主选择与不可逆后果。
- Confidence: high

## 信息是力量，也是污染

- Sources: `book-01-82fe54fd · segment-0002 · 行 312-380`；`book-01-82fe54fd · segment-0044 · 行 8866-9031`；`book-01-82fe54fd · segment-0058 · 行 11312-11324`
- Observation: 每日情报让苏牧避开盲区；日记扩大他的世界模型；但关于敲门威胁的描述可能使听者被间接锁定，知道得更多反而增加风险。
- Mechanism: 信息不再是免费的读者福利，而是需要管理传播路径和验证成本的资源。
- Transferable principle: 给知识设置容量、时效或污染代价；让角色必须决定“要不要知道/告诉别人”。
- Controls: 信息收益、传播风险、可信度、可撤回性、知识差异。
- Risks: 如果污染规则没有可观察证据，会像强行保密；如果信息永远正确，推理和主题都会消失。
- Confidence: medium

## 好运与能力：结果优势是否仍需要准备

- Sources: `book-01-82fe54fd · segment-0033 · 行 6892-7050`；`book-01-82fe54fd · segment-0037 · 行 7658-7813`；`book-01-82fe54fd · segment-0083 · 行 15076-15207`
- Observation: 幸厄转盘和盲盒取优给苏牧明显好运，但他仍通过位置、战斗、天赋选择和资源准备把好运兑现为可持续优势；文本也保留“运气还是规则”的怀疑。
- Mechanism: 好运最有趣的状态不是免费中奖，而是让人物更敢下注，同时要求他证明自己知道何时下注。
- Transferable principle: 把随机优势与判断能力绑定：运气改变收益分布，准备决定是否能承受失败或利用奖励。
- Controls: 好运强度、可控程度、失败代价、解释开放度、准备收益。
- Risks: 绝对好运会消灭风险；完全否定好运又会浪费主题能力。
- Confidence: medium-high

## 技术理性与自然/诡异之间的摩擦

- Sources: `book-01-82fe54fd · segment-0023 · 行 4826-5036`；`book-01-82fe54fd · segment-0062 · 行 11948-12103；book-01-82fe54fd · segment-0063 · 行 12104-12221`；`book-01-82fe54fd · segment-0091 · 行 16224-16364`
- Observation: 苏牧用分解、配方、属性和坐标解释环境；血参却会自行钻入土壤，诡火和敲门威胁又无法完全还原为普通工程对象。
- Mechanism: 可量化系统与未命名生命性并存，提醒主角模型不是世界本身。
- Transferable principle: 让理性模型持续有效，但在关键节点留下不能立即归入模型的行为；未知应迫使模型升级而非直接失效。
- Controls: 可测量比例、异常行为频率、模型错误成本、规则闭环速度。
- Risks: 若所有异常最后都只是更高数值，主题会退化；若异常永远无法学习，系统会显得任意。
- Confidence: medium-high

## 合作不是信任的终点，而是风险分配方式

- Sources: `book-01-82fe54fd · segment-0028 · 行 5958-6229`；`book-01-82fe54fd · segment-0047 · 行 9412-9586`；`book-01-82fe54fd · segment-0095 · 行 16802-16820`
- Observation: 苏牧和林雨薇的合作始终伴随底牌、分成、背信威胁和人情账；关系变近表现为在危险中采用对方判断、提供坐标和偿还救命资源。
- Mechanism: 信任被写成“我愿意把哪一部分风险交给你”，而不是抽象好感。
- Transferable principle: 每次关系升级都应具体化为新增权限、共享信息或共同承担的失败代价。
- Controls: 权限等级、信息共享范围、失败共担程度、关系债务。
- Risks: 没有拒绝和反制的合作会变成主角单方面控制；没有兑现的债务会让关系弧失去记忆。
- Confidence: high
