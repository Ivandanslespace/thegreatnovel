# 情节因果与伏笔状态

## 主线因果骨架

- Sources: `book-01-82fe54fd · segment-0001 · 行 68-78`；`book-01-82fe54fd · segment-0054 · 行 10602-10776`；`book-01-82fe54fd · segment-0093 · 行 16510-16659`
- Observation: 规则定义生存边界 → 苏牧选择情报 → 情报指向落点 → 落点提供资源/伤势/线索 → 资源升级纜車与能力 → 新能力改变下一次落点的可行性 → 世界公告抬高下一段压力。
- Mechanism: 每个升级节点都重新改写“下一次行动能做什么”，所以成长不会只停留在面板数字上。
- Transferable principle: 连载求生主线可用 `信息 → 选择 → 代价 → 状态改变 → 新选择` 的循环维持推进；奖励必须改变下一轮决策空间。
- Controls: 信息清晰度、风险幅度、状态变化数量、奖励的可复用性、下一轮压力。
- Risks: 如果奖励只给稀有物品而不改变选择，章节会变成掉落清单；如果每轮都升级，代价会被稀释。
- Confidence: high

## 弧一：降临与第一次情报（已支付）

- Sources: `book-01-82fe54fd · segment-0001 · 行 68-265；book-01-82fe54fd · segment-0002 · 行 266-404`
- Observation: 苏牧先读生存守则，再在信息/力量/建造之间选择每日情报；两条坐标把抽象世界转成具体路线，并立即引出宝箱与高等级怪物的风险差。
- Mechanism: 开篇先用规则和选择建立读者的操作界面，再用坐标把世界打开。
- Transferable principle: 第一章的外挂应同时改变认知方式和行动路线，不能只显示数值增幅。
- Controls: 规则展示量、首次选择的不可逆性、目标距离、危险提示。
- Risks: 规则说明过长会压低开篇速度；危险没有即时验证会显得只是设定。
- Confidence: high

## 弧二：第一夜与自动化生存（部分支付）

- Sources: `book-01-82fe54fd · segment-0011 · 行 2328-2511`；`book-01-82fe54fd · segment-0014 · 行 2874-3151`；`book-01-82fe54fd · segment-0017 · 行 3658-3877`
- Observation: 降温、诡蝠、捕兽夹和经验积累把夜间防守变成可重复生产；苏牧在近乎失控的猎物上第一次验证了自动化工具的边界，并升到二级。
- Mechanism: 恐怖场景被拆成“设备耐久—经验收益—是否回收”的小循环，紧张感来自边界即将失效。
- Transferable principle: 自动化能力需要一个清晰的失效窗口；玩家越想躺赢，越要被迫监控设备或保留手动干预。
- Controls: 自动化收益、耐久消耗、失效概率、夜间持续时间、人工接管成本。
- Risks: 自动化若无风险会跳过场景；风险若全靠随机会破坏可审计性。
- Confidence: high

## 弧三：林雨薇合作与幸厄转盘（已支付但关系未结清）

- Sources: `book-01-82fe54fd · segment-0028 · 行 5958-6229`；`book-01-82fe54fd · segment-0034 · 行 7052-7203`；`book-01-82fe54fd · segment-0037 · 行 7658-7813`
- Observation: 误认、枪口、手榴弹和坐标构成合作前的安全合同；游乐场行动以静音、地形和弱点攻击击杀强敌；分配争执后，苏牧用规则能力连续获得转盘收益，林雨薇的怀疑和不平衡感被保留下来。
- Mechanism: 合作既提高通关率，也产生权力不平等；好运奖励同时推进战力和关系张力。
- Transferable principle: 让合作任务的成功带来新的谈判问题，避免“组队成功=关系问题结束”。
- Controls: 贡献比例、战利品稀缺度、底牌透明度、能力被怀疑的程度。
- Risks: 若不平等只作为笑料，关系张力会消失；若主角永远不解释，伙伴会失去行动能动性。
- Confidence: high

## 弧四：日记与不可见规则（开放）

- Sources: `book-01-82fe54fd · segment-0044 · 行 8866-9031`；`book-01-82fe54fd · segment-0051 · 行 10082-10237`；`book-01-82fe54fd · segment-0057 · 行 11134-11311；book-01-82fe54fd · segment-0058 · 行 11312-11314`

- Transferable principle: 让世界知识同时具有收益和污染风险；每一次解释都应改变角色的知识状态，而不是只增加读者信息。
- Controls: 知识收益、传播半径、触发条件、验证成本、规则反例。
- Risks: 规则若永远不验证会显得玄学；解释过早会削弱后续恐惧。
- Confidence: medium

## 弧五：三级纜車与生产拐点（已支付）

- Sources: `book-01-82fe54fd · segment-0053 · 行 10454-10601`；`book-01-82fe54fd · segment-0054 · 行 10602-10776`；`book-01-82fe54fd · segment-0055 · 行 10780-10955`

- Mechanism: 系统奖励通过一个具体的“马上试用”场景落地，升级既改变战力，也改变信息保密难度。
- Transferable principle: 每个大升级都要在同一或下一章完成一次可见的接口测试，并产生新的社会暴露。
- Controls: 试用成本、产能上限、暴露程度、升级耗时、交易依赖。
- Risks: 产能无限会迅速摧毁资源经济；暴露没有后果会让隐瞒戏变成装饰。

## 截断点的状态

- Sources: `book-01-82fe54fd · segment-0100 · 行 17670-17716`
- Observation: 苏牧凭动态视觉看清高速敌人的轨迹，弱点锁定仍能命中，但 M500 对高护甲只造成极低伤害；强敌不是单纯“看不见”，而是“看得见但输出不足”。
- Mechanism: 悬念落在能力组合的边界，而不是是否拥有能力。
- Transferable principle: 在章末让旧能力部分成功、部分失效，下一章的问题就会是可计算的策略转换，而不是凭空升级。
- Controls: 信息成功率、伤害有效率、可替代武器、时间压力、队友可见度。
- Risks: 下一次解决若只靠新道具，会回收前面边界测试的价值；应让方案消耗已有资源或改变关系。
- Confidence: high
