## 2. Findings（17 条）

### F1. 进入场景时先定位，再让身体动作启动

- **事实**：开篇先给区域、村庄、农田和天色，再进入山顶、呼吸、视线和修炼；后段猎杀也先给夜色、空间安静、目标距离，再进入隐身和连招。
- **强推断**：常用 `镜头落点 → 感官细节 → 身体动作 → 能力/心理解释` 的四步入口。可用于让读者先知道人在哪里、正在看什么，再接受规则信息。
- **弱推断/待复核**：这更像通用网文场景模板，不应当当作每一节都必须遵循的固定顺序。
- **置信度**：高。
- **证据**：`book-01-bcc78727 / segment-0001 / 行3-25`；`book-01-bcc78727 / segment-0340 / 行70363-70387`。

### F2. 感官以视觉为主，声音、触觉、温度和嗅觉做触发器

- **事实**：开篇反复写颜色、光线、眼睛和远景；家庭场景补入饭香、酒气；战斗场景用爆鸣、尖叫、压力、疼痛把技能结果实体化。
- **强推断**：感官不是均匀铺陈，而是以视觉建立空间，以声响或身体受压标记转折，以气味/味觉强化生活落差。控制面板应按 `视觉 50–70%，听觉/触觉合计 20–35%，嗅味 5–15%` 设置起点，再按场景改写。
- **弱推断/待复核**：视觉占比来自词汇观察，不是经过中文语义标注的精确通道分类。
- **置信度**：中高。
- **证据**：`book-01-bcc78727 / segment-0001 / 行9-25`；`book-01-bcc78727 / segment-0002 / 行63-81、行149-155`；`book-01-bcc78727 / segment-0300 / 行61236-61270`。

### F3. 词汇语域是口语化叙事包住高密度技能/制度词

- **事实**：日常对话使用“爸爸、哥、吃饭、走吧”等亲近口语；同时直接解释武魂等级、学院制度、毒物配方、帝国与宗门规则，专名和等级词密集。
- **强推断**：可把语域拆成两层：叙事层保持直白、动作层保持可视化，规则层允许术语和序列化定义；不要让所有句子都变成古雅或技术说明。
- **弱推断/待复核**：术语密度随世界设定推进而变高，和纯粹的文风偏好无法完全分离。
- **置信度**：高。
- **证据**：`book-01-bcc78727 / segment-0005 / 行243-251`；`book-01-bcc78727 / segment-0260 / 行51622-51630`；`book-01-bcc78727 / segment-0379 / 行78598-78628`。

### F4. 句法偏并列推进，逗号是主要节拍器

- **事实**：逗号约 134,452 个，句号约 101,702 个，分号只有约 95 个；长句常用“同时、于是、只是、但、而”串联动作、解释和结果。
- **强推断**：句法控制应优先调“逗号分句数量”和“每个分句是否产生新动作/信息”，而不是只看平均句长。战斗段可提高动作分句密度，情感段可保留停顿和未完成句。
- **弱推断/待复核**：后段出现大量断句缺失，原始标点节拍可能比规范化文本更规整。
- **置信度**：中高。
- **证据**：`book-01-bcc78727 / segment-0003 / 行149-173`；`book-01-bcc78727 / segment-0340 / 行70375-70399`；统计定位：`book-01-bcc78727 / segment-0001—segment-0379 / 全文行1-78708（跨段统计）`。

### F5. 句段节奏是短反应 + 中段推进 + 偶发长块

- **事实**：全书句子粗切中位约 19–20 字，P75 约 31–35 字；对话中 ≤10 字的短回应约四分之一，11–30 字是最大桶，>120 字约一成以内。教学、策略、诀别和制度收束会形成长块。
- **强推断**：可用三档节拍：短句负责反应/拒绝/确认，中句负责交换事实，长句只承担一项完整解释或一次情绪揭示；长句之后应放动作、沉默或选择。
- **弱推断/待复核**：后段长行变多与 segment 粒度和段落粘连混杂，不能直接把行长当作作者句长。
- **置信度**：高（分布）；中（原始节拍解释）。
- **证据**：`book-01-bcc78727 / segment-0020 / 行1111-1129`；`book-01-bcc78727 / segment-0160 / 行20689-20709`；`book-01-bcc78727 / segment-0379 / 行78518-78530`。

### F6. 抽象规则和具体动作交替出现

- **事实**：锻造段把锤击次数、火炉、铁块和内力写成具体操作，随后抽象成“百炼成钢”的成长解释；学院段先定义称号，再把规则落到入学/毕业和实战；幻境段先抽象解释“爱”的弱点，再用递护腕、停手和落泪呈现。
- **强推断**：每次规则说明后应尽快落回一个可观察动作；每次情绪抽象后应给一个物件、身体姿势或空间距离。
- **弱推断/待复核**：抽象/具体比例未做人工语义标注，只能作为写作设计轴。
- **置信度**：高。
- **证据**：`book-01-bcc78727 / segment-0003 / 行149-173`；`book-01-bcc78727 / segment-0005 / 行247-251`；`book-01-bcc78727 / segment-0360 / 行74360-74382`。

### F7. 情绪主要外显为眼、脸、声音、姿势和动作

- **事实**：`身体`、`笑`、`目光`、`眼中`、`声音`等词高频；唐昊的激动通过拳头、颤抖和眼中晶莹表现，凌岳的生气通过挣脱、转头、抿嘴和不回答表现，比比宸的情绪通过血、咳嗽、笑和手的落下表现。
- **强推断**：情绪控制应优先写“身体证据”，再用一句内心解释校准读者，而不是每次直接命名情绪。
- **弱推断/待复核**：有些段落同时给出身体表现和心理结论，若用于新稿需要主动删减其中一层，否则会过度解释。
- **置信度**：高。
- **证据**：`book-01-bcc78727 / segment-0010 / 行553-573`；`book-01-bcc78727 / segment-0280 / 行56638-56654`；`book-01-bcc78727 / segment-0379 / 行78480-78508`。

### F8. 反复的状态副词和身体名词构成明显表面纹理

- **事实**：`突然`、`顿时`、`似乎`、`淡淡`、`缓缓`、`微微`以及“身体/目光/眼中/脸上”构成高频骨架；开篇呼吸与紫气段连续使用渐变、淡色、凝视和缓慢动作。
- **强推断**：重复是节拍工具，可保留少量作为风格锚点，但在同一场景内应设置替代词或直接改写动作，避免每次情绪变化都靠“目光一变/身体一颤/淡淡一笑”。
- **弱推断/待复核**：频次包含角色名、技能段和规范化重复，不能按词频直接判定为病句。
- **置信度**：中高。
- **证据**：统计定位：`book-01-bcc78727 / segment-0001—segment-0379 / 全文行1-78708（跨段统计）`；局部样本：`book-01-bcc78727 / segment-0001 / 行9-25`；`book-01-bcc78727 / segment-0340 / 行70353-70399`。

### F9. 转场常由时间/声音/动作信号直接切入

- **事实**：文本使用“正在这时”式突发信号、钟声召集、说完后离场、章节末的时间跳跃等方式切换场景；开篇出现明显的时间跳接，中段由钟声把食堂闲聊推向操场，后段由对话结束接入神界尾声。
- **强推断**：转场最小单元可以是 `离开动作 + 新地点锚点 + 新目标/威胁`；若要快切，至少保留一个声音、物件或时间标记。
- **弱推断/待复核**：部分空行和省略号可能是原文分段，也可能是规范化切片，不宜据此判断所有转场节奏。
- **置信度**：中高。
- **证据**：`book-01-bcc78727 / segment-0060 / 行3607-3615`；`book-01-bcc78727 / segment-0100 / 行6091-6095`；`book-01-bcc78727 / segment-0379 / 行78586-78600、行78646-78654`。

### F10. 场景/概述比例随段落功能变化，不能用全书单一比例覆盖

- **事实**：开篇有较多地理、身世、规则概述；中段既有解释性群聊，也有逐招战斗；后段对白引号内容占区字符下降，但战斗和制度收束中的长叙述增加。该比例是引用内容的代理值，不是人工场景分类。
- **强推断**：建议按功能切换：新世界/新势力用“概述 40–60%”；关系冲突和战斗用“场景 70–90%”；大战后的政治善后可暂时回到“概述 40–60%”，但每 1–2 段仍要有可见选择。
- **弱推断/待复核**：后段对白占比下降可能被长段合并、引号损伤和章节长度变化放大；不能把 16.7% 当作原始对白真实比例。
- **置信度**：中。
- **证据**：`book-01-bcc78727 / segment-0005 / 行243-251`；`book-01-bcc78727 / segment-0340 / 行70363-70400`；`book-01-bcc78727 / segment-0379 / 行78598-78644`；统计定位：`book-01-bcc78727 / segment-0001—segment-0379 / 全文行1-78708（跨段统计）`。

### F11. 对话话轮的主峰在 11–30 字，长话轮承担教学、战略或告白

- **事实**：对话单元中 11–30 字最多，短回应约四分之一；唐昊的资格测试、战队布置、临终揭示和帝国善后分别展示了短问答、策略长回合、告白长回合和条款式长回合。
- **强推断**：写作时先确定话轮功能：短回合改变态度，中回合交换信息，长回合只能完成一项“规则/计划/真相/请求”；长回合后必须让另一方拒绝、沉默、行动或重新定价。
- **弱推断/待复核**：引号嵌套和跨段粘连会把一个真实话轮拆成多个或合成一个，统计需在修复边界后重跑。

### F12. 沉默和不回答是状态动作，不只是留白

- **事实**：早段父亲冷眼使唐三吞回话；海神之光段凌岳挣脱、转头、不理会，唐三连续追问；终局大师先不说话，直到对方承认和解释后才开口。
- **强推断**：沉默应改变双方的行动许可或权力差：回避 → 追问 → 触碰/跟随 → 迫使对方表态；如果沉默后关系状态没有变化，就是无效停顿。
- **弱推断/待复核**：某些“没有说话”来自合并造成的缺句，需先核对引号边界。
- **置信度**：高（局部场景）；中（全书规则）。
- **证据**：`book-01-bcc78727 / segment-0005 / 行255-267`；`book-01-bcc78727 / segment-0280 / 行56642-56654`；`book-01-bcc78727 / segment-0379 / 行78480-78508`。

### F13. 地位协商通过称呼、资格、许可和能力展示完成

- **强推断**：对话中的地位变化最好由一个可验证动作确认：允许/拒绝、让座/离场、收回威压、改用称谓、交付物件；不要只靠叙述说“他更受尊敬”。

### F14. 话题回避先由玩笑/转移维持，外部压力再逼出直接表态

- **事实**：奥斯卡与凌岳用“占上”“难听”等玩笑绕开关系确认；海神岛段凌岳不解释，唐三追问；终局比比宸先用对大师的爱与报复解释过去，再把请求落到儿子和赦免上。
- **强推断**：可把潜台词写成三步：先说可安全说的事实 → 用玩笑或沉默保护核心需求 → 由危险、承诺或死亡迫使核心需求显形。
- **弱推断/待复核**：终局大段告白含明显规范化缺字和标点损伤，只能提取“信息延迟后集中揭示”的结构，不应复制其措辞或因果细节。
- **置信度**：中高。

### F15. 角色之间有可辨声纹，但叙述标签会把声音拉平

- **事实**：唐三倾向于条件、计划、禁令和道德条款；凌岳倾向于亲昵称呼、追问、玩笑和情感确认；唐昊短、冷、带资格测试；大师正式、克制、能在公开场合顶住权威；奥斯卡长于自夸和调侃；戴沐白更像学院/队伍说明者。
- **强推断**：声纹应由 `句长分布 + 称呼 + 常用动作 + 话题边界 + 施压方式` 五个变量定义，而不是只换几个口头禅。
- **弱推断/待复核**：`道/点头/微笑/目光`等叙述标签在全书过于通用，角色差异有时由情节位置而不是语言本身提供。
- **置信度**：中高。
- **证据**：`book-01-bcc78727 / segment-0060 / 行3575-3601`；`book-01-bcc78727 / segment-0100 / 行6113-6137`；`book-01-bcc78727 / segment-0180 / 行26918-26930`；`book-01-bcc78727 / segment-0379 / 行78598-78628`。

### F16. 对话承担较高说明负载，但有效段落会把说明转成关系或选择

## 5. 风格风险与失效模式

1. **副词和身体部位模板化**（高）：`突然/顿时/似乎/淡淡/缓缓`叠加 `目光/眼中/身体/脸上` 会让不同情绪同形。修正：同一场景设重复上限；每次重复必须改变动作后果，或直接删掉状态副词。证据：`book-01-bcc78727 / segment-0001 / 行9-25`；统计定位同第 1 节。
2. **说明书式对白**（高）：等级、学院、毒物和政治条款可以连续出现，但若对方没有质疑、误解、拒绝或获利，信息不会变成戏。修正：每个信息块绑定一个说服对象和一项选择。证据：`book-01-bcc78727 / segment-0005 / 行247-251`；`book-01-bcc78727 / segment-0080 / 行4879-4919`。
