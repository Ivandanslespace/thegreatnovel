### F01｜地理不是背景，而是能力、贸易与风险的倍率器

- **Observation**
  - [事实，高] 圣魂村向诺丁城供应农产，诺丁城靠近星罗边境与贸易线；法斯诺行省本身位于两国边缘。`book-01-bcc78727 / segment-0001 / L3-L7`; `book-01-bcc78727 / segment-0004 / L191-L195`
  - [事实，高] 巴拉克是天斗的属国，索托城是粮食区和军事城市；星斗大森林横跨两国，海神岛则是西侧海域的独立海魂师世界。`book-01-bcc78727 / segment-0060 / L3617-L3631`; `book-01-bcc78727 / segment-0116 / L7211-L7275`; `book-01-bcc78727 / segment-0275 / L55466-L55472`
- **Mechanism**
  - [强推断，中] 行动者每跨一个区域，都会同时改变补给、交通、魂兽密度、武魂适配和政治管辖；陆地魂师与海魂师在各自环境中存在显著的场域加成。`book-01-bcc78727 / segment-0275 / L55466-L55488`; `book-01-bcc78727 / segment-0362 / L74920-L74938`
- **Transferable principle**：每个新地点至少绑定一个资源优势与一个环境/政治代价；地点切换必须改变行动方案，而不能只是换场景名。
- **Controls**：维护 `地点—管辖方—补给—环境倍率—已知路线—当前季节` 六列；跨城、跨国、跨海分别记旅行方式与耗时。
- **Risks**：瞬移式移动、把海神岛规则套到大陆、把森林/海域中的同等级对手写成等强，会破坏世界的梯度感。
- **Confidence**：高。

### F02｜帝国、属国、宗门与信仰组织是四层叠加的权力网

- **Observation**
  - [事实，高] 大陆至少由天斗、星罗两大帝国构成；王国可以自治但承担朝贡，帝国整体处于衰退状态。`book-01-bcc78727 / segment-0004 / L191-L195`; `book-01-bcc78727 / segment-0060 / L3617-L3625`
  - [事实，高] 昊天宗曾因冲突隐退，顶级宗门、武魂殿和帝国军政并不等价；终局又由天斗承诺十年内不向星罗开战，唐门退出帝国战争。`book-01-bcc78727 / segment-0161 / L21630-L21668`; `book-01-bcc78727 / segment-0379 / L78594-L78622`
- **Mechanism**
  - [强推断，高] 权力来源至少分为领土主权、宗门血统/技术、武魂殿资格网络、海神信仰四种；同一人物可同时拥有帝师、宗门、魂师和神位身份，冲突时需要明确优先级。
- **Transferable principle**：写政治冲突时先标记“谁拥有地、谁拥有军、谁拥有资格、谁拥有信仰”，不要把“国家”“宗门”“武魂殿”当作同一个机构。
- **Controls**：为每个势力记录辖区、资源、直属武力、合法性来源、对主角的已知身份和当前关系；每次身份变化都更新。
- **Risks**：宗门命令被误写成国家法令；海神岛的信仰凝聚力被误写成武魂殿式强权；帝国停战承诺被后续战争静默覆盖。
- **Confidence**：高。

### F03｜武魂殿以“分布式服务 + 资格凭证 + 执法武力”维持秩序

- **Observation**
  - [事实，高] 村级觉醒由遍布各地的武魂殿分殿执行，直属执事有统一服装和徽章，徽章同时编码称号级别与战斗类型。`book-01-bcc78727 / segment-0006 / L305-L315`
  - [事实，高] 猎魂森林设有军队、围栏、武魂殿许可和执法团；高等级许可需要武魂殿批准及贵族担保，六枚最高级凭证与顶级斗罗相关。`book-01-bcc78727 / segment-0034 / L2065-L2089`
  - [事实，高] 后期武魂帝国魂师仍以统一标志、等级服色和跨境猎魂行动出现。`book-01-bcc78727 / segment-0319 / L65678-L65706`
- **Mechanism**
  - [强推断，高] 武魂殿不是单一城堡，而是覆盖觉醒、登记、补贴、许可、执法和帝国动员的网络；凭证既是通行证，也是社会等级与风险承诺。
- **Transferable principle**：制度性组织要通过可见的日常接口体现——分殿、徽章、许可、担保、执法人员，而非只靠旁白说“它很强”。
- **Controls**：检查每次进入猎魂区、领取补贴、跨境行动是否有凭证/担保/执法后果；记录凭证归属与是否永久有效。
- **Risks**：无许可进入核心猎魂区、普通人随意获得顶级凭证、武魂殿从未派人调查关键魂师，会削弱组织可信度。
- **Confidence**：高。

### F04｜魂师经济同时依赖劳动、补贴、市场与灰色交易

- **Observation**
  - [事实，高] 初级学院的工读生以清扫、园务换取资源和日薪；不履行会被开除，毕业后取得魂环又会脱离工读身份。`book-01-bcc78727 / segment-0024 / L1411-L1436`; `book-01-bcc78727 / segment-0025 / L1437-L1443`; `book-01-bcc78727 / segment-0045 / L2629-L2682`
  - [事实，高] 史莱克靠学生武魂补贴、学生自付食宿维持，学院拒绝贵族资金并长期贫困。`book-01-bcc78727 / segment-0116 / L7281-L7291`; `book-01-bcc78727 / segment-0080 / L4881-L4895`
  - [事实，高] 高额拍卖以资格门槛、佣金、保密和人身商品化运作；形式上禁奴，实际由拍卖行绕开。`book-01-bcc78727 / segment-0156 / L19579-L19681`; `book-01-bcc78727 / segment-0156 / L19733-L19749`
- **Mechanism**
  - [强推断，高] “能否修炼”与“能否支付猎魂、食宿、药物、装备”是两条不同门槛；魂环让低阶魂师迅速改变身份，但资金仍决定安全与选择范围。
- **Transferable principle**：力量升级必须留下资源账；训练、猎魂、治疗、装备和交通至少有一种现实支付方式。
- **Controls**：维护金币/魂币、补贴、工读工资、拍卖账户、食宿和药物消耗；记录每次身份升级是否改变收入来源。
- **Risks**：穷学生突然拥有贵族级装备却没有来源；学院长期“贫穷”但无限供应药物和住宿；灰色制度只作为背景而不产生后果。
- **Confidence**：高。

### F05｜魂环是“称号闸门 + 个人猎杀权 + 短时窗口”，不是普通经验值

- **Observation**
  - [事实，高] 每跨称号既要达到前级魂力上限，也要获得魂环；魂师知道魂环来自魂兽猎杀，环色与年限对应。`book-01-bcc78727 / segment-0008 / L433-L455`; `book-01-bcc78727 / segment-0032 / L1943-L1961`
  - [事实，高] 通常必须由本人完成最后一击，魂环只短暂存在；未在约一小时内吸收会消散。`book-01-bcc78727 / segment-0037 / L2247-L2253`; `book-01-bcc78727 / segment-0032 / L1953-L1959`
  - [事实，高] 野生魂兽没有人类所有权，争夺同一魂环时按魂师界的力量规则分配。`book-01-bcc78727 / segment-0118 / L7975-L8019`
- **Mechanism**
  - [强推断，高] 魂环制度把资源稀缺、个人资格、团队协作和暴力竞争绑定在一起；“有人帮忙”只能提高找到和控制目标的概率，不能完全替代个人承受与吸收。
- **Transferable principle**：任何升级节点都要同时验证资格、目标归属、最后一击、吸收时限和吸收结果。
- **Controls**：建立 `魂力等级—魂环序号—魂兽—年限—颜色—技能—吸收地点—窗口结束` 记录；关键环出现前禁止只写“获得了”。
- **Risks**：把魂环写成可交易物；跳过一小时窗口；把团队击杀自动当作所有成员都能得到环；忘记环本身不可随意改写。
- **Confidence**：高。

### F06｜武魂—魂环适配有方向性，蓝银草是低排斥但非无代价例外

- **Observation**
  - [事实，高] 大师要求同一武魂的后续魂环尽量保持方向一致，以免属性冲突；武魂会排斥相克魂环，兽武魂吸收毒性可能反伤宿主。`book-01-bcc78727 / segment-0028 / L1651-L1687`
  - [事实，高] 蓝银草因弱小、植物性和低排斥，被提出可以吸收兽环；该路线先是理论，后来由唐三实际测试。`book-01-bcc78727 / segment-0041 / L2415-L2447`
  - [事实，高] 首环效果由武魂、魂环变异生成，缠绕、麻痹、毒和韧性形成控制系方向，但火属性仍是明确反制。`book-01-bcc78727 / segment-0043 / L2563-L2574`; `book-01-bcc78727 / segment-0044 / L2575-L2593`; `book-01-bcc78727 / segment-0125 / L10337-L10363`
- **Mechanism**
  - [强推断，高] “低排斥”不是万能兼容，而是允许更宽的试错区间；真正效果仍由属性、年限、武魂成长和身体承受共同决定。
- **Transferable principle**：给异常适配安排“理论—风险—首次验证—后续边界”四步链，不要把一次成功泛化成规则无条件成立。
- **Controls**：每次吸收前记录属性冲突、理论依据、替代方案和失败后果；吸收后记录技能是否改变既有打法。
- **Risks**：所有植物环都默认安全；控制系突然获得无成本攻击；忽略火等明确 counter；用后来的神力解释早期普通魂环。
- **Confidence**：高。

### F07｜越级魂环是可成立的异常路径，必须保留身体与意志代价

- **Observation**
  - [事实，高] 首环、三环等存在明确年限上限；第三环通常约一千七百年上下，后续各环上限逐级增加。`book-01-bcc78727 / segment-0036 / L2167-L2173`; `book-01-bcc78727 / segment-0123 / L9555-L9575`
  - [事实，高] 唐三吸收超过三环常规上限的人面魔蛛环，文本将双生武魂、玄天功、意志和救凌岳的动机列为共同条件，同时明确风险极高。`book-01-bcc78727 / segment-0123 / L9555-L9615`
  - [事实，高] 后续神力、冰火保护、外附魂骨等又使十万年环成为特例，但仍伴随长时间、身体破损和精神压力。`book-01-bcc78727 / segment-0164 / L22380-L22380`; `book-01-bcc78727 / segment-0168 / L23626-L23701`; `book-01-bcc78727 / segment-0169 / L23702-L23876`
- **Mechanism**
  - [强推断，高] 常规上限是世界的安全边界，不是绝对数学墙；突破边界需要叠加性条件且不可作为普遍训练方法。
- **Transferable principle**：异常成功必须具备“触发条件—即时伤害—收益—不可复制性”四联单。
- **Controls**：续写中遇到越级吸收，强制复核身体储备、魂骨保护、意志动机、恢复时间与是否有后续功能损伤。
- **Risks**：主角特权扩散到配角；越级没有伤害或恢复期；把“神赐/献祭/冰火”混成同一种越级机制。
- **Confidence**：高。

### F08｜双生武魂是分阶段解锁的隐性系统，不是简单叠加两套技能

- **Observation**
  - [事实，高] 唐昊要求隐瞒昊天锤、不为其加环；只要一个武魂有环，双生武魂的魂力瓶颈即可消失。`book-01-bcc78727 / segment-0010 / L565-L614`; `book-01-bcc78727 / segment-0011 / L615-L617`
  - [事实，高] 大师再次禁止公开昊天锤与加环，并要求先确定蓝银草方向；双武魂的魂环方向和身体承受需要长期规划。`book-01-bcc78727 / segment-0027 / L1607-L1619`; `book-01-bcc78727 / segment-0161 / L21690-L21727`
  - [事实，高] 成为海神继承者后，才允许唐三给昊天锤批量补环，并明确第八考要求两个武魂都到九环。`book-01-bcc78727 / segment-0308 / L63190-L63198`
- **Mechanism**
  - [强推断，高] 双生武魂的核心优势是“先用一个武魂解除瓶颈，再把高质量资源延迟投入第二武魂”；隐藏本身是生存机制，不是单纯性格选择。
- **Transferable principle**：为每个武魂独立维护环序、公开状态、承受上限与当前可用技能；跨武魂共享魂力时标记代价。
- **Controls**：在战斗、登记、比赛和神考中分别记录“展示了哪个武魂”；每次新环都检查是否违反父亲/导师/考核承诺。
- **Risks**：早期公开昊天锤；把蓝银皇九环自动复制到昊天锤；忘记双武魂九环才满足第八考。
- **Confidence**：高。

### F09｜魂骨是嵌入式器官与稀缺资本，外附魂骨则是可进化的危险接口

- **Observation**
  - [事实，高] 普通魂骨极稀有、昂贵且通常不由击杀者独占；标准魂骨有六块，外附魂骨另算，能随宿主成长。`book-01-bcc78727 / segment-0126 / L10439-L10481`
  - [事实，高] 外附八蛛矛与脊椎、肋骨相连，承载毒素与移动能力，隐藏和损伤都可能致命；其进化能力区别于普通魂骨。`book-01-bcc78727 / segment-0126 / L10481-L10505`; `book-01-bcc78727 / segment-0292 / L59460-L59462`
  - [事实，高] 四肢骨可以在特殊条件下移除，头部和躯干骨除非死亡不能取出；复活凌岳时，右臂骨、魂环、右腿骨再生都构成明确代价链。`book-01-bcc78727 / segment-0308 / L63156-L63181`; `book-01-bcc78727 / segment-0318 / L65220-L65278`
- **Mechanism**
  - [强推断，高] 魂骨既是技能载体，又是身体结构和身份凭证；它的转移会同时改变战力、外观、伤势和知识状态。
- **Transferable principle**：所有魂骨必须有身体部位、来源、技能、是否外附、是否公开、可否移除六项属性。
- **Controls**：剥离、替换、进化、铠化各自记为状态迁移；不能只在战力表里增减数值。
- **Risks**：把魂骨当装备随手取放；忽略外附骨的致命依附；复活或神装后仍沿用已归还魂骨的技能。
- **Confidence**：高。

### F10｜魂兽是有领地、阶序、智慧与意志的资源主体

- **Observation**
  - [事实，高] 组团猎魂需要侦察、食物、恢复和绝对信任；高等魂兽不可圈养，野生魂兽的归属通过争夺决定。`book-01-bcc78727 / segment-0034 / L2051-L2073`; `book-01-bcc78727 / segment-0118 / L7975-L8019`
  - [事实，高] 泰坦巨猿具有人类级智慧；深海和海岛魂兽拥有族群、守护职责、交易边界与战斗使命。`book-01-bcc78727 / segment-0120 / L8515-L8669`; `book-01-bcc78727 / segment-0275 / L55528-L55558`
  - [事实，高] 自愿献祭可以绕开常规猎杀限制，留下魂环、魂骨和灵魂；大明、二明的献祭还直接改变唐三的双武魂配置。`book-01-bcc78727 / segment-0164 / L22380-L22380`; `book-01-bcc78727 / segment-0316 / L64842-L64954`
- **Mechanism**
  - [强推断，高] “猎杀获得资源”与“主体自愿转化”是两套不同制度；后者保留关系、承诺和死后灵魂影响，不能按普通掉落物处理。
- **Transferable principle**：每次获得高年限环/骨都应记录魂兽的意志状态、领地关系、最后一击或献祭同意，以及是否可能残留灵魂。
- **Controls**：把猎杀、争夺、护送、圣战、献祭分开建档；对十万年以上魂兽默认开启“灵魂残留检查”。
- **Risks**：只写魂兽年限不写族群政治；把自愿献祭写成免费升级；忽略百万年魂兽能在魂骨中伺机干预。`book-01-bcc78727 / segment-0360 / L74456-L74484`
- **Confidence**：高。

### F11｜毒、仙草与冰火两仪眼形成“高收益—高门槛—高互补”资源系统

- **Observation**
