# Distillation dimensions

Load only the sections selected by the user. Each observation needs a source ID and locator.

## Worldbuilding (`worldbuilding`)

Extract ontology, geography, history, factions, institutions, economy, technology or magic, resource flows, social norms, power distribution, rule costs, exceptions, enforcement, and how setting creates plot pressure. Distinguish stated rules from demonstrated rules and contradictions.

Output reusable design questions and causal patterns, not transplanted lore.

## Characters (`characters`)

Extract role, public goal, private need, fear, wound, value hierarchy, contradiction, capabilities, limitations, secrets, relationships, leverage, voice markers, decision patterns, state changes, and arc milestones. Represent relationships as directional.

## Plot (`plot`)

Extract premise, inciting disruption, commitments, turning points, reversals, crises, climax, resolution, subplots, setups/payoffs, information reveals, scene-level causality, and unresolved threads. Name the observed structure before mapping it to a known model.

## Style (`style`)

Extract operational traits rather than imitation prompts: diction register, sentence and paragraph distribution, syntax, figurative-language density, sensory channels, abstraction, emotional explicitness, repetition, transitions, punctuation, and contrast patterns. Produce configurable controls.

## Narrative (`narrative`)

Extract POV, tense, focalization, narrative distance, narrator reliability, interiority, exposition delivery, temporal order, scene/summary ratio, information asymmetry, suspense, surprise, and reveal strategy.

## Dialogue (`dialogue`)

Extract turn length, interruption, subtext, status negotiation, topic avoidance, idiolect construction, exposition load, action beats, silence, conflict escalation, and how dialogue changes scene state. Never preserve a catalogue of distinctive lines.

## Pacing (`pacing`)

Extract scene length, chapter length, event density, compression/expansion, sentence rhythm, cliffhangers, breathers, escalation intervals, viewpoint switching, and tension curves. Separate perceived pace from chronological duration.

## Themes (`themes`)

Extract thematic questions, competing answers embodied by characters, motifs, symbols, value conflicts, transformations, and how plot consequences test claims.

## Continuity (`continuity`)

Extract timeline, ages, locations, possessions, injuries, knowledge states, promises, rules, dependencies, unresolved questions, and immutable versus mutable canon. Record valid-at intervals.

## All (`all`)

Run every dimension, prioritizing causal links among them.
