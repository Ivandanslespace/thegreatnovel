# Narrative DNA

## 主角决策逻辑

唐三习惯先识别规则与对手边界，再把已积累的能力、伙伴、暗器和环境组合成非对称杠杆。他的关键决定通常围绕“保护伙伴、保留长期选择、以个人承担换取团队生存”展开。续写若只让外部任务推着他走，会破坏已建立的能动性。

## 成长与复利语法

成长不是单一数值升级，而是旧能力的重组与复利：唐门知识、双生武魂、魂环魂骨、领域、团队辅助、神位传承依次扩大策略空间。新阶段应保留这些成果，并以更高阶规则、职责、政治边界或信息差制造控制缺口。

## 压力与兑现

常见结构是规则说明与压力积累之后，以隐藏能力、团队协同或既有伏笔完成反转；大兑现之后通常需要战果确认、伙伴反应与新阶层入口。终局已经连续完成复活、双神融合与战争结束，续写开端更适合 `aftershock`、`relationship_shift` 或低至中压的新目标建立，不适合立即再堆同级神战。

## 关系演化

唐三与凌岳的关系以共同成长、互救和承担代价推进，终局把关系承诺与神力机制合并为双神共存。后续应通过行动、选择、职责分配和公开关系后果表现亲密变化，不能只用旁白宣布“更相爱”。

## 世界扩张

世界规模从村庄、学院、魂师赛事扩张到宗门、帝国、海域与神界。每次扩张都应保留旧成果并引入新的相对失控。五行大陆与神界异常可以成为更大世界入口，但必须先建立来源、代价、介入权限与为何此刻发生。

## 声音与节奏

- 第三人称叙述，以唐三及战斗相关角色的限知体验为主。
- 战斗段落倾向先解释能力规则与判断，再呈现招式组合、反制和结果。
- 章节常以局部胜负、能力揭示、危险反转或下一阶段入口收束。
- 群像战斗强调团队能力互补，但解释密度偏高；续写需避免连续多章重复“底牌揭示—对手震惊—更大底牌”。

## 重复与漂移风险

1. 神级战力已经触顶，继续用更大能量数字会损坏相对尺度。
2. 终局连续使用复活、融合和神位反转，短期内重复同类奇迹会削弱可信度。
3. 战后若再次让普通帝国战争成为主轴，会与唐三退出权力的承诺冲突。
4. 凌岳必须拥有独立目标与选择，不能只作为唐三的神力接口或情感奖赏。
5. 原文已明确完结；续写必须先选择是尾声、战后新篇还是跨世界新阶段，不能默认无缝接回旧高潮。
