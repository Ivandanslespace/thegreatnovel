# Future Possibility Space

以下路线全部是软候选，不是 Canon 或已批准大纲。

## ACTIVE（当前最自然但未获作者批准）

**战后余波与新生活边界**：从嘉陵关停战后的短期后果切入，让唐三与凌岳处理退出权力、婚礼安排、唐门军用体系收束与伙伴去向。结构签名：`aftershock -> relationship choice -> new responsibility`。它承接最近事实且不需要立即制造更大神敌。

## ALTERNATIVE A

**神界规则调查**：以五行大陆执行者遇害为远端异常，先调查信息来源和神的介入权限，再决定是否行动。结构签名：`mystery -> jurisdiction conflict -> constrained intervention`。不得在第一步假定唐三是唯一处理者。

## ALTERNATIVE B

**无主角常驻统治的大陆重建**：聚焦史莱克伙伴、唐门与帝国如何在唐三退出直接政治后处理战俘、技术扩散和停战承诺。结构签名：`political aftershock -> institutional choice -> social consequence`。唐三可作为约束或关键节点，但不能替所有人决定。

## ALTERNATIVE C

**伴侣共同体的新阶段**：以婚礼和双神共存后的职责分配为核心，让唐三与凌岳在私人关系、宗门、伙伴和神界义务之间作出有机会成本的选择。结构签名：`public commitment -> role negotiation -> shared mission`。

## WILDCARD

**五行大陆的规则不兼容**：远端异常最终揭示另一套力量 / 神界执行规则，与斗罗大陆既有神位逻辑并不完全兼容。结构签名：`foreign rules -> failed assumptions -> asymmetric learning`。这是高不确定候选，必须先补证据和反制，不能预设结局。

## Open Design Spaces

- 下一阶段采用唐三、凌岳、群像或新角色哪一种 POV 结构。
- 婚礼在第一章兑现、作为中期里程碑，还是只作为背景事实。
- 神界异常与大陆战后秩序哪一条先进入前景。
- 双神单次单一出手的限制在非战斗场景中意味着什么。
- 唐三不直接治理人间时，谁承担停战与技术约束的执行成本。
- 五行大陆信息是否仅为尾声彩蛋，还是实际续篇入口。

## Rolling Horizon 原则

- CURRENT：只承认第 379 章已经发生的状态。
- NEAR：允许设计战后余波、关系兑现和新目标建立。
- MID：允许选择一个新阶段矛盾并建立代价、对手与策略空间。
- FAR：只保留从大陆战后到神界 / 跨大陆尺度的阶段阶梯、控制缺口和开放问题；覆盖至少到等价第 758 章，不写逐章计划，不固定终局。
