## 主角与核心关系

- 唐三：海神 / 修罗神双神共存者。当前绝对能力已达神级，但主动退出人间统治；下一阶段不能用普通魂师或普通战争无因清零其既有成果。
- 凌岳：唐三的男性伴侣、裂空战狮能力链承载者、修罗魔剑与双神共存的共同完成者。正文已证明他在终局中主动保护唐三；不得把他降格为被动奖励或工具人。
- 唐三—凌岳：关系核心是长期同行、互救、共同承担神力风险与公开婚约。称呼中的“哥”是关系语境，不自动证明血缘或正式兄弟关系。
- 史莱克伙伴：仍是唐三的核心同盟。奥斯卡与宁荣辉承担了复活链关键环节；群像后续应保留各自目标与行动，而非只在主角出现时存在。

## 当前能力与硬边界

- 唐三的长期能力积累包括唐门绝学、双生武魂、魂骨 / 神装、海神权柄与修罗神力；后续冲突应来自更大尺度、职责、规则或信息缺口，而非随意削弱。
- 双神共存的明确限制是单次只允许一种神力发动。正文没有证明存在长期反噬，也没有证明可以无成本同时叠加两种神力。
- 神级复活分为肉身与神魂两层，分别由不同神力和信仰来源支撑；该事件不可被泛化成人人可复制的普通复活术。
- 神不应持续干预人间政务，是唐三退出权力的明确理由；若后续重新介入，必须出现神级威胁或与该承诺相容的桥梁事件。
