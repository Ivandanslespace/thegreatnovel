# Cross-Arc Contradiction Audit

## 当前结论

尚未发现足以阻断续写准备的当前边界矛盾。以下项目保留在 review queue，不能被系统静默修正。

## 结构与编号

- Source Store 的有效 ordinal 为 1–379，而章节正文标题编号到“第三百三十六章”，中间存在标题跳号和拆分 / 合并差异。这是文档结构问题，不自动等于故事时间线矛盾；续写锚点必须使用有效 ordinal 与 chapter_id，而非只信标题数字。

## 实体与代词

- 当前独立源中旧表面名 `小舞 / 胡列娜 / 千仞雪 / 比比东 / 宁荣荣 / 波赛西` 和代词 `她` 的全局词面命中均为 0；当前名 `凌岳 / 胡列昭 / 千仞霄 / 比比宸 / 宁荣辉 / 波赛川` 有稳定命中。
- 全局词面一致不证明每一处关系语义都正确。称谓、婚姻、亲属、身体描写和局部指代仍需以章节上下文审核；不得把机械替换结果直接升级为人物动机事实。

## 神力与复活边界

- 唐三复活由肉身与神魂两层构成，是终局特殊事件；不能泛化为无成本常规规则。
- 双神共存的明确限制是单次只由一种神力行动。正文没有确认长期反噬，也没有确认无限制双神叠加，两种说法都保持 UNKNOWN。

## 终局与未来

- 战争主线、比比宸敌手线和唐三退出人间权力已经闭合。任何重新开启必须有新事件和可见因果。
- 五行大陆信息只构成远端 hook；把它当作已批准续篇主线会把 CANDIDATE 静默升级为 Canon。
