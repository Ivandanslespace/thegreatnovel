## 2. Meaning Layer（INFERENCE，不是 Canon）

### 主角决策逻辑

跨 Arc 的稳定解释是“先识别规则与边界，再组合已有能力与伙伴形成非对称杠杆，最后以可见代价保护长期选择”。这来自海神考核中的规则越界撤离（`span_ad1b35a873b4c00df1d6f7fd`）、第八考中拒绝以放弃凌岳换取成神捷径（`span_a7ca9884b99311094ded00d`）和终局退出政治权力（`span_78e506ec415b579ab48eb2b9`）。它是高置信度的阅读模型，不是人物永远只能采取的公式。

### 成长与能力复利

成长主要通过旧能力重组扩大行动空间，而非单一数值膨胀：唐门暗器、双生武魂、魂环/魂骨、领域、团队协作、海神传承和修罗魔剑逐层叠加。Arc37 的海纳百川与复活链（`span_62c936cc3a9fdcf89a230ab3`、`span_bfec8b368e11c5b051e6f6aa`）说明能力价值来自组合与代价；Arc40 的“三环同吸”则是有来源的局部例外，不能抽象为任意越级许可。

### 压力、支付与兑现

常见节奏是规则可读化 → 期限/敌手施压 → 伙伴协同或底牌组合 → 局部控制 → 新层级缺口。重大兑现后应展示行为、关系和世界反馈；因此第 379 章之后更适合 `aftershock`、`relationship_shift` 或低至中压的新目标建立，而不是立刻复制一场更大的神战。指标中的 pressure/payoff/progress 观测只能诊断这种形态，不能证明文学效果或创造新事实。

### 关系演化

唐三—凌岳的关系不是称谓驱动，而是由共同承担复活代价、互救和公开承诺推进。称呼“哥/哥哥/兄弟”在早期是团队或昵称语境（`span_f40472f2eaaabb9134b7db26`、`span_b13758a8912afe6f7fc361ff`）；终局证据将性质收束为成年男性伴侣（`span_eeae31dd6055c25dbe5e42bf`、`span_78e506ec415b579ab48eb2b9`）。后续若继续写关系，应通过行动、分工、边界和机会成本表现变化，不能只用旁白宣布更亲密。

### 世界扩张

叙事尺度从村庄/学院/赛事扩展至宗门、海神岛、帝国、嘉陵关和神界方向。新尺度应保留唐三与凌岳已挣得的神级能力，同时引入职责、规则、权限和信息差造成的相对失控。五行大陆可以作为 `FAR/CANDIDATE` 的远端异常入口，但必须先补来源、路线、介入权限和代价，不能自动变成唯一主线。

## 3. Voice、节奏与结构语法（INFERENCE）

- 叙事倾向第三人称限知，战斗段先解释能力规则/判断，再呈现招式组合、反制与结果。
- 群像战斗依赖能力互补与高解释密度；章节常以局部胜负、能力揭示、危险反转或新阶段入口收束。
- 终局连续使用复活、融合、神位反转后，短期应主动冷却同类奇迹；“更大数字—更大敌人”的单轴升级会损坏相对尺度。
- 凌岳必须保持独立目标、判断和代价承受能力，不能退化为唐三的神力接口或情感奖励。
- 这些是软写作约束，不是硬评分公式；作者可以显式覆盖。

## 4. 重复风险与安全用法

1. 不重复“底牌揭示—对手震惊—更大底牌”的连续结构；至少改变来源、解决方式、关系后果中的两项。
2. 不在短窗口重复复活/融合/神位反转；应先写战后余波、制度反馈或共同生活边界。
3. 不把“哥/兄弟”改写为血缘，不把“阿岚/阿银/蓝银皇”按字符串相似度静默合并；实体 map 当前仍要求人工复核。
4. 不把 `PROVISIONAL` 指标语义估计当成事实；指标缺 source span 时保持诊断状态。

## 5. 当前开放设计空间

- `ACTIVE` 候选：战后余波与新生活边界。
- `ALTERNATIVE` 候选：神界规则调查、无主角常驻统治的大陆重建、伴侣共同体新阶段。
- `WILDCARD`：五行大陆的规则不兼容；只保留问题形状，不固定对手、路线或结局。
