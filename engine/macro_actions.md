# 宏观行动系统

## 适用场景

当玩家决定进行大规模、重复性行动时使用：
- 连续刷怪（一天杀几百只）
- 批量采矿/砍树/采集
- 大量制造/炼药
- 长时间训练
- 基地持续施工
- 连续航行
- 带队清理城区

## 玩家决策结构

玩家不逐次操作，而是决定：
```json
{
  "action_type": "GRIND_AREA / BATCH_CRAFT / MASS_HARVEST / TRAIN / BUILD / PATROL",
  "target": "目标对象",
  "goal": "停止目标（如：经验达到升级条件）",
  "stop_conditions": [
    "弹药少于X",
    "出现精英怪",
    "伤势超过轻伤",
    "距离撤离不足N分钟",
    "体力低于X%"
  ],
  "loot_policy": "全部回收 / 顺路回收 / 只取稀有",
  "risk_tolerance": "谨慎 / 标准 / 激进"
}
```

## 可刷取度公式 (Farmability)

```
Farmability =
  25% × 战力优势（玩家战力 / 目标平均战力）
+ 20% × 敌人情报完整度（已知信息 / 总信息）
+ 15% × 击杀稳定度（历史成功率）
+ 15% × 续航能力（弹药/体力/药剂可支撑时间）
+ 15% × 路线熟悉度（已探索比例）
+ 10% × 撤离能力（撤离点距离/安全性）
- 未知危险惩罚（区域未探索部分的风险）
```

## 处理方式

| Farmability分数 | 处理方式 |
|---:|---|
| 0-39 | 每场战斗详细处理（逐次决策） |
| 40-59 | 批量模拟3-10只（一次决策覆盖） |
| 60-79 | 模拟几十只（蒙太奇+结算） |
| 80+ | 允许长时间刷怪（压缩叙述+总结算） |

## 批量结算计算

```
总击杀数 = 可用时间 / 单次遭遇平均时间
总经验 = 总击杀数 × 单只经验 × 等级衰减系数
总掉落 = 总击杀数 × 掉落率 × 掉落品质分布
总消耗 = 总击杀数 × 单次弹药/体力消耗
资源回收 = 总掉落 × 回收率（根据loot_policy）
```

## 强制中断条件

无论Farmability多高，以下情况必须中断并回到逐次决策：

1. **升级**：经验达到升级阈值 → 触发三选一
2. **精英/BOSS出现**：区域刷新精英或首领
3. **稀有掉落**：紫色以上物品出现
4. **资源阈值**：弹药/体力/药剂达到stop_condition
5. **环境变化**：天黑/天气变化/灾难预警
6. **NPC重大行为**：队友遇险/势力行动/背叛
7. **新地点发现**：未探索区域入口出现
8. **死亡风险骤升**：区域警戒度触发增援
9. **异常事件**：秘境入口/隐藏任务/怪物战争

## 叙述方式

### 低Farmability（详细）
正常战斗叙述，每次决策600-1500字。

### 中Farmability（批量）
```
[蒙太奇段落：200-400字概括过程]
[系统结算框]
[如有中断事件，切入详细叙述]
```

### 高Farmability（压缩）
```
[一段话概括：100-200字]
[完整系统结算框]
[中断事件（如有）]
```

## 结算框格式

```
【宏观行动结算】
━━━━━━━━━━━━━━━━━━
▸ 行动：刷取猫妖 × 310只
▸ 耗时：6小时23分
▸ 经验：+5,260（Lv4→Lv5进度 78%）
▸ 掉落：诡晶×217 / 猫妖皮×89 / 绿色匕首×2
▸ 消耗：箭矢×338 / 体力-65% / 轻伤（左臂）
▸ 区域影响：猫妖密度↓ / 警戒度↑ / 首领注意
▸ 中断原因：弹药低于阈值
━━━━━━━━━━━━━━━━━━
```

## 区域影响

宏观行动会改变区域状态：
```yaml
area_changes:
  monster_population: -310    # 怪物数量减少
  alertness: +25              # 警戒度上升
  resource_depletion: -15%    # 资源消耗
  boss_awareness: true        # BOSS开始注意玩家
  respawn_timer: 72h          # 刷新计时
```

警戒度过高会触发：
- 怪物增援
- 精英巡逻队
- BOSS主动出击
- 区域临时封锁
