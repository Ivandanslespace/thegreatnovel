# 探索系统规则

## 三种游戏模式

### 模式一：开放探索
```
选择地点 → `TRAVEL`/`ENTER_LOCATION` → `EXPLORATION` → 搜索/战斗/收集 → `EXTRACT` → 返回基地
```

规则：
- 每天（或每个时间单位）有有限次探索机会
- 进入后地图有迷雾，需要逐步探索
- 有明确的时间压力（天黑/氧气/辐射等）
- 活动遭遇中不能用普通移动或 `REST` 绕过空间约束，必须用 `EXTRACT` 或 `LEAVE_ENCOUNTER`
- `EXTRACT` 会消耗地点注册表规定的撤离时间/体力，并关闭当前遭遇
- 未撤离时死亡 = 失去所有本次收获

### 模式二：副本任务
```
进入副本 → 系统公布规则 → 完成目标 → 结算奖励 → 返回
```

规则：
- 副本有独立局部规则（可能禁用某些能力）
- 有明确任务目标（击杀/收集/存活/解谜）
- 有推荐战力（低于推荐仍可进入，但极危险）
- 首通有额外奖励
- 失败不一定死亡，但可能失去进入资格

### 模式三：基地防守
```
收到预警 → 准备防御 → 敌人来袭 → 战斗结算 → 修复升级
```

规则：
- 周期性触发（灾难日/夜间袭击）
- 防御成功：保住基地+获得防守奖励
- 防御失败：基地受损/模块被毁/资源被抢
- 完全失败：基地毁灭（可能是游戏结束）

## 探索区域生成

每个探索区域包含：

```yaml
area:
  name: 区域名称
  level_range: [最低等级, 最高等级]
  danger_level: 1-10
  time_limit: 探索时限
  terrain: 地形类型
  features:
    - 可搜索建筑数量
    - 自然资源点
    - 宝箱（固定/随机）
    - 怪物分布
    - 隐藏事件
    - 撤离点位置（1-3个）
  special_rules: 区域特殊规则
```

## 搜索机制

### 建筑搜索
```
搜索时间：5-15分钟（游戏内）
发现概率：
  普通物资：60%
  有价值物品：25%
  稀有物品：10%
  陷阱/怪物：5%（危险建筑更高）
```

### 宝箱
```
宝箱等级：灰色/青铜/白银/黄金/铂金
开启需要：时间 + 可能需要钥匙/破解
内容：根据等级和区域决定
  灰色：基础物资
  青铜：F~E 级装备或中级材料
  白银：D~C 级装备或稀有材料
  黄金：B~A 级装备或特殊图纸
  铂金：S 级以上装备或规则类道具
```

宝箱等级与装备/天赋评级是两个维度：宝箱决定奖池范围，装备和天赋的 `rarity`
始终使用 `G/F/E/D/C/B/A/S/SS/SSS`，不能把宝箱名称当成物品评级。

### 采集
```
自然资源：矿石/木材/草药/水源
采集需要：对应工具 + 时间
产出：1-5单位（取决于工具和技能）
```

## 撤离机制

### 撤离点
- 每个区域有1-3个撤离点
- 撤离点可能需要：
  - 到达即可（最简单）
  - 清除周围怪物
  - 消耗燃料/道具
  - 等待读条（30秒-3分钟，期间可能被打断）

### 撤离失败
- 时间耗尽：强制随机传送（失去50%本次收获）
- 死亡：失去所有本次收获
- 被困：需要等待下一个时间窗口

## 时间系统

```
一天分为：
  清晨（安全，适合准备）
  白天（主要探索时间）
  黄昏（危险增加，怪物活跃）
  夜晚（极危险，特殊怪物出现）
  
探索时限通常 = 白天剩余时间
夜间探索：危险 ×2，但掉落评级提升1档（最高不超过SSS）
```

## 情报系统

如果玩家有情报类天赋：
```
每日情报内容（随机1-3条）：
  - 宝箱精确位置和等级
  - 区域危险分布
  - 怪物等级和数量
  - 特殊事件预告
  - 隐藏资源位置
  - 其他玩家/NPC动态
  - 撤离点状态
```

没有情报天赋时：
- 只能依靠观察（进入后逐步发现）
- 可以从NPC/交易获取部分情报
- 可能踩雷

## 区域难度递进

```
第1-10天：新手区域（Lv1-3怪物，基础资源）
第11-30天：中级区域（Lv3-6，需要装备）
第31-60天：高级区域（Lv6-10，需要团队或强力天赋）
第61天+：危险区域（Lv10+，需要完整构筑）

每个新区域至少改变两个变量：
  地形 / 规则 / 资源目标 / 敌人行为 / 撤离方式 / 时间条件
```

## 隐藏事件

每个区域有5-15%概率触发隐藏事件：
- 发现秘境入口
- 遭遇NPC求救
- 发现其他玩家尸体（可搜刮）
- 触发怪物战争（可观望/捡漏/逃跑）
- 发现旧文明遗迹
- 系统临时任务

隐藏事件不是凭空出现——必须有环境预兆（至少一句描写暗示）。

## 副本系统（详细）

### 副本结构

每个副本必须定义：
```yaml
dungeon:
  id: 唯一标识
  name: 副本名称
  difficulty: 难度评级(1-10)
  recommended_power: 推荐战力
  
  # 进入条件
  entry:
    level_requirement: 最低等级
    item_requirement: 所需物品（如钥匙）
    time_window: 开放时间窗口
    max_players: 最大进入人数
    faction_restriction: 势力限制（如有）
  
  # 时间
  duration: 持续时间
  time_pressure: 时间压力描述
  
  # 规则
  public_rules: []            # 进入时公布的规则
  hidden_rules: []            # 需要发现的隐藏规则
  disabled_abilities: []      # 禁用的能力/天赋
  special_mechanics: []       # 特殊机制
  
  # 任务
  objectives:
    primary: 主要目标
    secondary: []             # 次要目标
    hidden: []                # 隐藏目标
  
  # 失败条件
  failure_conditions: []
  
  # 奖励
  rewards:
    completion: 完成奖励
    first_clear: 首通奖励
    hidden_objective: 隐藏目标奖励
    rank_based: 排名奖励（如适用）
  
  # 撤离
  can_exit_early: true/false
  exit_penalty: 提前退出惩罚
  
  # 环境
  environment:
    terrain: 地形
    hazards: []               # 环境危害
    resources: []             # 可获取资源
    npcs: []                  # 副本内NPC
```

### 副本类型

#### 生存型
- 目标：存活N小时/N天
- 特点：资源有限、环境恶化、怪物递增
- 冲突来源：资源争夺、谁先放弃

#### 资格淘汰型
- 目标：300人只有100个资格
- 特点：玩家互为竞争者
- 冲突来源：直接对抗、联盟与背叛、最后名额

#### BOSS型
- 目标：击杀指定BOSS
- 特点：需要团队配合、分阶段
- 冲突来源：伤害分配、谁拿首杀奖励、复活次数

#### 阵营对抗型
- 目标：两方或多方对抗
- 特点：被分配阵营、可能有间谍
- 冲突来源：阵营利益vs个人利益、叛变

#### 解谜规则型
- 目标：发现并利用规则通关
- 特点：隐藏规则、逻辑推理
- 冲突来源：信息共享vs独占、规则理解差异

#### 资源争夺型
- 目标：获取有限资源
- 特点：资源点固定、时间紧迫
- 冲突来源：路线冲突、先手优势、伏击

#### 基地防守型
- 目标：保护核心不被摧毁
- 特点：波次进攻、准备阶段
- 冲突来源：资源分配（修墙vs造武器）、谁守哪路

### 副本规则设计原则

副本规则应自然制造冲突：
- 300人只有100个资格 → 合作还是竞争？
- 任务共享但奖励只有一份 → 谁拿？
- 队伍人数超过可撤离名额 → 谁留下？
- 玩家死亡后资格可被继承 → 杀人动机
- 禁用天赋 → 回归基础能力，拉平差距
- 隐藏规则 → 信息就是权力

### 副本中的知识边界

```
进入时：只公布 public_rules
探索中：逐步发现 hidden_rules（需要观察/推理/NPC提示）
完成后：可能仍有未发现的 hidden_rules（增加重玩价值）
```

GM不能因为"玩家应该知道"就直接揭示隐藏规则。
必须通过环境线索、NPC对话、试错来发现。

### 副本结算

```yaml
dungeon_result:
  status: completed/failed/abandoned
  time_used: 实际用时
  objectives_met: []
  objectives_failed: []
  casualties: []              # 死亡/受伤的NPC/队友
  rewards_gained: []
  hidden_discovered: []       # 发现的隐藏内容
  hidden_missed: []           # 错过的隐藏内容
  relationship_changes: []    # 副本中关系变化
  consequences: []            # 对世界的影响
```
