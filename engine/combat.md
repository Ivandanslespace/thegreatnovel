# 战斗系统规则

## 核心原则

战斗不是比谁写得有气势。先算结果，再写过程。

## 行动结算公式

### 行动优势 (A)
```
A = 能力匹配(属性vs难度) 
  + 装备加成 
  + 准备程度(0-20) 
  + 情报优势(0-15) 
  + 队友协助(0-20) 
  + 环境优势(0-15)
  + 天赋/技能加成
```

### 行动阻力 (D)
```
D = 目标基础难度 
  + 环境惩罚 
  + 伤势惩罚 
  + 疲劳惩罚 
  + 时间压力(0-20) 
  + 隐藏风险(0-30)
```

### 成功概率
```
P = sigmoid((A - D) / K)
其中 K = 10（标准波动）
     K = 6（硬核模式，波动更小，更致命）
     K = 14（休闲模式，波动更大，更宽容）
```

## 结果六级制

根据 P 值和随机数，确定结果等级：

| P值区间 | 结果 | 典型后果 |
|---------|------|----------|
| P > 0.9 且随机>0.8 | 大成功 | 达成目标+额外收益+无消耗 |
| P > 0.7 | 普通成功 | 达成目标，正常消耗 |
| 0.4 < P < 0.7 | 代价成功 | 达成目标，但受伤/失去道具/关系恶化 |
| 0.2 < P < 0.4 | 局部失败 | 未达成目标，但能撤离 |
| 0.05 < P < 0.2 | 严重失败 | 失去关键资源/队友死亡/基地受损 |
| P < 0.05 或特殊条件 | 死亡 | 当前角色永久结束 |

## 战斗流程

### 1. 遭遇判定
```
是否被发现？
→ 先手权归谁？
→ 能否避免战斗？（逃跑/隐蔽/交涉）
```

### 2. 战术选择
玩家可选择：
- 正面强攻
- 诱敌/绕行
- 使用技能
- 使用道具
- 呼叫队友
- 逃跑
- 自由行动

### 3. 回合结算（简化）
不做逐回合战棋。一次战斗 = 1-3次玩家决策。

每次决策：
1. 玩家描述行动
2. 计算 A 和 D
3. 得出结果等级
4. 扣除消耗（弹药/体力/技能冷却）
5. 更新双方状态
6. 判断战斗是否结束

### 4. 战斗结束
- 胜利：获得经验、掉落物
- 逃跑：可能受伤，失去部分物资
- 失败：根据严重程度，受伤/被俘/死亡

## 伤害计算（简化）

```
基础伤害 = 武器攻击力 × (1 + 力量/20)
实际伤害 = 基础伤害 - 目标护甲 × 等级压制系数
等级压制系数 = 1 - (攻击者等级 - 防御者等级) × 0.1
  （最低0.3，最高1.5）
```

## 经验获取

```
基础经验 = 怪物等级 × 10 × 品质系数
品质系数：普通=1, 精英=2.5, 首领=5, 传说=10

等级衰减：
  玩家等级 - 怪物等级 > 3：经验 × 0.2
  玩家等级 - 怪物等级 > 5：经验 × 0.05
  怪物等级 - 玩家等级 > 3：经验 × 1.5（越级奖励）
```

## 掉落规则

```
掉落概率：
  普通怪物：30% 掉落盒
  精英怪物：80% 掉落盒
  首领：100% 掉落盒 + 保底稀有

掉落品质：
  白色 50% / 绿色 30% / 蓝色 15% / 紫色 4% / 黄色 1%
  （首领保底至少蓝色）
```

## 特殊战斗情境

### 多对一
- 队友协助：每个队友 +5-15 行动优势
- 但战利品需要分配
- 队友可能受伤或死亡

### 偷袭
- 偷袭方：准备程度 +20，先手权
- 被偷袭方：第一回合无法反击

### 群体战（怪物群）
- 数量优势转化为环境惩罚
- 每多一只同级怪物：D +5
- 超过5只：需要AOE或逐个击破

### BOSS战
- 分阶段（通常2-3阶段）
- 每阶段有不同攻击模式
- 需要玩家识别规律并调整策略
- 不允许一次决策直接结束

## 逃跑规则

```
逃跑成功率 = 0.4 + (敏捷差/20) + 环境因素
失败后果：受到一次免费攻击
成功：脱离战斗，但可能失去部分物资（负重过高时）
```

## 战斗中的天赋触发

规则类天赋（如弱点锁定、额外攻击）在战斗结算时自动触发：
- 弱点锁定：伤害 ×1.5，无视部分护甲
- 额外攻击：结算后追加一次 50% 伤害
- 弹射：对附近目标造成 30% 伤害
- 危险感知·格挡：每场战斗第一次被偷袭时自动触发

这些是**确定性效果**，不参与概率计算。
