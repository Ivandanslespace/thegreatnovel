# 叙事引擎规则

## 核心循环

每一轮互动遵循压力-释放循环：

```
产生问题 → 玩家预测 → 做出选择 → 等待结果 → 获得奖励 → 发现更大问题
```

关键：每个理由都很小（"我就看看这个宝箱是什么"），但它们首尾相接。

## 节奏控制

### 叙述长度
- 每次叙述：600-1500字
- 战斗场景：可延长到2000字
- 安静/情感场景：400-800字
- 系统公告：独立格式，不计入叙述

### 决策频率
- 普通决策：每2-5分钟阅读时间出现一次
- 重大选择：每3-6次普通决策出现一次
- 战斗中：只有真正影响战术的节点才中断
- 不要每两句话就问"你要开门吗？"

### 回合类型轮换
```
探索回合（紧张）
→ 基地回合（放松）
→ 社交回合（信息）
→ 副本回合（高压）
→ 灾难回合（危机）
→ 奖励回合（释放）
```

不要连续3轮以上同类型。

## 爽点调度

### 三级奖励体系

#### 小型横财（每8-15轮）
- 规模：1-3次普通行动收益
- 作用：维持奖励感
- 例：一次获得够制造30发子弹的材料

#### 阶段性资源解放（每30-60轮）
- 规模：某资源从"核心焦虑"降级为"日常消耗"
- 作用：叙事换挡，进入新阶段
- 例：获得几百枚核心资源，不再为基础消耗发愁
- 规则：同一种资源只"毕业"一次，下次换更高级资源

#### 篇章高潮（每80-120轮）
- 规模：改变世界格局或主角定位
- 作用：宣告进入全新阶段
- 例：击败区域BOSS/建立势力/发现世界真相碎片

### 资源暴增后必须立即改变玩法
```
资源暴增 → 确认数量 → 立即挥霍一部分 → 玩法升级 → 出现新瓶颈
```
只获得不消费 = 爽感打折。

### 稀缺性上移
```
前期缺基础资源
→ 获得大量基础资源
→ 基础资源不再是问题
→ 但升级需要更稀有的高级材料
→ 必须进入更危险区域
```

永远不要让玩家"什么都不缺"。

## 悬念管理

### 多时间尺度悬念
同时维护不同时间尺度的未解问题：

```
即时（1-3轮）：这个宝箱里是什么？能安全撤离吗？
短期（5-15轮）：这个NPC可信吗？副本怎么过？
中期（20-50轮）：这个势力的真正目的是什么？
长期（50-100轮）：这个世界到底是怎么回事？
终极（100+轮）：系统创造者是谁？试炼的终极目的？
```

### 悬念债务规则
- 每解决一个问题，产生1-2个新问题
- 不要让所有悬念同时解决
- 长期悬念可以偶尔给碎片线索
- 玩家有权永远不知道某些答案（如果角色死了）

### 伏笔系统
```yaml
foreshadowing:
  id: 唯一标识
  planted_turn: 埋设回合
  content: 伏笔内容
  payoff_condition: 揭示条件
  earliest_payoff: 最早揭示回合
  latest_payoff: 最晚揭示回合（超过则自动触发或废弃）
  current_status: active/triggered/expired
```

## 延迟后果

### 三类后果

#### 即时后果
马上发生：消耗资源、获得物品、受伤、NPC反应

#### 延迟后果
```yaml
delayed_event:
  event: 描述
  trigger_conditions: [触发条件列表]
  earliest_turn: 最早触发
  latest_turn: 最晚触发
  consequences: 后果
```

#### 隐藏后果
玩家暂时不知道：
- 被敌人标记
- NPC暗中降低信任
- 某组织开始调查
- 救下的人有隐藏身份

### 未来事件队列
每轮检查 event_queue.yaml：
```
对于每个待触发事件：
  if 当前回合 >= earliest_turn:
    if 触发条件满足:
      触发事件
    elif 当前回合 >= latest_turn:
      强制触发或废弃
```

## 死亡设计

### 死亡公平性公式
```
死亡公平度 = 
  风险提示充分度(0-1)
  × 因果链清晰度(0-1)
  × 可避免程度(0-1)
  × 规则一致性(0-1)
  × 玩家自主责任(0-1)
```

死亡前至少满足2-3个条件：
- 玩家收到过直接警告
- 环境中有可观察征兆
- NPC提醒过风险
- 情报中指出过危险
- 玩家主动选择高风险路线
- 玩家缺少本应提前准备的物资
- 连续多个不利决定
- 规则早已说明失败会死亡

### 死亡不应是
- 毫无预兆的即死
- 系统为了制造紧张而强行安排
- 因为LLM不知道怎么续写
- 对玩家"不听话"的惩罚

### 死亡应该是
- 一系列错误积累的终点
- 玩家能复盘出"哪里做错了"
- 规则一致的结果
- 有叙事重量的时刻

### 多级后果（不是所有错误都致死）

| 层级 | 后果 |
|------|------|
| 完美成功 | 达成+额外收益 |
| 普通成功 | 达成，正常成本 |
| 代价成功 | 达成，但受伤/失去/关系恶化 |
| 局部失败 | 未达成，但能撤离 |
| 严重失败 | 失去关键资源/队友死亡 |
| 战败 | 被俘/任务失败/失去阶段优势 |
| 死亡 | 角色永久结束 |
| 世界失败 | 基地毁灭/全队死亡 |

## 主角性格连续性

### 隐藏人格变量
```yaml
personality:
  caution: 0-100      # 谨慎程度
  ambition: 0-100     # 野心
  empathy: 0-100      # 共情
  honesty: 0-100      # 诚实
  risk_tolerance: 0-100  # 风险偏好
  collectivism: 0-100    # 集体主义
```

### 人格如何影响
- 不剥夺玩家选择权
- 影响内心独白语气
- 影响系统提供的默认选项排序
- 影响NPC对主角的评价
- 影响某些职业/能力解锁
- 当玩家做出"反性格"选择时，叙述中体现矛盾感

### 人格更新
每5轮根据玩家选择微调：
- 连续选择谨慎路线 → caution +3
- 连续选择冒险 → risk_tolerance +3
- 帮助NPC → empathy +2
- 欺骗NPC → honesty -3

## 世界扩展节奏

### 舞台升级时机
当玩家完全掌握当前层级的规则时，引入新维度：

```
第1-10轮：个人生存（学会基本操作）
第11-30轮：社交出现（NPC、交易、初步合作）
第31-60轮：组织出现（势力、公会、政治）
第61-100轮：世界真相碎片（旧文明、系统秘密）
第100+轮：文明级事件（跨势力冲突、世界变革）
```

### 机制换皮
底层循环不变，但表层目标不断变化：
- 前期关心食物和水
- 中期关心装备和等级
- 后期关心团队和势力
- 终局关心世界真相和文明命运

## 叙述风格指南

### 系统流口吻
- 系统公告冷静、简洁、无感情
- 小说叙述生动、有感官细节
- 两者交替出现形成节奏

### 战斗描写
- 先写结果（规则裁定），再写过程（小说化）
- 不要写成战报（"造成17点伤害"）
- 要有感官：声音、触感、气味、痛觉
- 天赋触发时用系统提示框标注

### 情感场景
- 不要过度煽情
- 通过行为和细节传达情感
- NPC对话要有个性差异
- 允许沉默和留白

### 信息密度
- 低理解成本，高决策密度
- 用系统面板代替长篇解释
- 物品/技能用结构化格式展示
- 不要在叙述中塞太多设定

## 软公式系统（剧情监控）

以下公式只用于监控和建议，不强制决定内容。GM每轮内心评估，不展示给玩家。

### 1. 压力值 (Pressure)

```
Pressure =
  25% × 生存威胁（当前敌人/环境危险程度）
+ 20% × 资源匮乏（ResourcePressure均值）
+ 20% × 时间压力（剩余时间/截止时间紧迫度）
+ 15% × 信息未知（当前危险中未知比例）
+ 10% × 人际冲突（活跃矛盾/背叛风险）
+ 10% × 失败累积（最近N轮失败次数）
```

阈值：
- 大爽点适合在 Pressure 70-90 时出现
- Pressure > 80 不宜持续超过5轮
- Pressure < 35 不宜持续超过8轮（需要制造新压力）

### 2. 爽点成熟度 (Maturity)

```
Maturity =
  25% × 稀缺压力（该资源/能力的匮乏程度）
+ 20% × 铺垫深度（之前为此刻做了多少准备）
+ 20% × 等待时间（距上次同类爽点的轮数）
+ 20% × 主角支付成本（为获得此刻付出了什么）
+ 15% × 篇章节奏（当前是否到了该释放的节点）
```

### 3. 爽点冲击力 (Impact)

```
Impact =
  25% × 相对收益规模（相对于当前水平的增益）
+ 25% × 解除限制程度（解除了什么束缚）
+ 20% × 行为改变（玩家行为方式是否因此改变）
+ 15% × 长期成长价值（对未来发展的意义）
+ 15% × 社会反馈（其他角色/势力的反应）
```

### 4. 综合爽点评分 (PayoffScore)

```
PayoffScore =
  0.25 × Maturity
+ 0.25 × Impact
+ 0.15 × Novelty（新颖度：是否第一次出现这类爽点）
+ 0.15 × Causality（因果感：玩家是否觉得是自己赚来的）
+ 0.20 × AftermathValue（后续价值：能否引发新玩法/新目标）
- 0.10 × Fatigue（同类爽点近期出现频率）
- 0.10 × StoryDamage（是否损害了其他叙事线）
```

PayoffScore > 70 → 适合安排大爽点
PayoffScore 40-70 → 可以安排小爽点
PayoffScore < 40 → 继续积累，不要急着发奖励

### 5. 悬念债务 (NarrativeDebt)

```
NarrativeDebt =
  重要程度(1-10)
  × 等待回合数
  × 重复提醒次数
  × 玩家可见度(0-1)
  ÷ 已推进程度(1-10)
```

- NarrativeDebt > 50 → 必须推进这条线
- NarrativeDebt > 100 → 紧急，玩家可能已经忘记或失去耐心
- 同时活跃的悬念不超过5条（避免认知过载）

### 6. 进展值 (Progress)

```
Progress =
  20% × 永久成长（属性/等级/技能不可逆提升）
+ 20% × 世界变化（地图/势力/格局改变）
+ 15% × 关系变化（NPC关系发生质变）
+ 15% × 情报变化（获得新的重要信息）
+ 15% × 目标推进（主线/支线目标前进）
+ 15% × 新玩法（解锁新系统/新区域/新能力）
```

### 7. 停滞率 (StagnationRate)

```
StagnationRate =
  最近N轮中没有不可逆变化的回合数
  ÷ N
```

- StagnationRate > 0.5 → 警告：故事停滞，需要引入变化
- 不可逆变化包括：升级/NPC死亡/势力消亡/区域解锁/关系质变/真相揭示

### 8. 重复疲劳 (RepetitionFatigue)

追踪最近10轮中同类事件出现次数：
```
监控列表：
  - 开宝箱
  - 系统公告
  - 怪物突袭
  - 聊天频道震惊
  - 隐藏实力打脸
  - 同类地图探索
  - 同类结尾方式
  - 同类资源暴富
  - 同类战斗结构
```

同类事件间隔 < 3轮 → Fatigue +30
同类事件间隔 3-5轮 → Fatigue +15
同类事件间隔 > 8轮 → Fatigue = 0

Fatigue > 60 → 必须换一种叙事方式

### 9. 选择有效性 (Agency)

```
Agency =
  选项价值平衡（每个选项是否都有理由选）
  × 后果差异（选A和选B的状态差异有多大）
  × 信息充分度（玩家是否有足够信息做判断）
  × 机会成本（放弃的选项是否真的失去）
  × 长期影响（这个选择是否影响5轮以后）
```

Agency < 0.3 → 这是伪选择，重新设计

### 10. 信息未知度 (Uncertainty)

```
Uncertainty =
  30% × 当前危险未知（敌人/环境中未知比例）
+ 25% × 规则未知（副本/区域中未揭示的规则）
+ 20% × 人物动机未知（NPC真实意图不明）
+ 15% × 世界真相未知（长期谜题未解比例）
+ 10% × 奖励未知（宝箱/掉落/结果不确定）
```

理想状态：玩家清楚当前问题和失败条件，但不知道最终结果。
Uncertainty < 20 → 太透明，需要引入新未知
Uncertainty > 80 → 太迷茫，需要给一些确定性

### 11. 风险可信度 (RiskCredibility)

```
RiskCredibility =
  实际代价兑现率（说了会受伤，是否真的受伤了）
  × 失败后果清晰度（玩家是否知道失败会怎样）
  × 敌人有效性（敌人是否真的构成威胁）
  × 信息不完整度（是否因为不知道而可能失败）
  × 保护机制有限度（保命手段是否有限）
```

RiskCredibility < 0.4 → 玩家会觉得"反正不会死"，选择失去重量
必须确保：系统说伤势影响战斗，后面就真的影响。系统说不可逆，就不能补发。

## 公式三级分类

### 硬公式（真正决定游戏结果）
- 战斗伤害和命中
- 成功概率 P = sigmoid((A-D)/K)
- 经验获取和升级
- 资源消耗和获取
- 建造时间和材料
- 技能冷却和消耗
- 死亡判定
- 宏观行动结算
- 掉落概率

### 软公式（只建议，不强制）
- Pressure（压力监控）
- PayoffScore（爽点时机）
- NarrativeDebt（悬念债务）
- Progress / StagnationRate（进展监控）
- RepetitionFatigue（重复检测）
- Agency（选择质量）
- Uncertainty（信息平衡）
- RiskCredibility（风险可信度）
- DecisionValue（决策密度）

### 无公式创作（LLM自由发挥）
- 小说叙述和文风
- 对话内容和语气
- 氛围营造
- 情感表达
- 反转创意
- 角色人格表现
- 世界审美
- 恋爱是否动人
- 牺牲是否感人
- 某个选择道德上对不对

软公式只能提醒"这里可能适合安排一次关系事件"，不能强制"好感达到60所以NPC必须表白"。

---

## 不应由公式决定的内容

以下内容可以让模型评审，但不应该由公式直接决定：

- 对话是否自然
- 角色是否有魅力
- 恋爱是否动人
- 某次牺牲是否感人
- 文风是否优美
- 场景是否恐怖
- 某个反转是否惊艳
- 人物是否应该表白
- 玩家行为在道德上对不对
- 世界最终真相是什么

它们由世界设定、人物性格、当前状态、LLM创作共同决定。
