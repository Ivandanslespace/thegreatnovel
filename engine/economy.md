# 资源经济系统

## 资源追踪

每种资源必须记录：
```yaml
resource:
  id: 唯一标识
  name: 显示名
  category: 基础/中级/稀有/特殊/货币
  current: 当前库存
  capacity: 储存上限
  income_rate: 平均每日收入
  consumption_rate: 平均每日消耗
  sources: [获取途径列表]
  uses: [用途列表]
  scarcity: 稀缺度(1-10)
  next_stage_need: 下一阶段需求量
  tradeable: 是否可交易
  market_price: 当前市场价（如有交易系统）
  renewable: 是否可再生
  regen_rate: 再生速率（如适用）
```

## 资源压力公式

```
ResourcePressure =
  30% × 当前缺口（需求 - 库存，归一化）
+ 20% × 消耗收入比（日消耗 / 日收入）
+ 20% × 最近受阻次数（因缺资源无法行动的次数）
+ 15% × 下一阶段需求（升级/建造所需 vs 当前库存）
+ 15% × 玩家可感知程度（是否频繁提到/想到）
```

### 压力阈值
| 分数 | 状态 | 叙事表现 |
|---:|---|---|
| 0-20 | 充裕 | 不提及资源焦虑 |
| 21-40 | 正常 | 偶尔计算 |
| 41-60 | 紧张 | 影响决策，需要规划 |
| 61-80 | 匮乏 | 限制行动，焦虑明显 |
| 81-100 | 危机 | 生存威胁，必须立即解决 |

## 资源暴富规则

资源暴富之前，压力必须积累到至少60+。

暴富后必须同时满足：
1. 永久解决一种旧瓶颈（该资源压力归零）
2. 立即改变玩家行为（叙述中体现）
3. 开启一种新玩法（如：自动防御/批量制造）
4. 引出更高级资源需求（稀缺性上移）

### 禁止
- 不能同时让所有资源无限
- 不能暴富后几十轮没有任何变化
- 不能同一种资源反复"暴富"（第二次必须换资源或换形式）

## 资源层级

```
第一层（开局焦虑）：食物、水、基础材料
第二层（中期需求）：金属、燃料、核心资源、弹药
第三层（后期稀缺）：高级合金、特殊核心、图纸、职业书
第四层（终局资源）：规则材料、世界碎片、神格
```

每层资源"毕业"后，焦虑转移到下一层。

## 制造系统

```yaml
recipe:
  id: 唯一标识
  name: 制品名
  inputs:
    - resource: 材料ID
      quantity: 数量
  output:
    item: 制品ID
    quantity: 数量
  time: 制造时间
  station: 所需工作台
  skill_requirement: 技能要求
  success_rate: 成功率（如有失败可能）
```

### 制造规则
- 需要对应工作台（基地模块）
- 需要对应材料（从库存扣除）
- 需要时间（期间不能做其他事）
- 部分有失败率（材料损失）
- 批量制造：时间 × 数量，但可被中断

## 交易系统（如世界启用）

### 市场机制
```
价格 = 基础价值 × 供需系数 × 稀缺系数 × 区域系数

供需系数：
  供大于求：0.5-0.9
  供需平衡：1.0
  供不应求：1.1-3.0
  极度稀缺：3.0-10.0
```

### 交易方式
- 玩家间直接交易（系统担保）
- NPC商店（固定价格，库存有限）
- 拍卖（稀有物品）
- 势力仓库（成员共享）
- 黑市（高风险高收益）

### 交易安全
- 系统交易：物品直接转移，无欺诈可能
- 线下交易：可能被抢/被骗
- 契约交易：违约有系统惩罚

## 经济平衡检查

每10轮检查：
```
对于每种资源：
  if 库存 > 10 × 日消耗 and 无新消耗渠道:
    → 需要引入新消耗（升级/灾难/势力税）
  if 库存 < 1 × 日消耗 and 无获取途径:
    → 需要开放新来源（探索/交易/事件）
  if 某资源完全无用:
    → 考虑移除或赋予新用途
```
