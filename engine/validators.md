# 校验器规则

## 核心原则

每次叙述生成后、提交事件前，必须通过以下六类校验。
校验不通过 → 重写或修正，不能强行提交。

## 一、连续性校验

检查叙述是否与已确立事实一致：

```
□ 地点：主角是否真的在这里？（不能瞬移）
□ 时间：当前是什么时段？经过的时间是否合理？
□ 伤势：之前受的伤是否还在影响？（不能突然痊愈）
□ 人物生死：已死角色不能出场（除非有合理机制）
□ 物品来源：提到的物品是否真的在背包中？
□ 距离：从A到B的时间是否合理？
□ 天气/环境：是否与当前世界状态一致？
```

### 常见违规
- 主角在战斗中突然出现在另一个地点
- 已消耗的物品再次出现
- 已死NPC突然说话
- 夜晚场景描写阳光

## 二、规则校验

检查是否违反世界硬规则：

```
□ 技能冷却：使用的技能是否已过冷却？
□ 升级材料：升级/建造是否消耗了正确材料？
□ 安全区：安全区内是否发生了禁止的行为？
□ 副本条件：是否满足进入/退出条件？
□ 世界硬规则：每日探索次数/撤离规则/死亡规则
□ 天赋限制：天赋使用是否满足触发条件？
□ 装备要求：是否满足属性/等级要求？
□ 负重：是否超过负重上限？
```

### 常见违规
- 冷却中的技能被使用
- 没有材料却完成制造
- 安全区内发生PVP
- 超过每日探索次数

## 三、知识校验

检查角色是否使用了不该知道的信息：

```
□ 主角是否引用了未获得的情报？
□ NPC是否说出了只有其他NPC才知道的秘密？
□ 系统面板是否显示了主角不应知道的数据？
□ 叙述是否提前泄露了未满足揭示条件的真相？
□ 玩家的"直觉"是否有可观察证据支撑？
```

### 常见违规
- 主角"感觉到"某个从未暗示过的秘密
- NPC提到只有另一个NPC才知道的信息
- 系统直接告诉玩家BOSS弱点（未通过情报/观察获得）

## 四、战力校验

检查战斗和行动结果是否合理：

```
□ 是否存在无理由越级秒杀？（差3级以上需要特殊条件）
□ 是否忽略了消耗和伤势？
□ 伤害数值是否与公式一致？
□ 是否凭空创造了新能力？
□ 规则类天赋触发是否有正当条件？
□ 多对一的数量优势是否被体现？
```

### 常见违规
- Lv3主角一刀秒Lv8精英（无特殊机制）
- 连续战斗无体力消耗
- 突然使用从未获得过的技能
- 100只怪物的围攻被轻松化解

## 五、关系校验

检查NPC行为和关系变化是否一致：

```
□ NPC态度是否与历史事件一致？（不能无故180度转变）
□ 承诺和背叛是否被记住？
□ 关系数值变化是否有对应事件？
□ NPC是否做出了违反性格的行为？
□ 势力态度是否与玩家行为匹配？
□ 情感关系发展是否有足够铺垫？
```

### 常见违规
- 被玩家欺骗的NPC突然毫无芥蒂地合作
- 关系从陌生直接跳到亲密（无事件支撑）
- NPC忘记被背叛
- 势力对玩家的敌意凭空消失

## 六、叙事校验

检查本轮叙述的质量和方向：

```
□ 本回合是否有目标？（不能纯闲逛无方向）
□ 是否与最近3轮重复？（同类事件/同类结构）
□ 是否有进展？（状态是否发生了不可逆变化）
□ 是否错误提前揭露秘密？
□ 节奏是否合理？（不能连续高压或连续平淡）
□ 选择是否有真实后果？（不能伪选择）
□ 叙述长度是否适当？（600-1500字）
```

### 常见违规
- 连续5轮都是"进入-杀怪-开箱-撤离"
- 选择A和选择B导向完全相同的结果
- 没有任何状态变化的纯描写轮
- 秘密被无意中在对话中泄露

## 校验流程

```
叙述生成完毕
    ↓
逐项检查六类校验
    ↓
全部通过 → 提交事件，更新状态
    ↓
任一不通过 → 标记问题 → 修正叙述 → 重新校验
    ↓
最多修正2次，仍不通过 → 回退到上一步重新生成
```

## 校验严重度

| 级别 | 含义 | 处理 |
|------|------|------|
| CRITICAL | 违反硬规则/物品凭空出现/死人复活 | 必须重写 |
| ERROR | 知识越界/战力不合理/关系矛盾 | 必须修正 |
| WARNING | 节奏重复/轻微不连贯 | 建议修正 |
| INFO | 风格建议/可选优化 | 记录但不阻塞 |
