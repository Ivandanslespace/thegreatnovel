# 基地系统规则

## 核心概念

基地是玩家的安全屋、仓库、生产基地和防御工事。
基地有等级，等级决定可用模块数量和基础属性。

## 基地属性

```yaml
base:
  name: 基地名称（由世界主题决定）
  level: 1-10
  durability: 当前耐久 / 最大耐久
  space: 可用空间（模块槽位数）
  defense: 基础防御值
  modules: [已安装模块列表]
  special_properties: [特殊性质]
```

## 等级与空间

| 等级 | 空间(槽位) | 耐久 | 防御 | 升级需要 |
|------|-----------|------|------|----------|
| Lv1 | 3 | 100 | 10 | — |
| Lv2 | 5 | 250 | 25 | 图纸+铁锭×20+玻璃×10 |
| Lv3 | 8 | 500 | 60 | 图纸+铁锭×50+特殊材料 |
| Lv4 | 12 | 1000 | 120 | 图纸+合金×30+核心×1 |
| Lv5 | 16 | 2000 | 200 | 图纸+合金×80+核心×3 |
| Lv6+ | +4/级 | ×1.8 | ×1.6 | 递增 |

升级完成时恢复全部耐久（可作为结构性维修）。

## 模块系统

### 模块类型

| 类型 | 功能 | 示例 |
|------|------|------|
| 核心 | 基地运转必需 | 能源核心、控制中心 |
| 防御 | 抵御攻击 | 箭塔、护盾、陷阱 |
| 生产 | 制造物品 | 制作台、锻造台、炼金台 |
| 储存 | 存放资源 | 储物箱、冷库、弹药库 |
| 生活 | 恢复和生存 | 床铺、厨房、净水器 |
| 研究 | 解锁科技 | 研究台、图书馆 |
| 移动 | 基地移动能力 | 引擎、帆、燃料箱 |
| 特殊 | 独特功能 | 传送阵、通讯塔、训练场 |

### 模块结构
```yaml
module:
  id: 唯一标识
  name: 名称
  type: 类型
  level: 1-5
  space_cost: 占用槽位
  build_cost: 建造材料
  build_time: 建造时间
  effects: 效果列表
  maintenance: 维护消耗（每日）
  upgrade_path: 升级路线
```

### 建造规则
- 需要对应材料
- 需要建造时间（期间不可用）
- 需要空闲槽位
- 部分模块有前置要求（如：锻造台需要制作台Lv2）

## 基地升级路线（流派）

玩家可以选择不同发展方向：

### 战斗型
- 重点：防御模块 + 武器平台
- 优势：夜袭无忧，可主动出击
- 代价：生产能力弱，资源紧张

### 生产型
- 重点：生产模块 + 储存模块
- 优势：自给自足，可交易致富
- 代价：防御薄弱，需要盟友保护

### 仓储型
- 重点：储存 + 生活
- 优势：资源储备深厚，持久战
- 代价：战斗力一般

### 综合型
- 均衡发展
- 优势：无明显短板
- 代价：没有突出长板，升级更慢

## 基地防御战

### 触发条件
- 周期性夜袭（每X天）
- 灾难事件
- 被其他势力攻击
- 怪物潮

### 防御结算
```
防御力 = 基地防御 + 防御模块加成 + 玩家战力 + 队友战力
攻击力 = 来袭敌人总战力

结果：
  防御力 > 攻击力 × 1.5：完胜，无损失
  防御力 > 攻击力：胜利，轻微损耗
  防御力 ≈ 攻击力：惨胜，模块受损
  防御力 < 攻击力：失败，基地耐久大幅下降
  防御力 < 攻击力 × 0.5：基地毁灭
```

### 基地毁灭后果
- 所有未转移物资丢失
- 模块全部损毁
- 玩家需要从零重建（或依附他人）
- 可能是游戏结束条件之一

## 基地内活动

在基地时，玩家可以：
- 制造装备和消耗品
- 升级模块
- 修理装备
- 休息恢复
- 整理背包
- 交易（如果有通讯/市场模块）
- 与同居者互动
- 研究新科技
- 训练（消耗时间换取少量经验）
- 规划下一次探索

## 同居系统

### 规则
- 基地拥有者发出邀请
- 对方接受后进入同一基地
- 同居者不能伤害车主
- 未经许可不能拿走车主物品
- 车主可随时驱逐
- 车主拥有绝对控制权

### 同居者贡献
- 可以协助防御
- 可以分担生产
- 可以共享部分资源
- 提供社交互动和关系发展机会

### 同居风险
- 车主死亡：同居者失去保护
- 信任问题：虽然不能偷，但可以离开并带走信息
- 空间占用：每个同居者占用1-2槽位的生活空间
