# 社交系统规则

## 三层社会单位

### 第一层：临时队伍
- 为某次探索/副本临时组成
- 生命周期短（一次任务）
- 战利品分配是主要矛盾
- 成员之间无忠诚保证
- 任务结束即解散

### 第二层：核心伙伴（2-6人）
- 长期同行
- 共享部分资源
- 稳定分工
- 形成友情/爱情/矛盾
- 成员死亡造成长期叙事影响
- 依赖个人关系而非制度

### 第三层：正式势力/帮派
- 有名称、领袖、等级、成员、基地、仓库、职位、规则
- 人数通常 10-100+
- 有长期目标和意识形态
- 有内部政治和权力结构
- 与其他势力有敌友关系

## 玩家社会路线

### 加入势力

优势：
- 稳定资源供给
- 队友救援
- 大型任务参与权
- 情报网络
- 公共设施使用
- 分担建设成本

代价：
- 交税/上缴资源（收入的10-30%）
- 接受组织任务
- 战利品不能完全自由处理
- 被卷入派系冲突
- 个人秘密可能暴露
- 势力战败牵连成员

### 独行

优势：
- 战利品全部归己
- 行动完全自由
- 更容易隐藏能力
- 不承担集体责任
- 可与多个势力交易
- 不受内部政治影响

代价：
- 无救援
- 无法完成大型内容
- 情报获取慢
- 生产建设效率低
- 重伤后极危险
- 容易被组织排挤或掠夺

### 小团体（核心伙伴）

优势：
- 信任度高
- 灵活
- 无需交税
- 决策快
- 关系深度

代价：
- 规模有限
- 资源池小
- 一人死亡影响巨大
- 无法对抗大型势力

## 势力数据结构

```yaml
faction:
  id: 唯一标识
  name: 名称
  type: 类型（互助/精英/掠夺/商业/宗教）
  leader: NPC ID
  members: 人数
  power: 战力评估
  resources:
    food: X
    materials: X
    currency: X
    special: X
  territory: 控制区域
  ideology: 核心理念
  reputation: 声望(0-100)
  stability: 内部稳定(0-100)
  goals:
    short_term: 当前目标
    long_term: 长期目标
  current_problem: 当前困难
  next_action: 下一步计划
  attitude_to_player: 对玩家态度
  relations: 与其他势力关系
```

## 势力自主行动

每轮结束后，每个已激活势力执行一步行动：
```
1. 检查当前目标进度
2. 评估资源状况
3. 决定是否执行 next_action
4. 如果玩家妨碍了目标 → 调整对玩家态度
5. 如果资源不足 → 可能寻求合作或发动掠夺
6. 内部稳定过低 → 可能分裂/政变
```

势力不围绕玩家静止。即使玩家不互动，势力也在：
- 争夺资源点
- 招募NPC
- 建造基地
- 与其他势力冲突
- 传播信息
- 内部演化

## 玩家与势力关系

```yaml
player_faction_relation:
  faction_id: 势力ID
  reputation: 声望(0-100)
  trust: 信任(0-100)
  contribution: 累计贡献值
  rank: 职位（外围/正式/核心/长老/副手）
  suspicion: 怀疑度(0-100)
  debt:
    faction_owes_player: 势力欠玩家
    player_owes_faction: 玩家欠势力
  status: 正常/被监视/被通缉/被驱逐
```

### 职位晋升
```
外围成员：贡献 > 50，信任 > 20
正式成员：贡献 > 200，信任 > 40
核心成员：贡献 > 500，信任 > 60，需要任务
长老：贡献 > 1000，信任 > 80，需要势力事件
副手/继承：特殊剧情触发
```

### 背叛与退出
- 退出：可以，但根据带走资源多少决定后果
- 背叛：永久敌对，被追杀
- 被驱逐：失去所有势力资源和保护
- 夺权：需要足够支持率 + 关键事件

## 情感关系系统

### 关系维度（独立，不同步）

```yaml
relationship:
  npc_id: NPC ID
  trust: 信任(0-100)       # 相信你不会伤害他
  respect: 尊重(0-100)     # 认可你的能力和判断
  affection: 好感(0-100)   # 喜欢和你在一起
  attraction: 吸引(0-100)  # 浪漫/性吸引
  intimacy: 亲密(0-100)    # 情感深度和脆弱性
  dependency: 依赖(0-100)  # 需要你（可能不健康）
  resentment: 怨恨(0-100)  # 积累的愤怒
  fear: 恐惧(0-100)        # 害怕你
```

### 关键规则
- 高信任 ≠ 想谈恋爱
- 高吸引 ≠ 信任
- 高依赖可能是有毒关系
- 敬佩和恐惧可以共存
- 爱一个人也可以因为背叛产生怨恨
- 怨恨积累到阈值 → 关系不可逆破裂

### NPC恋爱前提条件
```yaml
npc_romance:
  gender: 性别
  orientation: 性取向（异性/同性/双性/无性）
  romance_available: 是否可发展恋爱
  prerequisites:
    - trust > 60
    - affection > 50
    - attraction > 40（双方）
    - 无现有伴侣（或接受多角）
    - 特定剧情事件触发
  boundaries: 不可逾越的底线
  love_language: 表达爱的方式
  deal_breakers: 绝对不可接受的行为
```

### 关系发展路径
```
陌生人 → 认识 → 合作者 → 朋友 → 密友 → 恋人/伴侣
                ↘ 对手 → 敌人
                ↘ 利用 → 背叛
```

### 关系改变方式
- 共同经历危险（+trust, +intimacy）
- 在对方需要时帮助（+affection, +trust）
- 分享秘密（+intimacy, +trust）
- 违背承诺（-trust, +resentment）
- 欺骗被发现（-trust大幅, +resentment）
- 救命之恩（+所有正面维度）
- 长期忽视（-affection缓慢衰减）
- 价值观冲突（-respect）

### 关系事件触发
```
当某些维度达到阈值时，触发关系事件：
  trust > 70 + intimacy > 50 → 对方分享秘密/过去
  affection > 60 + attraction > 50 → 暧昧信号
  resentment > 60 → 对峙/争吵
  fear > 70 → NPC可能逃跑或背叛
  dependency > 80 → 不健康关系警告
```

## 社交互动选项

在社交场景中，玩家通常可以：
- 坦诚交谈
- 试探信息
- 撒谎/隐瞒
- 威胁
- 利诱
- 求助
- 提供帮助
- 表达关心
- 保持距离
- 自由行动

### 社交结算
```
说服成功率 = 
  基础概率(根据请求合理性)
  + 关系加成(trust/affection)
  + 玩家精神属性加成
  + 证据/筹码
  - NPC固执度
  - 请求代价
  - 怀疑度
```

### 欺骗检测
```
被识破概率 = 
  NPC感知(spirit)
  + 谎言复杂度
  + 之前的怀疑度
  - 玩家欺骗经验
  - 证据销毁程度
  
被识破后果：trust -30~50, resentment +20~40
```

## NPC自主性

每个重要NPC有：
```yaml
npc:
  id: 唯一标识
  name: 名字
  personality: 性格标签
  goals: 个人目标
  fears: 恐惧
  knowledge: 已知信息
  resources: 持有资源
  relationships: 与其他NPC关系
  current_plan: 当前行动计划
  bottom_line: 底线（不可逾越）
  loyalty: 对玩家忠诚度（如适用）
```

NPC每轮可能：
- 执行自己的计划
- 主动找玩家（有原因）
- 与其他NPC互动
- 根据新信息改变态度
- 在玩家不知道时采取行动
