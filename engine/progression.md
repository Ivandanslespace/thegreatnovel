# 成长系统规则

## 基础属性

四项固定属性（所有世界通用，显示名称可换）：

| 属性 | 控制 | 默认显示 | 修仙显示 | 科幻显示 |
|------|------|----------|----------|----------|
| strength | 近战伤害、负重、破坏 | 力量 | 体魄 | 动力 |
| constitution | 生命值、耐力、抗性 | 体质 | 根骨 | 装甲 |
| agility | 速度、闪避、远程精度 | 敏捷 | 身法 | 反应 |
| spirit | 感知、技能威力、精神抗性 | 精神 | 神识 | 算力 |

### 初始属性
```
所有属性初始值：5
自由分配点数：4（玩家创建角色时分配）
范围：单项最低3，最高10
```

### 属性成长
```
每次升级获得：
  固定成长：每属性 +1
  自由点数：+2（玩家自行分配）
  突破加成：根据突破道具倾向额外 +2-3 到对应属性
```

## 等级系统

### 经验需求
```
Lv1→2: 100
Lv2→3: 200
Lv3→4: 400
Lv4→5: 800
...
公式：100 × 2^(level-1)
```

### 等级衰减（引擎 v1 唯一口径）
- 玩家比怪物高1级：经验 ×1.00
- 玩家比怪物高2级：经验 ×0.60
- 玩家比怪物高3级：经验 ×0.25
- 玩家比怪物高4级及以上：经验 ×0.05
- 等级相同或怪物等级更高：经验 ×1.00
- 具体计算由 `engine_runtime.calculators.experience_decay()` 执行。

### 突破机制
```
每3级需要突破道具：
  Lv3, Lv6, Lv9, Lv12...
  
突破道具带有成长倾向：
  力量倾向：升级时力量额外 +2
  体质倾向：升级时体质额外 +2
  敏捷倾向：升级时敏捷额外 +2
  精神倾向：升级时精神额外 +2
  
突破道具来源：副本奖励/商店/制造/掉落
没有突破道具 = 无法升级（卡级）
```

## 天赋系统（三选一）

### 触发条件
- 人物每升一级：触发一次三选一
- 基地每升一级：触发一次三选一（如果世界设定允许）

### 选项来源

每个世界在创建时由 LLM 原创一组 `world.talent_deck`。升级三选一只从本世界
已注册的卡池中抽取；引擎不提供跨世界固定的“信息类/个人类/建设类”天赋，也不
以主题关键词回填任何能力名称或效果。

### 评级
天赋与装备统一使用字母评级，不使用颜色代替等级。展示时从高到低为：
```
SSS → SS → S → A → B → C → D → E → F → G
```

`rarity` 字段只允许使用上述值。评级代表能力或装备的综合层级；获取概率、
掉落来源和是否唯一由具体奖池另行决定，不能把评级和掉率混为一谈。

幸运卡牌（★）：特殊规则类能力，通常为 S 级或更高；最终评级仍由 Python 生成。

### 规则类能力
规则类能力不参与概率，直接规定结果：
- 弱点锁定：攻击必中弱点
- 额外攻击：每次命中追加一次
- 危险感知：首次被偷袭必定格挡
- 物资收集：击杀范围内自动拾取
- 量产：低价值物品免材料制造

规则类能力之间可以连锁（这是主角的核心优势）。

### 天赋叠加
- 同一天赋可重复获得（升级效果）
- 不同天赋可组合产生协同
- 天赋总数无上限，但每次只能三选一

## 技能系统

### 技能结构
```yaml
skill:
  id: 唯一标识
  name: 显示名
  type: active/passive/ultimate
  level: 1-10
  cost: 消耗（体力/能量/材料）
  cooldown: 冷却（回合数）
  effects:
    - type: damage/heal/status/buff/debuff
      value: 数值
      scaling: 属性缩放
      duration: 持续时间
  requirements: 解锁条件
```

### 技能获取
- 职业书（转职获得）
- 技能书（掉落/购买）
- 天赋附带
- 基地研究解锁
- NPC传授

### 技能升级
```
消耗：技能点 + 对应材料
每级：效果 +15-25%
最高10级
```

## 职业系统

### 转职条件
- 达到 Lv3
- 拥有对应职业书
- 满足属性要求

### 职业评级
职业同样使用 `G/F/E/D/C/B/A/S/SS/SSS` 评级；评级越高，通常代表越高的成长上限、
更苛刻的获取条件和更明确的专属路线。

### 职业提供
- 属性成长加成
- 专属技能（2-4个）
- 装备适性
- 被动效果
- 后续进阶路线

### 双职业（隐藏）
- 极稀有条件解锁第二职业栏
- 两套职业技能独立
- 属性加成叠加
- 战斗中可切换

## 装备系统

### 评级
```
SSS → SS → S → A → B → C → D → E → F → G
```

装备的 `rarity` 保存上述字母评级。装备属性、特殊效果、获取条件和维护成本可以
分别变化，不能只凭评级忽略当前阶段的实际用途。

### 装备槽位
```
主武器 / 副武器 / 头盔 / 胸甲 / 护腿 / 靴子 / 饰品×2
```

### 装备属性
```yaml
equipment:
  name: 名称
  slot: 槽位
  rarity: G/F/E/D/C/B/A/S/SS/SSS
  level_requirement: 等级要求
  attributes:
    attack: 攻击力
    defense: 防御力
    speed: 速度加成
    special: 特殊效果
  durability: 耐久
  effects: 附加效果列表
```

### 耐久系统
- 每次战斗消耗耐久
- 耐久归零：装备失效
- 可修复（消耗材料）
- 不可修复的消耗品：箭矢、炸弹等

## 生命值与状态

```
最大生命 = 体质 × 10 + 等级 × 5 + 装备加成
状态效果：
  中毒：每回合 -X 生命
  流血：每回合 -X 生命（可叠加）
  骨折：速度 -50%
  疲劳：全属性 -20%
  饥饿：每X小时 -5 生命
  寒冷/炎热：持续伤害
```

### 恢复
- 自然恢复：安全区每小时 +5% 最大生命
- 药剂：即时恢复固定值
- 技能：治疗类技能
- 休息：基地内睡眠完全恢复
